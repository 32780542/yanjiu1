# 持续交通流的实验与评价方法

本文件保留初版v1/v2协议及效率、油耗定义。当前v3的基础NOA、入口与时间分解以[修正规则](基础NOA与入口修正规则.md)为准，直接编队指标见[规模与稳定度评价](编队规模与稳定度评价.md)。HBEFA3模型与同区间积分方法继续沿用。

本轮研究车辆在一段道路上持续进入、形成局部队形并驶离的过程。评价对象包括交通效率和燃油消耗。实验组使用当前纯规则编队；对照组采用同一运动模型下的常规跟驰与车道保持。

## 1. 场景依据与实验设置

Cai 等（2024）的 *Multi-lane Formation Control in Mixed Traffic Environment* 在第 3 页声明使用行程时间与燃油消耗评价交通表现，第 4–5 页采用每车道 1250、1500、1750、2000 辆/小时，并展示 600 s 的交通时空图。表 I 给出目标速度 28.8 m/s、最大速度 33.3 m/s。[论文 DOI](https://doi.org/10.1109/IV55156.2024.10588701)

用户选定以提供的 MATLAB 当前道路为主场景。`New_Road.m` 给出 0、1000、1200 m 三个节点，`New_Edge.m` 两段均设置三车道。本轮主场景因此采用长 1200 m 的恒定三车道直路。论文图 4 的道路为三车道转两车道，属于另一种道路设置。

| 项目 | 本轮设置 |
| --- | --- |
| 主场景 | 1200 m 三车道直路，车道宽 3.3 m。 |
| 连续生成时间 | 0≤t<600 s，逐车道、逐 0.1 s 独立 Bernoulli 请求。 |
| 每车道需求率 | 1250、1500、1750、2000 辆/小时，概率精确取 q×0.1/3600。 |
| 车辆构成 | 100%使用本研究同一车辆模型；编队决策仅使用本车有限观测与私有记忆。 |
| 初速度与目标速度 | 入口初速度28.8 m/s；主场景目标28.8 m/s；最大速度33.3 m/s。 |
| 编队几何 | 同车道目标层距30 m，车道相位差15 m。 |
| 控制与积分 | 0.1 s控制、0.01 s运动积分，保留原控制器和原运动模型。 |
| 随机重复 | seed1、2、3，同一工况开关编队共享完全相同的请求表。 |
| 停止请求后的处理 | 600 s后继续发出入口队列并推进全部在网车辆，直到排空或记录至2400 s。 |

检测到车体接触或驶出道路时，保存当前控制拍并结束该例，登记安全失效。该例的计划请求总数、已释放请求、未来尚未释放请求、入口队列和在网车辆分别记录；未观察完整600 s的出口量留空。先前已经完整封存的安全失效例保留原记录，性能汇总采用同一安全有效条件。

主场景共有 4种需求×3种子×2种模式=24例。补充2、4车道、每车道1500辆/小时的12例；另在三车道、1500辆/小时下改变目标速度为24、32 m/s，改变层距为24、36 m，共18例。总计54例，其中层距变化共享相同种子的基准对照。

常规跟驰调用本工程的[纵向控制](../variants/phase5g_pure_formation/noa/driving.py)，包含3 m静止间距、1.8 s时距及考虑响应、执行器变化的制动反馈。编队组调用现有[编队目标计算](../variants/phase5g_pure_formation/noa/simple_formation.py)和[编队执行](../variants/phase5g_pure_formation/noa/simple_controller.py)。两组共同采用车道保持，编队组另外执行其分层补位；两组的普通主动超车关闭。

目标速度是局部领航车的巡航设定。既有位置跟踪规则允许后车在追赶参考位置时加速，最高33.3 m/s，所以实际全网平均速度单独报告。层距24、36 m实验只改变同车道纵向间距，车道相位差均保持15 m。

两组的纵向安全判据也有区别：常规组使用含执行响应的最坏制动距离和舒适停车速度上限；普通编队跟驰无活动换道计划时，使用当前净距/TTC紧急判据，有有效编队跟踪目标且未触发紧急状态时，以位置跟踪指令替换常规纵向指令。活动换道、道路终点分支另有保护。当前比较反映这两套完整控制实现的综合差异，编队排列的独立收益需在统一纵向安全条件与速度规则后评价。实际时间分解与参数代入见[结果报告](持续大交通流验证报告.md#常规组为什么耗时长)。

## 2. 请求、入场与出口

MATLAB 的 `rand<VGR` 用来生成到达请求。本轮采用同一机制，并保存每个请求的绝对时刻、车道和车辆标签。各车道维护独立 FIFO 队列，车辆在入口满足时距与现有运动模型的制动距离后进入。

新车的制动距离计入控制响应和执行器变化；前车速度取当时的实际速度。这个条件避免把28.8 m/s的新车直接插在慢行队列之后。两组使用相同的入场条件，队列车辆均保留。

1200 m 是测量出口，传感道路在出口后继续延伸。车辆跨过出口时记录实际离场时间，并从后续推进与审计中移除。跨越时刻在0.01 s积分子步内插值，最后一小段燃油与里程按同一时间比例计入。

每拍检查车辆守恒：已经请求的车辆=已经入场的车辆+入口等待车辆；已经入场的车辆=已经离场的车辆+当前在网车辆。

## 3. 交通效率

对车辆 i 记录请求时刻 ri、实际入场时刻 ei、出口时刻 ai。三种时间分别为：

\[
W_i=e_i-r_i,\qquad T_i=a_i-e_i,\qquad S_i=a_i-r_i=W_i+T_i.
\]

- **平均入口等待 W：** 反映请求积压和道路接纳能力。
- **平均在网行程时间 T：** 对应1200 m路段内的通行过程。
- **平均系统时间 S：** 从请求到驶离，完整计入入口等待。

完整队列均排空的案例，使用该次600 s中产生的全部车辆计算均值。观察终点仍有未入场或在网车辆时，列出对应数量，完整车群平均系统时间留空。

**固定窗口出口流量**由0–600 s内实际驶离车辆数计算：

\[
Q_{out}=\frac{N_{exit,600}}{600}\times3600.
\]

同时保存600 s时的实际入场数、出口数、入口队列数和在网数，以及最终完成量和排空耗时。

**全网平均速度**使用累计实际行驶距离除以累计车辆在网时间：

\[
\bar v=\frac{\sum_iD_i}{\sum_iT_i}.
\]

这使停车时间直接进入统计。时空速度图采用1 s位置样本，在5 s×25 m网格内对车辆速度求平均，空单元留白。

## 4. 燃油消耗

燃油采用统一的 **HBEFA3/PC_G_EU4** 汽油乘用车类别。SUMO 的官方工具可依据速度和加速度轨迹计算排放与燃油，当前默认质量流率为 mg/s。[官方轨迹油耗工具](https://sumo.dlr.de/docs/Tools/Emissions.html)、[官方燃油单位](https://sumo.dlr.de/docs/Simulation/Output/EmissionOutput.html)

本轮将该类别的瞬时公式用于实际运动积分结果，统一采用平路、发动机开启和官方默认1500 kg及默认迎风面积。油耗模型是独立评价层，不参与车辆决策。

在未触发发动机制动断油时，质量流率为：

\[
f(v,a)=\max\left(\frac{3014+299.3av-149v+9.014v^2}{3.6},0\right)\quad\mathrm{mg/s}.
\]

断油条件沿用该版本的速度相关滑行阈值。具体系数和实现来自 SUMO 1.27.1 的 [HelpersHBEFA3.cpp](https://github.com/eclipse-sumo/sumo/blob/v1_27_1/src/utils/emissions/HelpersHBEFA3.cpp#L236-L242)、[HelpersHBEFA3.h](https://github.com/eclipse-sumo/sumo/blob/v1_27_1/src/utils/emissions/HelpersHBEFA3.h#L97-L115) 和 [PollutantsInterface.cpp](https://github.com/eclipse-sumo/sumo/blob/v1_27_1/src/utils/emissions/PollutantsInterface.cpp#L197-L209)。本机官方工具的47个平路参考点与本实现对照，最大差为0.005 mg/s，与工具保留两位小数的舍入一致。

每个0.01 s积分子步使用实际速度变化计算实际纵向加速度，在子步中点计算油耗率，并按实际经过时间积分：

\[
M_i=\sum_k f(v_{i,k},a_{i,k})\,\Delta t_{i,k}.
\]

出口截断子步的油耗与里程采用同一段时间。燃油统计区间为实际入场至实际离场，入口等待时间另列。

报告三项燃油量：

| 指标 | 公式与单位 |
| --- | --- |
| 在网总燃油质量 | ΣMi / 10⁶，单位kg。 |
| 距离归一化油耗 | ΣMi(mg) / ΣDi(m)，数值单位g/km。 |
| 每车平均燃油流率 | ΣMi / ΣTi，单位mg/s，以车辆在网时间加权。 |

距离归一化油耗与其分母使用同一车辆、同一在网行程。速度与加速度变化带来的燃油影响由这个模型直接量化。

本机 Chen 等（2021）*Mixed platoon control of automated and human-driven vehicles at a signalized intersection* 的第7页式(19)、(21)–(23)采用瞬时燃油率的时间积分，第12页§4.1按距离归一化报告油耗，可作为这一评价思路的相关文献依据。[DOI](https://doi.org/10.1016/j.trc.2021.103138)

## 5. 配对比较

每个编队案例与车道数、需求率、种子、目标速度相同的常规跟驰案例配对。层距24、36 m变化使用同一基准对照；速度24、32 m/s各使用对应速度的对照。

时间和油耗的改善率统一为：

\[
I=100\times\frac{X_{base}-X_{formation}}{X_{base}}.
\]

正值表示减少，负值表示增加。出口流量变化率取编队组相对对照组的增加比例。两组均完整排空且未检测到碰撞或驶出道路时，登记为有效性能配对；其他案例保留原始结果与未完成数量。

工况结果先按单个种子计算，再给有效案例的均值与样本标准差，并标明有效数量/3；逐例表保留全部预定案例。改善率先在有效配对内计算，再跨种子汇总。主文同时列出在网时间、系统时间、实际出口量和油耗。

## 6. 数据与复算

每例保存完整请求表和逐车行程台账、0.1 s全网累计、1 s物理位置样本、接触及驶出道路事件、参数与文件SHA-256。批次共享一份源码快照。

长时运行使用缓存字段读取替代冻结数值记录的递归深拷贝。1000组随机积分的完整结果摘要与原实现相同，既有600个局部场景及1250拍闭环摘要也保持一致；积分运算、感知范围、排序依据和车辆规则不变。分批接续时，已封存条件直接保留，未完成条件使用相同参数与请求表在新目录重算，各条件只进入总表一次。

汇总脚本逐一核对摘要，再从台账独立重算时间、通过量与燃油指标，并检查逐步全网累计与逐车累计相等。每个配对还核对请求表逐项相同。原始未改善、执行失败和早期探针均保留。
