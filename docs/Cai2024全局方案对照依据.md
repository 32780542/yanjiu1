## 4. 共同SUMO条件下可实现的集中参考定义

建议命名为**“Cai式集中目标分配参考（本机适配）”**，与“Cai2024论文原始结果”分栏。它适用于100%CAV：

1. 共用已授权的道路、1250概率请求序列、种子、同一CAV车型、28.8/33.3m/s、0.1s步长、600s请求后排空、SUMO运动及安全执行，以及同一评价代码。入口不额外限流。
2. 中央参考控制器读取当前全体实车物理状态，按纵向相邻距离≤50m分组；50m是本机补充定义，不是原文明确数值。每5s联合规划；不读取未来随机请求。
3. 用组最前车为移动参考，生成与组车数相等的交错目标，优先填前方空位。同道间距30m、跨道相位15m；组最前车到640m时改为保留的两车道目标。几何相位采用本工程固定的物理车道约定，并显式记录这一适配。
4. 按本机MATLAB的`(Δ纵向网格)^2+(Δ车道)^2`成本做一对一最小成本匹配（网格15m），记录分组、目标和分配。相同成本时使用稳定、公开的几何次序作确定性处理；该全局分配仅属于参考控制器。
5. 轨迹执行共用SUMO安全检查、相邻换道、8m目标道净空及速度/加速度边界。中央控制器须处理目标/运动冲突；可先用分阶段几何调度和本工程速度跟踪实现，记录重新规划、不可行、等待和未完成。不能用强制摆位或不安全瞬移提高结果。

此定义保留“中央获取状态→生成交错目标→联合最小成本分配”的核心，但将原文提到的A*/CBS/Bezier及MATLAB的GPOPS/SNOPT最优控制替换为共同SUMO执行和适配轨迹逻辑，也不复制整组低速归零门。因此它是**集中分配的工程参照，不能称作完整复现Cai2024或其论文性能上界**。若后续要求严格复现，应先解决SNOPT可运行性、干净源版本、路网和后处理口径，再单独验证。

三方案最终表应全部使用共同条件本机数据，保留请求数/实际插入数/完成数/发车延迟、行程时间、出口流量、速度、共同燃油模型、安全事件及未完成。原论文热图只附作来源参照，缺失的油耗与非编队数据留空并写明未提供。
