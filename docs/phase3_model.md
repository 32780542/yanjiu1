# 阶段3：局部观测、统一时钟与重放语义

主车辆运动已按用户2026-09-11要求简化，见 [kinematic_motion.md](D:/yanjiu1/keyan1/docs/kinematic_motion.md)。旧动力学只支持历史重放。

每轮顺序：冻结全部车辆同刻状态→分别生成局部输入→每车纯函数动作→全部车辆独立积分→提交全部终态→SUMO仅推进一次→逐车核验。统一时钟只执行物理仿真，不进行通行排序、协调、组队或目标分配。读回、几何或数值故障只报告/终止，不做全局补救。

控制入口为不可变 `ControlInput(ego, observation, memory)`。`perception/probe.py` 仅用自车速度和当前可见邻车的相对位置/速度产生简单纵向命令，转向为零；它不是NOA或安全控制器。给定贝塞尔参考的单车测试独立进行，不是多车共享轨迹。

观测按车辆几何中心在自车矩形 `−100≤x≤200 m, |y|≤50 m` 内筛选，边界计入。无edge筛选、遮挡、噪声或漏检。相对速度是双方世界速度之差投影到自车轴，不是包含坐标旋转项的相对位置导数。测量时刻等于本次更新物理时刻。浮点边界比较仅在最大量程8 ULP（当前2.274e−13 m）内按边界处理，原始允许状态数值不加噪声或修饰。

每个自车单独分配轨迹编号，新编号按可观测几何/运动字段排序，不按真实ID、类型或全局顺序。连续可见时真实ID仅辅助关联；退出立即删除当前关联，重入新编号。完全不可区分的重复观测不保留真值关联，分离后重新编号。策略不以编号设优先级。

历史只包含过去1 s的测量，当前观测另列。范围外旧目标只保留旧值和旧时刻，不能查询其当前真值。重复/不规则采样、混合时刻、重复内部键、非有限输入均拒绝。道路适配器只支持当前已核验直路，输出区域内边界、标线及收窄部分，合并无物理意义的edge分段；控制器没有完整道路或全局瓶颈阈值。

启动配置读取前先保存可获取的命令、Python、源码和配置快照。初始化与运行期读回均保留已读取、失败、未读取车辆，失败后实例不可继续。初态安装两个原生步排除于物理时间之外，偏移和警告原文保留。

重放从冻结初态、道路和参数重建全部观测、历史、动作、子步，并核验SUMO读回与证据哈希；还重新执行隐藏信息变更审计、同命令积分细化及贝塞尔自车参考。重放不启动SUMO，原始SUMO日志作为已运行证据；重新执行仿真使用 `phase3`。故意失败和正常结果分开记录。

这是已实现代码的信息流审计，不是任意恶意Python控制器的操作系统沙箱证明。新增控制器仍需检查导入、数据入口及不变性。
