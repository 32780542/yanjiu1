用户当前要求是**有限范围内精确、零额外测量延迟的理想观测**。不要重新加入遮挡、噪声、漏检或传感器失联需求；保持离散采样和执行器响应。

建议本阶段实施顺序：

1. 先将阶段2单车时钟扩展为统一多车状态缓存/调度器：同刻冻结真值→逐车感知→逐车独立动作→统一积分→提交全部终态→SUMO只推进一次→逐车核验。不能让每辆车分别调用单车桥而重复推进全局仿真。
2. 实现感知适配器，只有它和隔离评估模块可访问仿真真值。控制入口坚持 `ControlInput(ego, observation, memory)`，不传车辆全局表、NOA/HDV标签、真实ID的语义编码、他车计划、共同领航车或全局槽位。
3. 在自车坐标中采用包含边界的矩形：`−100≤relative_x≤200 m` 且 `abs(relative_y)≤50 m`。每次更新输出范围内允许状态的精确值；时间戳等于本次感知时刻，额外测量延迟零。几何范围不限于同一edge；不能因其他车辆挡住视线而漏掉范围内目标。
4. 提供仅局部可见目标的跟踪编号及明确退出/重入记忆语义；编号不能把隐藏真值类别、全局排序或组信息透露给控制器。
5. 静态地图在主方法关闭。只输出感知范围内的道路收窄/边界信息，控制器不能凭全局x=1000或旧源码x=640阈值触发合流。
6. 先写范围内/外/边界、跨edge、并排/换道和时间一致测试；再做同允许观测、不同隐藏类型/范围外状态/他车计划时动作不变的审计。记录观测、控制输入和自车动作并可重放。

阶段2提供的单车测试跟踪律不是NOA基线，也没有感知依赖。阶段3可用最小、确定的自车测试策略审计信息隔离，明确这种策略不是完整NOA；阶段4才实现CRUISE/FOLLOW/PREPARE_LC/EXECUTE_LC/MERGE/EMERGENCY及安全决策。阶段5再实现局部交错规则。
