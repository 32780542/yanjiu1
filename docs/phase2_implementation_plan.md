# 阶段2实施计划：连续车辆动力学与SUMO同步

依据用户已授权的研究规格§7/阶段2与`phase2_entry.md`执行；不扩展到阶段3感知或阶段4 NOA。所有新文件和输出在keyan1。

目标：实际状态来自连续方程积分；SUMO只显示/同步积分后的位置、航向和速度；独立车身/扫掠检测及重放能够检出异常。

设计：冻结`VehicleState`与`Actuation`；`models/vehicle.py`无TraCI、道路或邻车依赖。RK4以0.01 s积分，控制命令以0.1 s采样保持；低速用平滑融合的运动学目标松弛模型，高速使用2-DOF整轴线性轮胎模型与摩擦圆饱和。纵向状态区分执行器等效加速度和受非负速度/最高速度约束的实际速度导数。测试轨迹源仅使用自车状态和预先给定的单车参考；它不是NOA决策器，不读取瓶颈坐标/邻车类型/计划。

文件分工：`models/vehicle.py`状态/参数/积分；`models/geometry.py`车身/角度转换；`safety/geometry.py`独立SAT及保守扫掠、道路包络；`simulation/external_bridge.py`同步与只读回验；`experiments/phase2.py`小工况、日志、重放和收敛；`configs/phase2.json`新增假设与测试阈值；`tests/test_phase2*.py`数值/几何/时序/失败门槛。
