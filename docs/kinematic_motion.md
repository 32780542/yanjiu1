# 当前车辆运动：简化运动学与二次贝塞尔

2026-09-11，按用户执行中的新指示，主运动模型改为 `models/kinematic.py`。旧 `models/vehicle.py`、阶段2和阶段3两次旧动力学完整运行保留，不与新结果混合。此修订取代此前强制二自由度轮胎动力学要求。

以几何中心为参考点：`X_dot=v cosψ, Y_dot=v sinψ, ψ_dot=v tanδ/L, v_dot=a`。ψ是中心轨迹切线方向，δ是等效转向，忽略侧偏和轮胎力；并非精确质心动力学模型。保留4 m车长、1.8 m车宽、2.7 m等效轴距、0–33.3 m/s速度边界、−10至5 m/s²命令硬边界。测试策略日常命令仍为−3至2 m/s²；响应0.2/0.15 s、执行器jerk 2 m/s³、转向率0.5 rad/s沿用旧设置，没有调参追求改善。转向目标按名义横向加速度2 m/s²限幅，实际运动学横向加速度仍另算。

**活动模型不含质量、横摆惯量、轮胎刚度、附着系数、轮胎力或低速轮胎融合参数。** 历史配置中的值只支持旧证据重放，不是阶段3/4前置条件。新增 `kinematic` 层两个选择项，没有新增物理参数。模型读取器显式筛选活动字段；重放根据冻结的 `motion_model` 标记选择新旧模型，未知显式名称直接拒绝。

积分0.01 s，控制/感知/SUMO同步0.1 s。位置、航向和速度先积分，再按中心到前保险杠转换提交SUMO；不会把车辆搬到曲线上。RK中间阶段也对用于位姿积分的速度做边界投影，避免停车处短暂倒退或上限处积分超速。该投影并非精确停车事件定位；停车附近实际jerk仍可能非光滑，本次未证明停车舒适性。

单段二次曲线若两端切线均平行于车道，通常无法产生非零横向位移。实现采用两个二次段，D=vT、W=y1−y0：

- 第一段控制点 `(0,y0), (D/4,y0), (D/2,y0+W/2)`。
- 第二段控制点 `(D/2,y0+W/2), (3D/4,y1), (D,y1)`。

两段各占T/2时间，端点切线沿道路，连接点位置和一阶导数连续（C1）。连接处参考横向加速度从 `+4W/T²` 跳到 `−4W/T²`，**不是C2**。实际轨迹经过横向位置/速度误差反馈、转向滞后和速率限制后积分，位置、航向和转角保持连续。

验证使用20 m/s、W=3.3 m、T=5 s参考，再保持5 s。沿用已有最大横向误差0.35 m与终态误差0.05 m门槛。贝塞尔试验只是自车预设参考验证，不向邻车提供计划，也不等于完成NOA换道决策。实际结果和重放入口见阶段3验收报告。

该模型适合交通方法开发中的连续几何运动，不用于轮胎极限、失稳、附着变化或实车能耗研究。阶段3信息隔离、有限历史、独立几何检测和失败保留要求不变。NOA决策与安全筛选仍属阶段4，M1尚未完成。
