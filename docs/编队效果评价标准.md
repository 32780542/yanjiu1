# 纯规则编队效果评价标准

本研究的评价对象是车辆能否依靠现有跟驰与换道规则，在动态入场后形成有秩序的多车道交错队形。评价使用实际物理位置和速度，与车辆内部的角色名称、补位状态分开计算。核心结果为整队形成率、形成延迟、交错几何误差、速度一致性与目标偏差。

## 2. 什么时候算整队形成

每例共有 N=4L 辆车，L 为车道数。车辆入场车道由随机请求决定，目标终态为每条车道 4 辆。按照实际位置给每条车道的车辆从前到后排序，序号为 r=0、1、2、3。

车道自下向上编号 0 到 L−1。与最上方车道相隔偶数条车道的车道构成相位 A，其余为相位 B。A、B 相位相差 d=15 m，同相位车道在纵向对齐。各车道内部目标层距为 D，基准 D=30 m，参数实验取 24、36 m。

一帧满足以下全部条件时，称为整队达标帧：

1. N 辆车全部实际入场，均有连续物理记录。
2. 所有车辆组成同一个车群。按纵向位置排序，相邻车辆的纵向间隔均不超过现有规则中的 50 m 连通阈值。
3. 车辆车体完全属于某条车道，且每条车道恰好 4 辆。换道过程中的跨线车体暂不作为完整占位。
4. 同车道相邻车辆的间距相对 D 的误差不超过 2 m。
5. 同相位各车道对应序号车辆的纵向对齐误差不超过 2 m。
6. B 相位车辆相对 A 相位参照车道的对应车辆后移 15 m，误差不超过 2 m。
7. 全队速度极差不超过 1 m/s。

上述状态连续维持 1 s 后，在这 1 s 的结束时刻确认形成。确认时间用于排除经过某个瞬间恰好对齐的情况。观察从首辆实际请求入场开始，到最后一辆实际入场后 200 s 结束；每例均完整运行这段观察过程。

评价代码继续使用现有独立物理检测器 `experiments/phase5_detection.py`，本轮调用将 `formation_deadline_s` 和 `hold_s` 设为 `None`。

## 3. 四类主指标

### 3.1 整队形成率

\[
R=\frac{n_{\mathrm{formed}}}{n_{\mathrm{scheduled}}}\times100\%.
\]

每个工况安排 5 个固定种子。表格同时报告成功次数与百分比，例如 4/5、80%。全部预定案例保留在分母中。执行状态、记录完整性及碰撞情况另列，便于逐例核对。

### 3.2 形成延迟

\[
T_f=t_{\mathrm{confirmed}}-\max_i t_{i,\mathrm{entry}}.
\]

`t_entry` 是车辆真正进入道路的时间，包含入口排队影响；`t_confirmed` 是首次连续达标 1 s 的结束时间。未形成案例的形成时间留空，并列出实际观察终点。汇总表给出成功案例的中位数与范围，同时列出形成次数。

### 3.3 交错几何误差

令 x(l,r) 为车道 l 上第 r 辆车的纵向位置，a 为最上方 A 相位车道，b 为 B 相位车道。三部分误差分别为：

\[
E_D=\max_{l,r}|x(l,r)-x(l,r+1)-D|,
\]

\[
E_A=\max_{P\in\{A,B\},\,l\in P,r}|x(a_P,r)-x(l,r)|,
\]

\[
E_B=\max_{l\in B,r}|x(a,r)-x(l,r)-15|.
\]

其中 aP 是相位 P 中最上方的车道。总几何误差取三部分中的最大值。2 车道没有额外同相位车道，其对齐项为 0。目标占位尚不完整时，总几何误差记为缺测；缺少比较对象的分项也记为缺测，可计算的分项和实际车道车辆数照常报告。

逐例结果保存三个误差和最大值，汇总表使用观察终点的误差。这样既能看到是否形成，也能看到观察结束时的队形精度。完整轨迹可用于检查形成和失去对齐的时间。

### 3.4 速度一致性与目标偏差

车辆速度取平面速度大小：v=√(vx²+vy²)。报告：

\[
\Delta v=\max_i v_i-\min_i v_i,\qquad
E_v=\max_i|v_i-v^*|.
\]

Δv 描述全队是否同速，Ev 描述车辆是否达到实验设定的目标速度。逐例表还保存平均速度和速度标准差。速度指标与几何误差均使用观察终点的物理状态，形成判据中的速度极差按每个控制拍计算。

## 4. 记录与复算

每例保存请求及实际入场表、完整参数、0.1 s 物理轨迹、换道阶段、全部 0.01 s 积分子步的首次车体接触事实、结果和文件 SHA-256。碰撞以出现接触的不同车辆对计数，车道分布与换道次数作为解释编队过程的事实记录。

`formation_metrics.evaluate_run` 从压缩轨迹和输入表重新计算指标，不读取车辆的跟驰目标或内部槽位。汇总工具验证文件摘要，再逐例复算，与原结果逐字段比较。论文图、逐例 CSV 和工况汇总 CSV 均从同一批保存结果生成。

本轮指标对应形成效果和巡航一致性。实验报告给出每个车道数、每个需求率和每组参数的实际结果，并据此说明当前规则的适用条件。
