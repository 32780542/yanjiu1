# 持续大交通流与油耗评价计划

**目标：** 将有限车群验证扩展为持续进入、行驶和退出的开放交通流实验，比较当前纯规则编队的交通效率和燃油消耗。

**用户已选定：** 主场景为 MATLAB 当前三车道直路；1200m测量路段，600s持续独立Bernoulli来车。保留当前控制器与运动积分，开放出口不作为停车边界。

## 固定协议

- 主实验：每车道1250/1500/1750/2000辆/h，seed1/2/3，编队开/关配对，共24例。目标速度和入口速度28.8m/s，同车道目标层距30m、交错15m。
- 车道扩展：2、4车道直路，每车道1500辆/h，3seed、开/关配对，共12例。
- 参数扩展：三车道、1500辆/h，目标速度24/32m/s、层距24/36m。每组3seed，编队开启12例；速度变化各增加3个关闭编队对照，共6例。层距关闭组共享主实验同一基准。总计54个独立运行。
- 600s后停止新请求，继续入口排队与排空，最多运行到2400s；全部请求、入场与离场时间始终保留。
- 安全事件发生时保存当前拍并终止该例，失效结果保留；尚未到请求时刻的车辆与实际入口队列分别统计。
- 以相同请求车辆集合统计入口等待、在网行程时间、请求至出口系统时间、固定600s出口量，以及在网燃油总质量和g/km。未完成车辆和队列在600s及最终时刻单列。
- 油耗统一采用HBEFA3/PC_G_EU4、平路、发动机开启，依据实际积分速度和加速度计算，每个0.01s子步积分。与本机SUMO1.27.1官方工具做数值交叉核对。

## 文件职责

- `experiments/traffic_flow.py`：固定时长请求、开放交通推进、配对矩阵与归档。
- `experiments/traffic_metrics.py`：逐车台账、交通效率和燃油汇总。
- `models/fuel.py`：有来源并经官方工具验证的瞬时HBEFA3模型。
- `tests/test_traffic_flow.py`：生成、守恒、出口、感知等价和指标测试。
- `run_traffic_flow.py`、`summarize_traffic_flow.py`：运行和成果导出。

长任务使用根目录 `scripts/run_logged.py`。源代码只存一份批次快照；每例保存请求/行程台账、0.1s全网统计与1s位置样本，完整动作序列保留滚动摘要。控制器不读全局流量、请求表或油耗模型。

启动前核验：入口同时满足现有时距与模型紧急制动距离；两组均关闭额外的旧主动超车策略，对照为常规跟驰和车道保持。47个平路油耗参考点与官方SUMO工具输出差异≤0.005mg/s。短测81辆/组，全部完成、0碰撞，台账与全网燃油和距离累计一致。原始失败及早期插入条件不足的探针完整保留。
