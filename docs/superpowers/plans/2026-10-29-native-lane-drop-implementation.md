规则接口固定为：

```python
@dataclass(frozen=True, slots=True)
class Vehicle:
    track: int
    x: float
    y: float
    speed: float
    lane: int
    vy: float = 0.0
    acceleration: float = 0.0
    time: float = 0.0

@dataclass(frozen=True, slots=True)
class Command:
    speed: float
    lane: int | None = None
    reason: str = ''
    target_x: float | None = None
    reference: int | None = None

def decide(ego: Vehicle, neighbors: tuple[Vehicle, ...], memory: Memory,
           mode: str, drop_x: float | None = 1000.) -> tuple[Command, Memory]: ...
```

本车track为0，邻车是每车私有映射的局部轨迹标签。neighbors已裁剪到前200m、后100m全部车道；代码仍须不利用真ID或标签大小作优先权。`y`按物理车道中心1.65/4.95/8.25归一化，使用实测横向偏移与速度。道路静态信息`drop_x`允许两种策略同等读取。Memory只保存本车选择的参考、动作或间隙；运行器不向规则提供全车表、其他车状态机或目标。
