建议实施“车道优先、同车道严格超过原2 m纵向差才可判前后”的局部关系；它应只取代现有未进入竞争分支的纵向判断。该关系可以消除跨车道并排的歧义，但不能保证互斥、公平、有限时间通行或逐车形成。新增的主要负面边界是：没有换道请求的上方后车也可能持续阻挡下方前车。

## 优先关系的一致性

先保留 `entered → inward → occupied` 的现有判断次序。只对现有同gap `participants` 中的未进入车辆应用新关系。

令 L 是由可信可见车道几何得到的中心纵坐标，x 是世界x位置。可信比较定义为：

1. L(peer) > L(ego)：peer优先，纵向前后不改变结果。
2. L(peer) < L(ego)：ego优先，纵向前后不改变结果。
3. 两车属于同一可信车道：peer.x − ego.x > 原margin时peer优先；小于负margin时ego优先；含边界的中间区间不可比。
4. 任一方无法可信唯一归属车道：该对不可比；不能以原始y、车道数组位置、邻车顺序或标签补齐。

在共同、可信的车道几何下，此“优先”关系是严格偏序：跨车道比较由有序L决定，同车道两次严格领先相加后仍严格领先。不可比关系本身不传递，例如同车道x为0、1.5、3 m时，前两对可近并列而首尾可分前后。因此不要用“容差内相等”的自定义排序比较器排序后取首个赢家。

建议对ego逐个归约：有可信更高者即硬让行；所有参与者都可信更低才可放行；其余保持ambiguous。未知参与者永远不能帮助放行；如果已存在另一个可信更高者，仍可直接硬让行，不需要为该未知参与者制造额外状态。原episode association的UNKNOWN及其阻断语义必须保留。

“先dx>2，再用lane处理近并排”的通用关系可出现环，例如三条车道的A=(上,0)、B=(中,1.5)、C=(下,3)：A压B、B压C，而C靠纵向压A。这是比较关系的代数反例；当前同一中间目标带的三车运行不能直接等同于该反例，因为中间车进入目标带时应已被先行分支处理。

## 最小实现位置与几何条件

最小核心修改位于 `r5.assess_candidate` 现有 `participants` 之后的dx三分支，约第119–123行。保留near半径、同gap筛选、目标带判定、物理签名和episode关联结构。推荐新增小型纯几何归属/逐对比较辅助函数，避免散落在controller里。

若增加 `yield_visible_upper_lane` 等新原因，必须同时加入 `HARD_YIELD`；否则 `advance_backoff` 可能将它当作不阻断的清晰情形放行。相应ego胜出原因应准确说明lane依据，不宜继续把上方后车胜出称为“ego_visible_front”。可在assessment增加仅来自物理几何的诊断字段，但不要把这些新诊断字段塞进旧episode匹配签名或改变私有随机抽样条件。

道路的 `current_center_m` 和near筛选现在都采用最近中心，并在距离相等时选较小center。该规则足以做原来的候选筛选，不能单独视为“唯一车道”的证书。新优先判断应辨别中心等距、车身跨线、缺少可见边界和车道几何不能唯一支持归属；这些情况下保持保守。车道归属以可见strip为依据，不能以原始body.y的微小差值把同车道两车排成上下。可见道路在车道终止处随x改变；不要把只在ego横截面成立的source strip外推成peer所在x处也存在的车道。目标带本身不可重建仍沿用原拒绝边界。

controller无需改动数值或候选守卫。应确认新规则沿当前路径在PREPARE期间每拍复核，竞争重新出现时撤销准备；已提交plan继续走原active_plan_bypass。后者表明静态偏序不等于动态全局互斥。

## 必须保留的限制

1. **未请求车辆导致误让行。** `participants`完全基于可见几何，不知道谁有动机。原规则已会让同车道后车等待一个没有换道请求的前导；新规则进一步让下方前车等待上方后车，即便后者一直CRUISE。不能读邻车控制器状态或推测“不会请求”来消除该边界。
2. **饥饿及低速。** 固定车道偏好不轮换。上方持续有车、其候选持续被原守卫拒绝，或上方车一直无动机时，下方可无限期等待；不应新增超时强放行或老化队列。附加让行可将车速拉到5以下，旧可行上端数值问题也仍存在。更早获得优先权不等于能换道。
3. **视野差异。** 单车near半径含相对速度及本车几何，gap、可见边界和参与者集合也局部构造。不同车辆未必同时看到同一竞争集合；严格偏序的证明仅针对共同可信几何，不能扩展成可见性、全局赢家或有限步收敛证明。
4. **动态优先变化。** 进入、向内运动、完成换道后的新车道及参与者离开可见集合会改变关系。原entered/inward优先及active_plan_bypass必须继续覆盖这些边界。不要把物理先行状态排序成“上方车必须随时抢先”。
5. **形成职责未变化。** R5只控制换道候选入口，B1形成参考规则不变。`formation.py`在episode等风险期间将形成增量置0；因此有序提交甚至有序完成也不足以证明逐车形成。

## 建议的8项测试

下述为测试设计，没有在本审查中执行；前两项的近距离数值首先用于纯比较/assessment边界，并非全部是可驾驶初态。

1. **上方后车与下方前车互换ego。** 车道中心8.25/1.65、共同目标4.95；上车x=100、下车x=104、等速8。下车应硬让行，上车应得到清晰优先；两车均无新随机抽样。再把纵向差换为±2边界及0，跨车道结果不改变。
2. **同车道保留2 m边界。** 同一可信source lane，dx取−2.0001、−2、0、2、2.0001，分别为ego优先、ambiguous、ambiguous、ambiguous、peer优先；同车道内小幅y变化不能改变结果。ambiguous到期仍阻断，不重抽。
3. **三方关系与遍历置换。** 对三个可信lane/x构造逐对关系，覆盖上文三车代数反例，断言无严格优先环；同lane不可比链不被排序“等价”传播。assessment使用同一物理集合的全部6种邻车顺序，归约结果相同。
4. **已进入/向内/占据先行。** 让低车道peer的车身先碰入目标带，ego位于上方；仍须yield_entered。再用阈值上下的向内速度覆盖原inward规则，保留原occupied夹具；新增lane优先不得抢过任一原硬让行分支。
5. **车道归属不可信。** 覆盖等距中心、跨source strip、缺失边界以及peer所在x处已无该lane的几何。禁止用最近中心的较低y回退或数组序号获得ego放行；可重建目标而source不可信时保守ambiguous，目标不可重建时仍拒绝。
6. **未请求前导/上方后车边界。** 使用真实decide输入：本车具备原慢前导动机，优先peer无自身换道动机或低于5且不提交。same-lane前导与upper-lane后车分别持续可见时，本车继续等待；超过私有期限也不放行。这是应记录的已知false-yield，不能写成通过了有限时间通行。
7. **标签、顺序与隐藏内容变异。** 改track_id、反转邻车和道路折线输入次序、整体平移x/y；可信几何下reason、动作、抽样次数及deadline相同，平移后的物理签名按对应坐标比较。只改仿真层标签/隐藏plan/车型真值而保持观测物理量相同时，本车输出不变；不要把真值加入控制器输入来测试。
8. **控制路径回归。** PREPARE前ego清晰优先，下一拍出现已进入peer时必须撤销准备；原candidate guard拒绝不能被优先权覆盖；低于5不产生新plan；已有deadline/UNKNOWN遵循旧规则；新硬让行reason必须确实导致blocking。形成层在R5 episode期间仍抑制增量。已提交plan继续原绕过路径，不把该测试写成重新仲裁。

每车记录：第一次参考候选、稳定参考、实际形成增量及守卫结果、连续位置/速度残差、原离线形成判定及首次/持续时间；另记录R5评估、plan提交/完成、低于5区间和UNKNOWN。检验“先有A作为无前参考队头，B/C何时稳定跟随”发生与否，不强制宣称B先于C。

**归因边界：** 此场景没有预设慢前导或本车道终止动机，R5很可能始终未激活；若两个版本完全相同，结果只能说明B1在这个三车物理链中的表现。它是低成本逐车形成诊断，不能替代原固定competing等活跃R5场景，也不能据它宣称lane-first改善。现有道路只终止上方车道，恰好三个物理actor不足以自然复刻“两个外侧受控候选各有一个独立慢前导”的原四车竞争夹具。若要同时测试三车候选排序与实际通行，须另行预登记匹配动机的场景，不能偷偷放宽动机、添加控制器意图输入或修改安全门槛。

## 验收建议

先确认8项受影响测试及旧受影响回归，再用原冻结活跃竞争案例检查新规则；三车形成诊断独立列示。报告必须把“lane比较已消歧”“候选guard通过”“plan实际提交”“物理完成”“B1稳定参考”“原离线形成达标”逐层分开。保留未请求优先车造成的等待、低速与未完成。阶段5科学门槛不能因静态关系无环或换道次数改变而自动通过。
