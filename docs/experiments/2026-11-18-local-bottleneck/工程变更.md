# 本轮工程变更

根入口默认实时 SUMO，四项常用参数在文件顶部，镜头由用户手动平移和缩放。实验物理、车辆类型和来车过程仍在同一个原生运行器中维护。

缩道信息有两层。车辆感知窗口仍覆盖前 200 米、后 100 米的实车。物理终止位置只有进入道路观察视距后才通过适配层送入分布式控制器。其他车辆的动作只能通过已经发生的横向运动观察。对照中的普通 NOA 仍按原规则做主动超车和必要合流。

编队车获知退道任务后，记住本车的目标道。当目标走廊挡住横移时，纵向速度继续跟随当前实际前车；走廊检查通过并发出请求后，才用目标道实际前车作为纵向参考。下一步视野和安全检查仍会生效。中道使用原有真实交错空位规则。

旧版验收代码和有独立科研用途的文件继续随各阶段版本保存。当前入口中移除了重复的配置对象、无调用者的主动超车开关和重复计算的阶段条件。最新规则详情参见 [代码阅读](代码阅读.md)。
