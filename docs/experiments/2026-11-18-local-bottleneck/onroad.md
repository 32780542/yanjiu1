# 交错编队、纯 NOA 和 Cai 普通 HDV 的路内行程时间

每辆车实际进入上游道路时开始计时，驶出下游道路时结束。车辆已经上路后，在瓶颈处减速或停车都计入行程。逐车用时直接取 SUMO 的实际驶出时刻 `arrival` 减实际入场时刻 `depart`，并与该车的 `duration` 核对。

## 三种方法在同一条路上的结果

每次来车 600 秒，之后继续仿真到全部车辆驶出。道路长 1200 米，前 1000 米三车道，后 200 米两车道。三组共用 SUMO 1.27.1、33.3 m/s 车速上限、28.8 m/s 入场速度，以及同一批车辆的来车时刻和起始车道。普通 HDV 采用本机 Cai MATLAB 工程的普通车型参数和原生跟驰、换道模式。交错编队和纯 NOA 共用项目的车辆物理参数。

| 需求（辆/h/道） | 每种方法实际车辆数 | 交错编队（秒/车） | 纯 NOA（秒/车） | Cai 普通 HDV（秒/车） | 编队较 NOA 缩短 | 编队较 HDV 缩短 |
|---:|---:|---:|---:|---:|---:|---:|
| 1500 | 3750 | 40.27 | 43.46 | 60.03 | 7.34% | 32.92% |
| 1750 | 4384 | 41.03 | 46.00 | 109.65 | 10.80% | 62.58% |
| 2000 | 5035 | 43.10 | 51.80 | 161.00 | 16.80% | 73.23% |

每档重跑五个种子（311–315）。主表将五次运行中所有实际入场车辆的路内时间相加，除以这些车辆的总数，每辆车权重相同。三档流量各自的五次运行中，交错编队均比同种子的纯 NOA 用时短。2000 档，交错编队比纯 NOA 平均少用 8.70 秒。这两组的差值反映启用编队后的变化。与 HDV 的差值还包含普通人驾跟驰与换道行为的差别。

若要看整批车辆，从第一辆实际入场到最后一辆驶出的时长如下。表内是五次运行的等权均值。

| 需求（辆/h/道） | 交错编队（秒/批） | 纯 NOA（秒/批） | Cai 普通 HDV（秒/批） |
|---:|---:|---:|---:|
| 1500 | 638.46 | 647.26 | 688.34 |
| 1750 | 641.32 | 654.08 | 783.66 |
| 2000 | 646.74 | 661.76 | 905.94 |

### 只取前 600 秒已经上路的车辆

按 `0 ≤ depart < 600` 选车，然后一直跟踪到每辆车驶出。每格依次列出实际入场车辆数和它们的平均路内时间。

| 需求（辆/h/道） | 交错编队（辆 / 秒） | 纯 NOA（辆 / 秒） | Cai 普通 HDV（辆 / 秒） |
|---:|---:|---:|---:|
| 1500 | 3750 / 40.27 | 3750 / 43.46 | 3745 / 59.94 |
| 1750 | 4383 / 41.03 | 4383 / 46.00 | 4333 / 109.45 |
| 2000 | 5034 / 43.10 | 5034 / 51.80 | 4673 / 162.17 |

2000 档中，前 600 秒已经上路的 HDV 有 4673 辆，它们上路后平均走了 162.17 秒。算上后来实际入场的车辆，5035 辆 HDV 的平均路内时间为 161.00 秒。两行数字的差别来自所选车辆。上一轮报告另列的 160.75 秒则是先求每个种子的路内均值，再把五个种子等权平均。[两种平均方式的精确数值](stage/onroad/summary.csv)

## 数据与复跑

同路三组重新运行 45 次，原环境参照另运行 15 次。全部车辆均已驶出，每次运行的碰撞记录及遥移数均为零。共保留 52,676 条逐车入场与离场记录，其中同路比较 39,507 条。表格中的行程由本轮生成的 `tripinfo` 逐条计算。

- [Excel 表格](stage/onroad/路内行程对照.xlsx)含三种方法的主表、前 600 秒入场子样本、原环境参照和逐种子记录。
- [逐次统计](stage/onroad/cases.csv)含每次实测车数、总路内用时、平均行程、最早入场与最晚驶出时刻。
- [逐车记录](stage/onroad/trips.csv.gz)按方案、流量、种子和车辆编号列出实际入场时刻、实际驶出时刻和路内行程，所有时刻单位均为秒。

在项目根目录运行以下命令。每次复跑使用新的批次和报告目录。

```powershell

python -B scripts/run_logged.py --label onroad-repeat --timeout 5400 -- python -B "$study/run_onroad.py" tmp/onroad_repeat --original-hdv --matlab-data D:/matlab_huipu_2000/traci_tls/data --legacy-sumo-home 'C:/Program Files (x86)/DLR/Sumo'
python -B "$study/summarize_onroad.py" tmp/onroad_repeat tmp/onroad_report_repeat --with-matlab
```

只跑同路三组时，第一条 Python 命令省略两个 MATLAB 原环境路径，第二条省略 `--with-matlab`。
