# 仅凭局部感知的缩道变换

## 研究问题

在相同三道来车、1000 米处减至两道、1200 米出口的条件下，测量纯 NOA 的瓶颈排队和编队提前接续带来的差异。普通 NOA 保留真实前车跟驰、受阻主动超车、安全并入。每辆车读取本车状态、有限局部观测和自身记忆。任何来自论文的车辆参数先用于共同物理条件，独立报告改变参数后的效果。

## 比较顺序

1. 复算 C12 的 200 米默认直接感知和 300、500、600 米公开预告的已有同种子数据，分别记录速度、停车、入口等待和完成率。
2. 200 米是当前默认直接感知。无公共预告的较短道路可见范围 75、100、150 米仅用于敏感性试验。三档采用 1500、1750、2000 辆/h/道、seed211 和 212、600 秒来车。只改变道路终点可用距离，邻车前200后100米、反应式NOA、入口和制动保持共同。
3. 独立复核 MATLAB 原始实现及输出。分别分析旧 SUMO 内部汇合、物理终止道和直路，保持来车日程；再测试普通车型参数作为本项目两组共同执行条件。
4. 优先根据同条件开发轨迹查找局部变换损失，单规则试验后再冻结。独立于开发种子的验证同时记录完整两道交错和持续车流，累积每车低速、末道停车、合流位置及配对时间。
5. 将默认直接感知、可选公告和邻车感知写清楚。清理现用入口中可证明冗余的代码和既有审计确认可重建的残留。保留旧验收复现入口、最新工作改动和原始研究数据，验证接口和行为后再发布。

Cai 2024 的速度图单独对照。已发表集中式结果、当地 MATLAB 交通仿真和本项目的同输入对照分别列出。要得到精确排序，各方案须面对相同车辆、来车序列、路网、指标与可用信息。
