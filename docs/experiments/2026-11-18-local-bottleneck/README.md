# 局部感知下的缩道排队与交错变换

在三道缩为两道时，纯 NOA 依然会主动超车，也会在实际间隙不足时等在终止道。当前编队用交错位置、相邻道路腾位和时距跟驰组织合流。默认道路信息在 200 米内取得，车辆只收到本车附近的物理观测，无需公共预告或车间通信。

## 普通车辆为何会排队

MATLAB 普通 HDV 上路后使用 SUMO 默认主动换道。三条道的车辆在瓶颈处合到两条道，接收车道的实际空隙和出流能力决定排队。用相同的 781 个请求重跑，前 600 秒原地路网完成 593 辆，物理终止道完成 581 辆，直路完成 740 辆。两个缩道工况约 77% 的低速车秒集中在接收道。旧版和新版 SUMO 在同一路网、同类型和 33.3 m/s 上限下有明显行为差异，见单独的版本与限速对照。

本项目的 1500 辆/h/道纯 NOA 在直路上没有低速积聚，缩道后瓶颈区域低速暴露平均 1117.50 车辆秒，终止道停车暴露平均 597.72 车辆秒。现有 NOA 没有附加入口门，纯 NOA 仍正常主动超车。共同移植较大的 SUMO IDM 跟驰时距、更大静止间隙和更慢加速会使两种控制均变慢；在 2000 时，编队虽减少瓶颈区域延误，全程平均行程优势消失。相关结果作为物理敏感性保留。 [共同物理试验](shared_physics.md)

## 仅直接感知的距离试验

200 米是原有默认直接感知。为测直接观测较晚会发生什么，在两组都无公开预告时，把道路有效可见距离设为 75、100、150 米，保持邻车前 200 米、后 100 米。每组为相同种子 211、212、600 秒来车。36 例全部安全排空，54 个配对经原封存方法复核。

| 流量（辆/h/道） | 75 m 纯 NOA / 编队（s） | 100 m 纯 NOA / 编队（s） | 150 m 纯 NOA / 编队（s） |
|---:|---:|---:|---:|
| 1500 | 46.47 / 41.29 | 44.81 / 41.01 | 44.66 / 40.89 |
| 1750 | 52.12 / 42.80 | 49.90 / 42.01 | 48.03 / 41.52 |
| 2000 | 63.87 / 56.62 | 63.39 / 52.81 | 59.71 / 51.78 |

较短距离在高流量下增加纯 NOA 的通行时间，也增加编队自己的时间。1500 档的 NOA 时间没有随距离单调变化。保留 200 米默认，各组采用相同道路信息。 [逐种子和指标](stage/visibility/) · [上一轮 300、500、600 米公共预告](../2026-11-04-public-preview/README.md)

## 当前规则改动

终止道车辆等安全空隙时继续跟随本车道实际前车。获得可执行空隙后再以目标道前车作纵向参考。该变化保留原有邻道接收、真实空位、共同安全检查和已下发动作的继续执行。规则对普通 NOA 的纵向和主动换道行为没有改动。

开发使用 211、212 两个种子。冻结后用 213–215 独立确认。表中是五个种子等权的系统时间，从来车请求计算到驶出。并排消融只把跨道半间距改为零，其他规则相同。

|---:|---:|---:|---:|---:|
| 1500 | 44.754 | 40.603 | 40.567 | 41.506 |
| 1750 | 48.008 | 41.471 | 41.175 | 42.474 |
| 2000 | 55.895 | 46.222 | 43.788 | 46.414 |

| 流量（辆/h/道） | 纯 NOA → 当前低速车秒 | 纯 NOA → 当前末道停车车秒 | 纯 NOA → 当前瓶颈流量（辆/h） | 纯 NOA → 当前油耗（g/km） |
|---:|---:|---:|---:|---:|
| 1500 | 1117.50 → 30.62 | 597.72 → 21.76 | 4596.48 → 4608.00 | 72.45 → 74.58 |

低速和断面流量按 100–600 秒的固定窗口。末道停车在 900–1000 米范围内按全程采样。2000 档当前方法相对原 C12，平均系统时间少 2.434 秒，断面出流多 64.8 辆/h，区域低速减少 473.30 车辆秒。同档终止道停车比原 C12 多 53.20 车辆秒，各指标分别如实报告。新旧对照在三个独立种子中，2000 档的系统时间分别少 1.596、1.140、2.291 秒。1500 档三种子里仅一个比原 C12 更快。

队形另用两组 45 车初态验证。出口延长到 3600 米，只用于观测队形。当前规则在 70.0 秒和 64.7 秒分别首次恢复全体两道交错，每组共完成 22 次横移。随机来车下本车关系参与率的五种子均值为 97.65%、98.66%、99.13%，平均连续参与时长为 39.01、40.06、42.98 秒。这是本车 0/1 关系统计，全体交错由实际轨迹检验。 [同源配对、消融和指标原表](stage/local_merge/)

## 集中式参考和论文结果

本机简化集中式参考用全部车辆的状态做 5 秒周期的目标分配，再由相同 SUMO 运行器执行。两个配对种子下，2000 档简化集中式、原 C12、纯 NOA 平均系统时间为 43.136、47.823、56.477 秒。1500 和 1750 档原 C12 更快。该实现省略论文的路径规划、冲突消解和最优轨迹求解。 [本机简化集中式对照](stage/global/README.md)

Cai 等 2024 的图 5(b) 可核实全 HDV 出现低速带、全 CAV 集中编队明显缓解。它采用不同的车辆模型、仿真版本和参考组。全路行程时间、吞吐和油耗的可配对数值未公布。同作者早期预印本的 1500 工况图上约为集中编队 42 秒，对照 73–74 秒，属于该版自己的条件。可比较机制与瓶颈位置，目前精确效率排序来自本机同输入实验。 [IEEE 2024](https://doi.org/10.1109/IV55156.2024.10588701) · [相关预印本原图](https://arxiv.org/pdf/2103.10287v3#page=10)

## 普通 NOA 的并入调速

本轮也改进了普通 NOA。终止道在视野内、当下空隙还不满足换道条件时，车可以降低速度与目标道真正的前车对齐。没有目标道前车，或该调速会超过本车道跟驰的速度请求时，维持原跟驰。此时仍等待真实安全空隙，车辆不会因这条规则成为编队成员。

独立种子 213–215 的九个配对全部安全排空。新版纯 NOA 在三个流量下平均系统时间分别为 43.962、45.987、53.290 秒，原纯 NOA 为 44.574、48.128、55.508 秒，当前交错编队为 40.668、41.205、43.479 秒。可见空隙调速改善纯 NOA 后，编队在九个配对中仍全部更快。低速与制动的细项另见该阶段配对报告。

共同 IDM 参数下的中道清空试验表明，取消提前接收能提高部分工况的中道断面出流，但也延长末道等待。在原物理设置中，仅对实际接收关系使用低速交错接入距离的候选，六个开发对照只有一例系统时间改善，两例持平，当前规则继续采用原接入距离。 [共同物理下的接收关系](shared_physics_receiving.md) · [接入距离六例](stage/actual_receiver_spacing.json)
