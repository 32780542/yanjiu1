# 简化集中式参考的同输入比较

参考模式读取完整实车状态，以纵向相邻间隔 50 m 分组，每 5 s 生成交错目标并做最小成本联合分配。组首距缩道点 360 m 时切换为两道目标，公共速度反馈、净空检测和 SUMO 完成执行。该实现采用 Cai 式组内目标分配，省略论文的多阶段最优轨迹求解。它是本机参考，比较结果仅适用于这个实现。 [参考实现](../../../../../variants/phase5g_pure_formation/experiments/global_reference.py)

采用历史 C12_200 冻结入口的同一组十个执行文件，在 SUMO 1.27.1 下运行 `global`。IDM 的静止净距 1.5 m、时距 0.2 s、加速度上限 5 m/s²。0–1000 m 为三道，1000–1200 m 为两道。每道 1500、1750、2000 辆/h 分别请求 600 s，种子 211、212，排空截止 1200 s。逐例核对了与历史普通 NOA 和 C12 编队变换相同的请求序列、vType、路网生成输入、SUMO 版本和执行边界。六个参考案例共 5343 辆，全部完成，最晚于 642.9 s 排空，零碰撞、零瞬移。18 个案例均通过配对资格审计。 [逐例数据](cases.csv) · [审计](audit.json) · [历史逐例报告](../../../2026-11-04-timegap-staggered/data/formal600_main/per_case.csv)
