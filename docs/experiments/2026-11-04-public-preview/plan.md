# 公共预警距离与局部变换

- 复用 C12 冻结源和运行器，先完成 500、600 米预警的 24 个开发案例。预警对所有驾驶方式一致，车流为 1500、1750、2000 辆/h/道，600 秒来车。用 211–215 五个种子把两档预警与上一轮相同条件的 300 米结果配对。
- 检验两个变换规则。L1 仅在本车需要退道、选到虚拟前车或正在横移时切换纵向接入。L2 在此基础上只将一个接入间距内的邻道实车提前当作前车。这两个改动分别检验预警过早关闭普通调距和过早接收远处车辆。
- 先比较 201、202 的系统时间、停车与油耗。与同预警 C12 比较，再对有改善的候选做 211–215 独立确认。采用条件为完成全部对照、系统时间改善且瓶颈过程能解释差值。确认也要覆盖原 200 米场景及固定车群，作为是否替换默认规则的依据。
- 保存原始配对、失败、参数及候选规则。用阶段报告说明取舍，17:30 收口。

开发组的 2000 流量两种子中，600 米比 500 米有更多车在 500 米位置之前完成并入，也有更多车到 900 米之后才完成并入。L3 以 L1 为起点。公共预警阶段只有当目标车道存在符合时距的空位时，才因预警发起提前合流。距终点 200 米以内恢复必要合流。前车实际横移引导和本车已提交动作继续执行。按原两种子和两档预警测试，记录早期和末端并入。

L1 的六组开发均值均增加系统时间。L4 将提前空位规则直接用于 C12，单独检验合流时机。L4 与 L3 只差普通跟驰切换，与 C12 只差提前空位条件。独立确认优先采用开发中改善系统时间的预警组合，并保留其余预警条件下的相对结果。高流量持续对照用 221、222 两个种子和 1800 秒来车。

L4 在两档预警下均未恢复固定45车交错。L5 检验缩道点后的实际后车关系。L6 回到提前合流的触发条件，允许可见前方开阔的头车先行，现有空位和安全检查继续适用。L6 通过两档固定车群后冻结，再用 211–215 做 300、500、600 米共45例随机车流，与同预警 C12、L4、NOA 分别配对。追加两档高流量持续4例，与同种子原方案配对。高流量500/600还增加200米真实前车跟驰的NOA对照，检查结果对单车跟驰基线的敏感性。
