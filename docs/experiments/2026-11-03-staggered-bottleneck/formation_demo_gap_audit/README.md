# J2长下游局部缺口：真实跨道层只读核查

本轮未启动仿真、未实现规则、未改原报告或旧封包。这里仅核对父任务提出的几何witness，不新增形成评价器或“全24辆必须连成一队”的要求。两个局部编队之间两道共同空白，可以是合法边界；单凭大同道前距不能断言形成失败。

ego→实际同道front为`unformed_l2_r05`→`unformed_l2_r06`，真实车头前距58.792395404m，满足此次待研究范围50<gap≤60。实际邻道中间车`unformed_l0_r05`位于ego.x与front.x之间，距ego43.854111732m；按给定式`(c.x+phi(c)-phi(ego))−(front.x−30)`，残差+0.061716328m，满足给定绝对值≤2m。**因此该具体缺口有实际witness，不是两道共同空白的局部编队边界。**

q序列局部为1688.938954(邻道车l1_r06)、1689.374146(ego)、1718.228258(邻道中间层l0_r05)、1748.166542(front)、1748.190931(邻道车l0_r06)。只有q≈1718层缺少ego同道的对应车；原最近邻l1_r06与ego属于q≈1689的已配对层，不能将该最近邻误当中间witness。所有13辆实际邻道车均在[候选表](J2_24_t52p8_all_adjacent_candidates.csv)，未只输出命中者。

这里只证明现存几何占用与指定witness条件成立。该front距ego58.792m，在原CTH跟驰的50m范围外；不能由本离线表直接宣称原控制器已知它，也不能自动获得新感知/通信权限。此处没有要求跨局部编队追赶，没有实现跨道桥接。
