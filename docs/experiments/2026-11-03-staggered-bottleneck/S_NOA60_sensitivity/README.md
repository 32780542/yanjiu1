# S 对 NOA60 的同输入敏感性

原NOA60长20与S31高10的30例协议均核验；只比较两档缩道、31–35种子的10对共同计划，不补造直路S样本。另从20个共同case的原input/result/trips、compact旗标及gate/region ledgers独立重构，核验全部15项主指标均值、原始差和来源/需求/参数SHA。

2250系统时间52.9391→48.5624s，改善8.2674%；2500为76.2814→67.4847s，改善11.5320%，均5/5种子。燃油差仍为+6.2546、+5.5279g/km。改善率由NOA60实际分母逐输入重算，不能把另表的约1.8%从原S改善率机械相减。正式NOA50基线和数值表不改。

NOA60为无形成模式的默认前车距离敏感性，对照不是单独形成几何的因果识别；规则源不同，需求、物理参数（含SUMO版本、duration/max_time）及非rule源码SHA逐对相同。通用wrapper表头内G0/LP0说明不参与本比较，LP0后续等价证明见其他附注。完整源、逐seed、反例和油耗均保留；本复核不重仿真。
