## 4. 主要收益确有车道负荷均衡，几何交错尚未证明

去掉补位使1100米lane0占比回到约1/3，关闭道与原中间道车辆主要压向lane1；保留补位则接近两道均衡，因此其大部分收益与一般车道负荷调节相符。关闭相位速度但保留相位坐标补位的ENP仍有明显收益，不能把所有_fill收益都命名为“交错编队特有优势”。

另一方面，2500 E/ENP的lane0总份额只差.513647个百分点，时间却差2.715633秒、低速差792.70车辆秒；在“终点总份额”之外存在时序/局部组织贡献的证据。但1100米总份额不描述何时/何处形成空隙，相位速度仍可能通过改变补位时机、局部负荷与跟驰扰动间接作用。**这不能单独证明车辆已经形成30/15米交错几何。** E的0/1参与率甚至低于ENP（2500两种子E约98.06/97.92%，ENP98.67/98.44%），更不能以参与率替代几何证据。

## 5. 当前能说什么、不能说什么

- 本轮证明的是这18个关闭试验与既有六个E等价控制中的条件差异：补位对通行很关键；相位速度在2500两个种子下都对时间/低速有增量价值，在较低档较小或不一致。没有因为关闭项更慢就自动采用一个新算法。
- E相对同跟驰NOA平均TT减少1.106603/1.108804/3.868628秒，但燃油分别增加4.158814/4.611090/1.607404g/km；原TM2500的严重恶化已由删除协作避免，内部E−ENP/E−ENF又显示保留组织项仍有贡献，两种来源不可混写。
- 不能完全排除普通负荷均衡解释，不能用0/1证明几何，不能把有限窗口通过量当容量，不能把完整区域暴露与原固定窗口混用。只试两种子/180秒；正式600秒和新种子由父任务另定。
- 按父任务最新要求，后续仅规划一个真实SUMO几何demo，等待E/ED选择后再执行；[demo计划](demo_plan.md)不恢复额外形成评价器，不编造或重排实际车辆。
