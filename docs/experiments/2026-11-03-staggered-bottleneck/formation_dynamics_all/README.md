# E/J2/L/M：取消形成时限后的真实连续几何

本补充只重读四个冻结控制器的原24/45长2400米完整轨迹，没有新增仿真、规则、形成评价器或成功时限。原报告及其0/5/10/15帧、所有封包保持不变。原始输入、速度、插入、道路条件一致；各方法以本例最后初始车辆首次实际过1000米为anchor，连续展示anchor至首辆实际退出之前的**每一帧**。该窗口全部初始车辆都仍在场，未把前车退出后的孤立车当全队完成。可接受多个有秩序的局部编队，未要求每格填满。

## 实测结论

| 控制器 | 24辆 +25 CTH误差范围(m) | 45辆 +25 CTH误差范围(m) | 限制与解释 |
|---|---:|---:|---|
| E | −0.005704…+0.002468 | 大孔最大+24.05138 | 同道误差小不单独证明跨道交错；45的大孔原样保留 |
| J2 | 最大+29.56341 | −0.012103…+0.099036 | 24原59米孔有真实邻道中间层witness，另见只读gap审计 |
| L | −0.051673…+0.011130 | −0.012103…+0.099045 | 24孔在原局部witness机制下恢复，端点多一个层可产生raw dx约45米 |
| M | −0.118692…+0.071658 | −5.59247…+5.53357 | 45残余持续存在，不能称为仅慢收敛或凭峰速较低判为振荡改善 |

以上是固定+25时刻的原始误差陈述，不是成功阈值。统一额外+20/+25共16帧均全体24/45在场、无提前退出；所有实际ID/车道/坐标/速度、真实前车及raw跨道差在CSV完整列出。连续图y轴各自缩放，请读实际刻度。

CTH前距用本车实际速度计算`D(v)=5.5+(30−5.5)/28.8*v`，真实前方车头间距减D；无前车留空。物理走廊采用原分析程序的实际y邻域，原车长、原横移均保留。相邻跨道位置差是实际最近邻的`peer.x−ego.x`，保留符号、不取模；离线几何最近邻并非控制器的q互选reference。raw signed dx的中位数会因正负数量/奇偶性接近0或±15，不能单独用作交错程度。raw约45米也可能是端点局部编队边界，不能仅据极值要求全局满格。

## M45的具体局部原因

冻结M函数、实际有限邻域和本车自身记忆独立重放，未读取邻车私有Memory。t61.6真实互选`formed_l2_r06`↔`formed_l1_r07`的raw dx为±24.703458米、q误差±9.703458米；dv/K为±5.61155米，使phase饱和增量±0.4m/s，与真实CTH增量∓0.379565/0.380410m/s几乎相抵。t66.6另一稳定互选`formed_l2_r05`↔`formed_l0_r05`的raw dx±25.031148、q误差±10.031148也有同方向冲突。这些指定极值事件及前后固定±1秒记录均保留，稳定互选不能仅解释为临时换配；另有实际换配事件也没有删去。本分析没有声称证明全局静态平衡。
