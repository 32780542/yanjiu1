# 单环节消融：定位高流量负效益

2500每道的180秒需求下，现有TM两个种子均明显慢于同跟驰NOA。因此先分别关闭四个环节，其他条件与TM完全一致，检查究竟哪些动作造成降容。这里的关闭版本仅用于因果诊断，不是提出四套新驾驶方法。

| 名称 | 唯一关闭项 | 保留内容 |
| --- | --- | --- |
| NF | 自由形成补位 | 实际前车CTH、跨道队首、变换协作与必要合流 |
| NC | 变换协作块（腾位及接收开隙） | 原形成与相位、准备区、实际间隙必要合流 |
| NP | 跨道队首的速度修正 | 原物理关系0/1报告、形成补位、协作变换 |
| NH | 中间道车辆向左腾位 | 接收开隙、形成补位与必要合流 |

命令 `python -B docs/experiments/2026-11-03-staggered-bottleneck/tools/build_ablations.py` 从Git起点177f7a3精确重建四份临时源及差异补丁。没有修改主入口或NOA、执行器、安全、需求。区分“关闭后变好”与“保留交错编队仍能提高效率”：前者用于找原因，后者还须新方法和独立验证。
