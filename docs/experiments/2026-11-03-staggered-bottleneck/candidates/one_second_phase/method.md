# Q：一秒相对位置预测

M对互选边使用 `.3e+(v_j-v_i)`，等价于以3.333秒预测误差乘.3。真实45辆变换诊断在所有车辆仍在场的+20/+25秒留下约±5.5米CTH残余，原L同期约.1米，故M未直接采用。

Q只将同一互选边反馈改为 `.3*(e+1s*(v_j-v_i))`。一秒与原横移clear的短时外推尺度一致，减少相对速度对调距的压制。真实前车CTH、L的邻道实车空位证明、互选对象和物理相位、硬安全、换道优先级、Memory都保留。它是本轮方法更新，不从PD式预先宣称交通或收敛更好。

先用固定M作为红阶段，再构建Q跑专项；交通仍从原种子1/4八例短筛开始，几何沿原24/45同输入及全部固定帧。没有据最后61–65的结果选择参数。
