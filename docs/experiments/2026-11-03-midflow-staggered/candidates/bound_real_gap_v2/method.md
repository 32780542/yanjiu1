# GP2：时域、真实pair与当前接入条件属于同一计划

## 适用范围与接口

从冻结GP独立修订；相对S仍是绑定本车真实gap的单独候选，不叠V/F/C5源码。仅transform地图准备区初次/active目的lane1调用；NOA、formation、直路及目的lane0沿用原S/GP逻辑。Memory仍只有lane_target/gap/joining，不读取邻车意图、共享分配或真实ID优先权。

局部目标走廊中每一对实际相邻、可见且有序的F/R均可成为候选。`memory.gap`绑定所选真实标签；ego尚未进入其区间不会使held失效。held只有在仍可见/相邻且至少一个允许名义时域可达时优先保持；否则重新选择。无任何名义可达双侧CTH资源，纵向、目标gap和横移判断全部回原GP/S当前gap策略，不新增等待或额外安全门槛。

## 两个有来源的名义时域与解析可达窗

地图剩余时域`Tmap=(drop_x−ego.x)/28.8−1s`，减去原横移时长。Tmap≤0不规划；否则使用去重的`min(5s,max(.1,Tmap))`及`max(.1,Tmap)`两个时域。5s沿用Cai本机阶段时长，.1s沿用SUMO步长；没有时间扫描或根据交通结果调参。

对每个时域，F/R名义恒速，u=(vF+vR)/2。记D(v)=L+s0+Hv，严格名义终点窗为

`[R.x+R.v*T+D(R.v), min(F.x+F.v*T−D(u), drop_x−u*1s)]`。

道路上界使名义终点保留按终速运动的原横移1s；全程名义v≥0使到达终点前不越过该位置。它不是滚动执行的deadline保证。

令ΔX=X−x−vT、E=u−v。双积分最小∫a²的a0=6ΔX/T²−2E/T，aT=−6ΔX/T²+4E/T，代价`J=12ΔX²/T³−12ΔX*E/T²+4E²/T`。将终点窗与a0/aT∈[−10,+5]、速度峰值∈[0,33.3]对应的解析ΔX闭区间求交，再clip无约束极小点ΔX*=ET/2。速度闭区间的独立推导是把v写成二次Bezier形式：

`v(r)=v(1−r)²+2w*r(1−r)+u*r²，w=3ΔX/T+2v−u`。

在端点速度合法时，全程速度非负当且仅当`w≥−sqrt(v*u)`；全程不超过V当且仅当`w≤V+sqrt((V−v)(V−u))`。因此无需扫描时间极值。开发测试另用实际二次速度的临界点独立核对。

选优顺序为`(不是held, T, J, 几何)`：已持pair在任一允许时域可达就继续它；新选择才先最短可行时域、再最小J。仅执行当前a0对应的下一帧速度请求，所有原物理安全和SUMO执行约束继续生效。名义可达不含对邻车未来恒速的保证，也不等于安全过滤后一定按计划到达。

## 当前CTH兼容带控制新横移接入

有名义规划资源、尚未实际启动横移时，只有ego位于所持pair当前兼容带

`R.x+D(R.v)−2m ≤ ego.x ≤ F.x−D(ego.v)+2m`

且原8m `_clear`通过，才发新横移请求。前侧用本车当前速度，后侧用实际后车当前速度，不能用gap平均速度替代。2m是原加入/成形跟踪容差，不是由本次交通结果选择的新物理阈值；应称“CTH兼容带”，不是严格CTH间距保证。同速下最多短2m对应原CTH位置项名义加速度约−1.2m/s²，而短15m对应约−9m/s²；这只是对请求公式的解释，不是实际制动保证。

有规划时，已经测得moving或收到本车own pending横移反馈，继续原已启动执行，不用新的接入带中途取消。无规划时先完整回原GP/S；其中pending尚无vy而_clear失效可能不重复发lane请求，但这不会撤销SUMO已接受的原横移。

当前窗与终点窗是两个不同对象，已在`development_witnesses.json`按同一真实pair/T列出。正式交通归因仍需在完整观测和自身Memory上逐帧重放同一确定性函数，记录pair、T、终点窗、当前带、continuing/fallback及新横移；参与flag不能替代这些证据。

## 红灯纠正、边界合同与机器舍入

初始推断“M705/R690/F770，均28.8时GP有可达资源但过早合流”是错的：GP固定Tmap≈9.243s使future low=986.2m，而road high=971.2m，实际_plan=None。该测试在错误前提处失败，日志保留，不能算admission有效红灯。真正GP已有plan却过早进入的例子是M755，front gap15m不足CTH。加入5s优先时域后，M705才有名义资源：目标g720，终点864，a0=3.6m/s²，速度峰值恰33.3m/s；GP2继续接近而不立即横移。

该M705边界还揭示机器舍入：ΔXlow=15而解析速度上界约14.999999999999988。GP2只对不超过`ulp(x+vT)`的闭区间倒置合并到较小upper，不增加可调物理容差。它处理浮点表达式舍入，不允许可观的速度/加速度/道路放松；复算仍保留原物理限速。初始严格带patch和失败日志独立保留。

开发合同覆盖：M705正相对位移、M755真实admission反例、718/719/721/742m等±2m边界、前后CTH分别使用正确速度、moving/pending继续、无资源与NOA/formation/直路/目标0精确回归、标签/排列/感知外不干扰、原安全。另1600个名义状态核对a端点、二次速度精确临界点和道路界。

## 是否可能无谓等待或回退抖动

可能。兼容带会推迟原8m条件下已经能换道的车辆，额外接近时间未必被后续扰动减少抵消；请求继续纵向接近，不等于其交通成本为零。held优先减少主动因J变化换gap，但可见性、相邻关系或可达性变化仍可每帧触发重选。没有新增hysteresis/timer，因此不宣称消除抖动。

Tmap耗尽或资源失效时会回原S，可能重新允许只满足8m的接入；GP2不是全程CTH接入不变量。无可达真实gap时它也不会凭空造gap。需要独立交通结果及真实gap/几何轨迹判断它是否值得采用，不能由合同通过推出系统收益。
