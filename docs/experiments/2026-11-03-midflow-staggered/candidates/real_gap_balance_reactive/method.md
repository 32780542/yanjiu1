# DR：去未来占用映射的单行消融

DR从锁定D1 `2be889140b497b763818a35814b0f34815c7cccd309dd5007ebaddca8a91f35a`仅删除`resource=min(resource,1) if future else resource`一行。源码422行，SHA256 `89a9299f0dd043600846f7e5d7239e68d079053a75e4d32e442f0619fbab6811`。

它保留相同receiving触发、可选实际道范围、y/vy实测运动目的道投影、局部负荷势能、真实gap、响应损失、纵向phase和所有执行/安全逻辑。接收时目标资源仍是0/1，但未横移的ending2车辆不再通过π预计入1；若测得车辆已向存续道横移，其同一运动投影仍可计入目的资源。DR并非删除全部地图感知或接收协调的控制器，也不是纯NOA。

D1与DR比较只隔离未来占用预映射。静态反例中，D1因ending需求提前释放中道，而DR在当前存续道已平衡时不作同一迁移；这不预示哪一种交通结果更优。若DR同样或更好，必须保留，不能把D1组织形状视为交通收益证据。

共同测试核验源精确为单行删除，NOA1000状态×2地图hexexact，safe/publicCF各1000一致，标签与24种排列一致；无地图formation及transform各1000状态与D1逐位一致。测试没有运行交通。
