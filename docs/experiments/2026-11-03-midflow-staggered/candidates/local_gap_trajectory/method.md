# C5：实际间隙的局部最小加速度进入

从S单独构建，不叠V或F。现有gap追踪使用0.5s响应的快速位置追赶；新候选只替换编队的gap接近/横移期间纵向请求，保留gap选择、横移触发、实际CTH、phase及物理安全。NOA逐字段保持原规则。

Cai的本机活跃程序使用5s阶段并最小化加速度平方积分；这里借用其移动端点的思路与阶段时长，不移植全局指派或求解器。令真实F/R中点或单侧目标为g，参考速度u。对本车双积分模型，在T=5s后要求x(T)=g+uT、v(T)=u，最小化积分a²，其初始加速度闭式为

`a(0) = 6(g−x)/T² + 4(u−v)/T`。

每0.1s重新观察实际gap，只执行当前初始加速度得到的速度请求；共同执行器和safe_speed继续约束。它是局部滚动端点接近，不把F/R未来恒速当事实，也没有要求邻车执行任何计划。

在当前T=5与POSITION_GAIN=.3下，夹紧前的速度增量恰为`.08[(u−v)+.3(g−x)]`，是原gap追踪`.2[(u−v)+.3(g−x)]`的0.4倍。因此当前实现也可准确描述为由5s端点解导出的较柔和gap响应，不把它包装成完整Cai多车规划。

例：本车705m、前后车730/670m，全部28.8m/s。g=700，a(0)=−1.2m/s²，本步请求28.68，替代原28.50。目标对齐且等速时a=0；存在速度差时同一端点公式同时处理位置和速度。无需额外舒适阈值、等待状态、完成期限或换道门禁。

待验证假设：较平缓的进入能否降低640m附近组织扰动、燃油与全程时间。不能只凭请求更平滑判定有效；换道后仍回到原实际CTH，必须从实际轨迹确认没有把制动推迟到横移结束后。
