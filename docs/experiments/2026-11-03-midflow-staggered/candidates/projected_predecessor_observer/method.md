# V2：按可见并入车而非观察者的位置触发预跟驰

V1的三档两种子180s筛查没有稳定收益，640–800m的速度亏损基本不减。另发现它要求接收车本身已过640m：典型并入车x642、接收后车x626时，虽可见必要合流却不投影；等后车过640，前车往往已实际占道。

V2仅删除这个观察者位置条件。可见终止车仍须在[640,1000)m、位于本车前方50m内，且比实际接收道前车更近才可能接管基础请求。地图、实际邻车、CTH、安全和全部记忆不变。它不提前终止车的换道触发，不延迟已有横移，不叠加未来资源重分配。

开发新增公开场景ego630、actual front660、终止车645、左道车645；原V1不能提前建立关系，合同按预期失败。随后在新输出路径构建V2并运行完整9项合同，其中一万局部状态对NOA/formation/硬安全逐字段比较。

V1保留原路径和原筛查。新builder先核V1 SHA后只替换一个调用条件，差异可严格反向复原。交通试验仍用同一73/74输入，独立新batch，不把V1的小幅负结果当成V2的结果。
