# GP2-G0：保留局部间隙规划的非交错对照

此为机制对照，名称与原纯NOA分开。使用GP2相同的真实间隙选择、持有、CTH兼容带、横移及实际安全；移除相邻道交错phase与自由补位，并保留普通慢前车超车。所有车辆输出formation_state=0。

采用transform运行以保留GP2执行路径，是否组织交错与是否使用局部间隙规划在本对照中分开。源只修改_decide，其余函数AST逐个相同；输入、最高/巡航速度、物理、安全和排空条件不变。NoA模式逐字段仍为原S。

它回答“GP2相对NOA的收益是否只来自间隙规划”。GP2与此对照的差别才是主动交错形成/补位在相同规划背景下的作用；若G0更快，该结果必须保留，不能把规划收益归到交错编队。无相位控制不要求任何瞬时几何绝不偶然交错，状态0表示本对照没有建立主动交错关系。
