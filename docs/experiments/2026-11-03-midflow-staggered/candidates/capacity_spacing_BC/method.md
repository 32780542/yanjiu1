# BC：同容量参考、无主动交错组织

BC是B的非主动交错匹配对照，单独命名，不等同于原纯NOA。BC从已锁定B源构建，B源码不变。

## 保留的共同背景

B与BC在缩道地图`transform`、`x<drop_x−360`处均使用1.5倍基础CTH位置参考，即`front.x−1.5*(L+s+H*v)`。直接前车仍限50m，单缺格前车关联仍可到90m，但必须满足B原式的真实、可见side-witness条件。边界之后和直路自然使用原30m巡航尺度。两者的速度松弛、位置增益、公开CF模型、实际gap选择/加入执行、8m clear与停止安全帽完全相同。

BC保留side-witness相位几何作为关联条件，不施加由相位误差产生的速度反馈。它不声称所有横向几何信息都被移除。已有active/pending横移动作和必要合流沿用真实gap执行，避免因对照切换取消已提交动作。

## 去除主动交错与普通超车

`_following`在得到共同基础CTH（含原side-witness延长关联）后直接返回，不执行互选相位速度叠加。`_decide`不发起自由`_fill`，所有模式与地图的formation_state均为0。`mode=transform`在缩道及直路均启用原NOA慢前车普通超车条件，原`mode=noa`行为逐位不变。`formation`请求也不施加phase或freefill；该模式未作为新的B匹配交通条件。

普通超车仍服从原慢前车条件、实际目标道空距、8m clear及必要合流优先。BC没有新增等待或安全门槛，也没有保证必然超车。

## 对照可解释性

BC让B的交错组织与相同容量参考背景比较，同时保留普通超车能力，避免把非交错控制器人为弱化。B−BC是完整控制策略的比较：B采用phase/freefill，BC采用非交错跟驰和普通超车。因此若出现差异，它不能单凭一个数值被归因为phase或freefill中某个单独模块；如需分开识别，仍需单独消融。扩大参考本身可能改变车辆速度、入口供给和观测到的密度，不能直接宣称总流量守恒。

静态合同只证明该对照定义按预期执行；流量、波动、旅行时间及横移动作成本须独立交通筛查。没有修改B、生产或Git状态，没有运行交通。
