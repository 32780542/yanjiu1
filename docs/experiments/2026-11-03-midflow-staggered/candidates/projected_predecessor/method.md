# V：预合流的局部前车拓扑

父版本为已验证S，8bdaa...d12f。只修改_following及其transform调用，共9行净增量。终止道车辆继续追踪实际目标道F/R空隙；接收道车把准备区内实际可见的终止道车投影到本车道，使用原50m、正纵向距离、最近前车CTH。在选择基础CTH请求时保留实际前车请求，投影计算只有请求更低时才接管。随后沿用原CTH优先phase和共同物理安全，横移与gap执行完全不变。同向phase仍可提高基础请求，最终物理safe_speed始终为硬上限。

它检验“提前建立合流后纵向关系能否减少切入后的响应扰动”。不预设更早制动一定更高效：必须测640–800m的总时间/速度损失和双方制动，防止把扰动向上游搬移。

不同于旧C/helper腾位，此法不增加任何横移或等待阶段，不指定全局head/队长，不读取邻车标志、记忆或计划。投影只在本车准备区且mode=transform时启用；形成和NOA模式逐字段保持原S。并排和后方车辆不作为投影前车。地图范围、时距、响应与安全参数均沿用原定义。
