# DP：纵向相位关闭、保留横向组织

DP从锁定D1仅将`phase_speed=max(−2,min(2,k*error))`替换为`phase_speed=0.0`。源码423行，SHA256 `cfd2ee27031dac3b0efc2ef098551131878055b2518dfa4f9264a50886b4b86f`。

真实前车CTH、互选关联和formation_state关系flag计算继续沿用D1。它仍主动执行未来资源均衡的`_fill`，保留π映射、上游接收、真实gap、安全和已有动作。没有添加普通超车。故DP必须标为“纵向相位关闭、保留横向组织”，不能标为纯NOA或非编队控制器。

D1−DP检验附加纵向交错相位反馈的作用，不能用队形图代替交通结果。若DP同样或更快，应如实报告；这意味着当前条件下尚不能证实纵向相位提供额外性能收益，而非可以强行归因于交错优势。真实gap选道及未来资源映射的作用应分别看其他消融。
