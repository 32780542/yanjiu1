## 严重程度与结论

**未发现可复现的 critical、important 或 minor 实现缺陷。** 这只表示代码符合其目前写明的名义规划与接入规则，不表示交通收益、安全不变量或交错形成收敛已经通过。下面两个场景是已声明规则的实际边界，不应伪装成需要额外补丁的 bug，也不能从后续报告中省略。

1. **短名义时域优先，不等于最早实际接入。** 源 199、219 行的顺序是 held、T、J。ego 在终止道 x680、v10；目标道四车依次为 x590/v10、x650/v20、x710/v20、x810/v20。fresh 选择后方 pair `(650,590)`、T=5，因此不发横移；当前 pair `(710,650)` 已满足当前 CTH 兼容带和原 8m `_clear`，若该 pair 已 held 则使用 T=10.111111…并立即发横移。规则实现与文档相符，但不能把选优描述为“最近 gap”“最早实际并入”或跨所有时域的最小 J。独立合同明确记录两种输出。
2. **当前 CTH 位置兼容不等于后车无需强制动。** 源 235–237 行：ego 在终止道 x730/v10，目标道 rear x709.48/v20、front x850/v28.8。GP2 有 T=8.375 的计划、原 `_clear` 为真并发 lane1 merge。若只作本刻完整插入的静态反事实，公开同一 `safe_speed` 对 rear 给出 18.1096991524m/s，低于 rear 当前 20−10×0.1=19m/s。实际横移持续时间、后续运动和安全执行可能改变该值；它不是碰撞或实际制动轨迹结果。它证明报告必须沿用“CTH 位置兼容带、名义可达”，不能升级成舒适制动或全程 CTH 保证。现 method 已明确这些限制。

## 信息、身份和闭环核对

- 383 行先把观测限制在前 200/后 100 米；新规划只使用这些本地 rows、ego、自身 gap 和公共 drop_x。F/R 来自 197–200 行实际占道走廊的有序相邻实车；没有全局车辆表、流量、邻车记忆或邻车 pending 输入。track 仅用于相等与自身 held 关联，不进入几何排序或 score。
- 与冻结 S 的 AST 比较：仅 `_join_speed`、`_decide` 改变，新增 `_gap_plan`、`_gap_clear`；原 Memory 三字段、CF、相位、fill 和 hard safe_speed 不变。局部持有真实标签不是独占预订：其他分布式车辆仍可能独立选同一 pair，不应称为共享 gap reservation。
- `_join_speed` 先重新选择/持有真实 pair 并写回 memory.gap；同帧 `_gap_clear` 在相同 ego/rows 上以该 pair 作 held 再计算。该 pair 既然已可达，held 排序使其继续被选中，接入检查不会换成另一资源。实际中间车出现会打破相邻关系，原 held 被弃用。
- 接入门禁只控制未启动的新横移。moving 或本车已经提交且接受的 pending 延续原执行；无任何名义计划时在接入带之前先回原 `_clear`，纵向也回同一 `_merge_target`。这不是全程 CTH 不变量，也没有新无资源等待模式。
- 新纵向控制只在 transform 准备区且实际目的 lane1 启用；NoA、formation、直路及 active target0 比较通过。规划成功只输出 a0 对应下一帧请求，最后 521–523 行仍接受原 hard safe_speed。它不是执行整条 cubic 的承诺，安全过滤后的真实到达时间不受名义 T 保证。

## 数学与机器边界

205–211 行的区间逐项对应终点双侧 D(v)、a0/aT∈[−10,+5]、道路终点及二次速度峰值约束。令 ΔX=X−x−vT、E=u−v，a0=6ΔX/T²−2E/T，aT=−6ΔX/T²+4E/T；J 对 ΔX 的无约束极小点为 ET/2。速度的二次 Bezier 中间控制值为 w=3ΔX/T+2v−u；在合法端点速度下，两条解析约束 w≥−sqrt(vu)、w≤V+sqrt((V−v)(V−u)) 正确。源 244 行由返回的反投影 target 复原 a0，也与该公式一致。

212–215 行只合并不超过 ulp(x+vT) 的闭区间倒置。在本地图坐标量级，它属于约 10^-13 米的算术误差修正，不是可调物理余量；确实可能落在另一约束边界的一个舍入单位之外，所以不应将浮点实现表述成实数意义上的零误差约束。其后实际速度夹紧及原硬安全仍保留。没有发现该处理造成可观的速度、加速度或道路界放松。

## 作为完整纯规则方法的判断

GP2 在定义上内在一致：它是“有限本地真实 pair → 两个确定名义时域内的有界 cubic → held/T/J 选择 → 当前同 pair 位置带及原 clearance 接入 → 逐帧重算/安全过滤 → 无资源回原规则”的单一确定性方法。没有拼入 V/F/C5 的投影或邻车角色链，也没有把离线全局评价反馈给控制。

5s 新候选时域和将既有 2m 形成容差用于 CTH 接入带，都是需要以本轮证据评估的设计选择；复用已有数值不能替代新用途的论证。ULP 合并属于实现算术边界处理。三者均写明且局部，未发现隐藏 ID 特判或专门识别测试场景的条件；但 GP→GP2 同时改变时域与接入规则，因此其整体差异不能单独归因为“CTH 门禁效果”，也不能从一两个开发 witness 推出交通优越性。
