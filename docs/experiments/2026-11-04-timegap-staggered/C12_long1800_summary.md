# C12的1800秒持续需求结果

两种道路信息范围、三档流量、种子201／202共24例均安全排空：`safe=true`、`status=drained`、`all_completed=true`，0碰撞、0teleport、0失败，形成12对可比较案例。C12的系统时间在12对中全部降低；fuel在9对中增加、3对中降低，入口等待在12对中均略增。

200 m对应直接道路感知，300 m对应提前道路警示；车辆观测仍统一为前200 m、后100 m。

NOA复用N200／N300的旧C8_relations冻结源。该源的NOA分支和参数与最终C12相同，C12修改的是非NOA的纵向关系选择与记忆。配对表中的需求、物理参数和非规则源码均一致；本报告使用已复制的消费CSV／JSON，没有重新读取轨迹或运行仿真。1800 s为持续需求时长，运行继续至排空。
