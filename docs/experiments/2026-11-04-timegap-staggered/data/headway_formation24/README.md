# 两种时距的完整形成轨迹

固定同一24辆不整齐初态，只将规则中的HEADWAY分别设为0.75 s、1.00 s，在三道直路上形成。每包包含实际输入、冻结源码、SUMO结果与完整逐步轨迹；每个压缩成员已经与原件逐字节比较。[index.json](index.json)列出包大小和真实结果。

两组均24/24安全排空，0碰撞、0瞬移、0换道；30 s和60 s时24辆均仍在场。目标同道车头间距随速度与时距变化，巡航28.8 m/s时分别为27.10和34.30米，相邻道相应错开13.55和17.15米。真实误差见[逐帧读数](../../stage/headway_formation24.md)。

这是两条固定初态形成案例，与48条持续随机交通敏感性实验分别计数。几何测试观察道路出口2400米；大流量交通比较仍采用1200米道路。
