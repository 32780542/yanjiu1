# 本轮怎样评价编队

评价分成交通效果与编队本身两部分。控制时每辆车只读取局部观测；记录和统计时可以读取全路车辆。统计结果不传回车辆控制器。

## 交通效率：整批车辆实际用了多少时间

每辆车记录三个时刻：请求发车、实际进入道路、驶出道路。三项时间分别为：

| 指标 | 计算 | 含义 |
| --- | --- | --- |
| 系统时间 | 驶出−请求 | 一辆请求车辆从产生到完成行程的总时间，是主指标 |
| 路内旅行时间 | 驶出−进入 | 车辆实际在道路内行驶的时间 |
| 入口等待 | 进入−请求 | SUMO原生插入尚未完成的时间 |

三项对同一批请求车辆取平均，因此平均系统时间等于平均入口等待加平均路内时间。程序没有额外的Python入口限流。实际插入仍遵循共同的车辆尺寸与SUMO规则；统计入口等待能检查路内收益是否被上游排队抵消。

完整比较使用整批请求车辆排空后的结果。到时限仍有车未完成时，保留完成数、剩余数及已完成子集的描述值，整批平均指标留空。这样不会把仍在排队的车辆漏掉。

正式持续来车试验还使用原有100–600秒固定窗口，记录1000米断面的通过流量，以及瓶颈上游800–1000米区域的车辆数、平均速度和低速暴露。区域低速沿用速度小于5 m/s的定义，低速车辆秒为每步低速人数乘该步时长后累加。短筛只来车180秒，固定窗口未覆盖完整时，不把部分轨迹当作正式稳态结果。`exit_flow_veh_h`统计来车持续时间内已经驶出1200米出口的车辆；它与1000米断面的固定窗流量分列。

## 油耗：相同行驶距离消耗多少燃油

所有车辆使用相同的`HBEFA3/PC_G_EU4`模型。每步读取燃油消耗率，乘0.1秒得到该步燃油量，再对全部车辆累计。TraCI返回的单位为mg/s，步长积分方式见[SUMO官方文档](https://sumo.dlr.de/docs/TraCI/Vehicle_Value_Retrieval.html)。

油耗率为总燃油量除以总行驶距离，单位g/km；数值上等于总mg除以总m。它表示模型下的单位里程消耗。与NOA比较时，车种、燃油模型、道路、需求与种子一致。时间改善与油耗变化分别报告，不把二者合成一个人为权重分数。

## 编队参与规模：直接统计车辆自己输出的0/1

每辆车每步输出一个状态。0表示没有建立编队关系；1表示已建立真实跟驰、互选错位或变换接收关系，仍可以处于调距过程。仅NOA方案始终输出0。

令当前道路上的车辆数为N，状态1的车辆数为N₁。直接统计：

- 瞬时参与规模：N₁；平均参与规模是N₁随时间的平均值；峰值是观察期内最大的N₁。
- 参与率：所有状态1的车辆时间，除以所有在场车辆时间。它按车辆在道路上的实际停留时间加权。
- 连续参与时长：同一辆车状态连续为1的时长，直到状态变0或离场；报告平均值和最大值。

这些指标直接使用车辆输出，不另设距离、持续十秒或组件合并条件。连续为1表示本车一直持有某种编队关系；关系对象可以在过程中改变。平均参与规模统计全路参与车辆，不冒称这些车属于同一个大编队。

## 真实队形：车辆是否真的交错、间距是否恢复

24车形成与45车变换演示直接检查实际位置和速度。车头间距目标为`D(v)=5.5+0.85v`，不是固定30米。

1. 同道最近前后车：实际车头距离减去后车的D，报告平均绝对误差和最大间隙。
2. 相邻道互选车辆：根据两车平均速度计算半D错位，检查实际相位误差。
3. 两道实际纵序：把所有车辆按真实纵向位置排序，检查相邻车辆是否交替占道0/1，并报告实际纵距相对半D的误差。
4. 同时列出在场数、已经离场数、横移数。几何恢复用全体车辆仍在场时的结果，不靠先驶出一批车得到整齐截图。

局部互选相位误差与全体纵序同时使用。局部误差很小，也可能有两个相距很远的小团；最大同道间隙和全体排序能直接看出这件事。用户已取消形成期限和保持期，本轮报告实际恢复时刻及实际观察到的保持过程，不再使用“最后发车后30秒、保持10秒”的门槛。

## 变换过程：是否减少末端等待和反复横移

从原生轨迹记录实际换道请求、严格完成时刻、完成位置、每车完成次数和反向往返。必要退道与普通补位分开查看。单向收缩规则的实际检查是每次完成均为2→1或1→0，每车最多两次。

末端停止描述沿用本轮短筛的定义：车辆位于900–1000米、仍居终止道中心附近，速度低于0.1 m/s。停止车辆数与停止车辆秒同时报告；它描述末端等待，不能代替全路系统时间。若终止道停车少了，而系统时间增加，说明重排代价抵消了末端收益。

## 怎样判断收益来自形成还是缩道变换

相同流量和种子分别运行三道直路、三道变两道。先在每条道路内计算“编队−NOA”，再计算：

`道路附加效应 = 缩道上的差值 − 直路上的差值`。

负值表示编队在缩道中还有额外的时间改善。直路上的改善保留为一般形成、追赶和队形组织效果，不全部写成瓶颈疏解。先逐种子计算，再对种子等权取平均，同时保留每个反例。

200米直接可见与300米公共警示分别比较；两方案在同一情形中获得相同道路信息。300米只改变道路预告时刻，车辆视野始终为前200米、后100米。
