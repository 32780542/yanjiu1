# 理想固定前驱模型的速度扰动传播

图直接计算[理论文](../../理论性质与稳定性边界.md)推导的H(z)，采样周期0.1 s、位置增益0.3、每步松弛0.2，零初始扰动。固定距离在与h=.85相同的巡航平衡29.98 m处展开，目标对速度的导数为0；固定时距使用D(v)=5.5+.85v。两者均为固定前驱、同质、无切换、无约束激活且命令准确执行的模型。

固定距离最大幅值约1.1047，出现在约0.085 Hz；时距曲线在非零频率小于1，两者直流增益均为1。这解释的是该理想链的扰动传播，不是SUMO完整混合控制器的稳定性测试。实际形成、接收和切换另由轨迹与交通试验报告。

数值见[frequency_response.csv](frequency_response.csv)；PNG为300 dpi，另有矢量SVG。用[plot_ctg_response.py](../../tools/plot_ctg_response.py)可复算，工具不读取实验结果或修改控制器。
