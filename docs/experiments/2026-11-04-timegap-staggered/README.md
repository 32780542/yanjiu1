# 时距交错形成与局部变换：11月4日研究入口

本轮从已保存的D1版本重新研究，按用户要求持续到2026年11月4日08:00。研究分支为`research/20261104-timegap-staggered`，工作目录为`D:/yanjiu1/keyan1`。本页随实际结果更新；正式确认种子211–215尚未启用。

## 这次改变了什么

同道车头间距改为`D(v)=5.5+0.85v`米，相邻道错开`D(v)/2`。0.85秒是原30米巡航间距所对应时距的两位小数取值：在28.8 m/s时得到29.98米，保持原队形尺度，也使低速队形随速度收缩。这个取值不是经过优化得出的最优参数。

取消D1的未来负荷平方和与响应代价组合。新方法直接围绕实际前车、可用编队空位及三道变两道的接收关系展开。纯NOA保留普通跟驰、受阻超车与当前合流间隙接受，不提前追踪间隙中点。两种方法使用相同车辆、速度、刹车、原生入口、SUMO执行和安全走廊。

分别测试本车看到前200米内瓶颈、所有车辆提前300米获得道路警示两种情形。车辆感知仍为前200米、后100米；300米警示只增加道路知识，不增加邻车可见范围。编队后车只能依据前车实际横移和几何变化响应，不读取前车的私有编队状态。

## 已得到的结果

| 原型 | 主要变化 | 实际结果 |
| --- | --- | --- |
| A | 按物理前驱串成两道反相链 | 24例均安全排空；中高流量重排代价过大，反复换道，未采用 |
| B | 三车单元按α/β交替展开 | 12例中6例未排空；硬角色目标使下游回等上游，未采用 |
| C | 可执行前向虚拟跟驰，真实F−D空位接续 | 12例均安全排空，缩道系统时间较反应式NOA减少5.25–8.61秒；仍更费油，交错几何未完全恢复，继续修改 |

C200的直路对照12例也已完成。1500/1750/2000流量下，直路系统时间分别减少3.44/2.67/1.92秒；扣除这部分后，缩道附加改善分别为1.83/2.71/5.84秒。六个开发种子的附加差值均为改善方向。这是场景配对结果，不能代替交错结构验收。

C的45车演示在13.5秒完成全部必要退道，21次换道无人重复，无50米以上同道大孔；60秒仍45车完整在场。然而真实纵向车道交替只有42/44，半交错间距平均绝对误差4.71米。24车直路也出现相位反馈被外层跟驰上限裁掉的问题。因此正在单独建立C2，恢复原完整相位反馈，并删除原终止道车辆永久禁止再形成换道的多余限制。

02:15更新：C2已恢复完整24车形成和45车变换，后者在60–67.5秒全部在场并保持100%交替；但54次换道、最多一车10次。C3的临时横移等待没有解决往返，C4的半距硬上界将换道降至32次，却也挡住一次最终有效补位，45车离场前仍未完全交替。C4在1750流量还比NOA更慢，未采用。

下一步先纠正道路信息语义：普通形成换道也可能是2→1，不能把一次横移永久视作第三车道消失。新C5将道路知识与实际运动接收分开，保留只凭前车真实动作跟随的能力。正式确认仍未运行，当前没有选定最终规则。
