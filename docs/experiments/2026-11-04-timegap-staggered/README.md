## 当前方法

车辆根据前200米、后100米内各车道实车形成关系。同道目标为 `D(v)=5.5+0.85v` 米，相邻道错开半D。0.85秒是原30米巡航间距对应时距的两位小数取值；28.8 m/s时得到29.98米与14.99米。它保留原队形尺度，速度降低时队形随之收缩。

形成阶段以真实前车跟驰和相邻道互选相位调整速度。普通纵向链在50米内建立，已有链可在200米内继续跟当前真实前车；切入或离开导致前驱更换时接续新前车，无实际前车时释放。缩道时，以严格前方的实车建立接收关系，终止道2→1，中道按真实编队空位1→0。所有横移朝存续方向，每车至多两次；自身只记目标道和当前前驱，空位锚车优先。D1的负荷平方和、响应代价与全路分层均已去除。

详细条件与所有函数见 [逐条规则](规则逐条说明.md)，整体执行见 [系统说明](../../原生SUMO编队变换系统说明.md)。旧D1保留在Git历史和[11月3日报告](../2026-11-03-midflow-staggered/README.md)，不与本轮数字合并。

## 形成几何、单车跟驰与速度上限的补充检验

匹配并排只把相邻道相位改为0，保持相同纵向关系、收缩方向、安全、入口和速度。新增45例全部安全排空。30个缩道配对中，交错22次、并排8次更快；六格“并排−交错”的系统时间差在−0.304至+0.290秒之间。高流量均值并排略快，因此目前交通收益不能主要归给半D几何。正式交错仍作为研究方法，匹配并排用于辨别收益来源，详见[并排结果](formal600_parallel_summary.md)。

为了检验基线跟驰范围的影响，另将单车NOA的真实前车跟驰范围从50米扩到200米，保持无编队链、无虚拟接收和状态0。新增45例全部安全排空；C12在27/30个缩道配对更快，2000流量下200/300米信息分别省8.44/9.00秒，六格平均油耗都更低。直路C12反而慢3.56–4.09秒。低流量300米条件保留3个时间反例，不删掉它们。见[扩展NOA完整结果](posthoc_NOAfront200_summary.md)。

共同指令速度上限28.8 m/s检验使用201/202，而正式主试验为211–215。该组36例均安全排空，12/12缩道配对中C12更快，六格平均省1.56–6.75秒；直路慢0.29–0.47秒，六格平均道路差中差均为负。它说明提前接收和变换的收益可在共同巡航上限下出现。不同种子组不用于计算“取消33.3 m/s上限后少了多少收益”。油耗有升有降，详见[共同上限完整结果](posthoc_speedcap288_summary.md)。

连续1800秒来车24例也全部安全排空，12个缩道配对均更快，六格平均系统时间减少8.77%–17.37%，六格平均油耗均增加。此组没有对应1800秒直路，不补造长时道路差中差。见[持续交通结果](C12_long1800_summary.md)。

时距敏感性只把h改为0.75 s或1.0 s，NOA与编队在各组共用同一h。48例全部安全排空，12个缩道T−NOA配对全部更快；从0.75提高到1.0 s，编队在三档缩道流量下的系统时间却分别增加0.96、2.61、16.87秒，油耗也增加。因此相对基线的收益和参数本身的绝对代价分开报告，主h=.85保持原队形尺度，不据此重选。完整四指标、直路、道路差中差及0/1结果见[时距结果](posthoc_headway_summary.md)。同一24车初态的两种h形成试验还验证，目标D与半D确实随时距变化；60秒时同道与相位误差均很小，见[两条形成读数](stage/headway_formation24.md)。
