# h=.75与1.00的固定24车形成读数

只读取两个已完成的单案例：`20261104_h075_24_straight_geometry`和`20261104_h100_24_straight_geometry`。两者均为transform、straight3、同一unformed24初态、观察出口2400 m，规则分别仅改h=.75／1.00，MAX_SPEED仍33.3 m/s。这是**两个固定初态形成测试**，不与h48交通案例合并，不据此选择主参数。

两例实际result均为`drained`、`safe=true`、`all_completed=true`，requested／completed为24／24，碰撞与teleport均为0，整个运行的实际完成横移为0。30 s和60 s各帧都保留24车、0离场，均已横向居中静止；截至各帧的实际横移也为0。

## 相邻道互选相位

沿用原mutual50匹配与相同的物理平局键；相位按实测y连续插值，D使用两车共同平均速度。每帧01有8对、12有7对互选关系；没有匹配的边不当成零误差。

## 数据与计算来源

完整20行度量见[headway_formation24.csv](headway_formation24.csv)，保留每道CTH及01／12相位的pair数、实际值范围、动态目标、MAE／最大误差、在场数、LC与安全字段，以及各run和冻结rules路径。

读数复用既有`geometry_diagnose_20261104.py`的纯几何函数，仅将其spacing绑定到各run冻结源的`desired_spacing`，没有运行旧脚本的A／B消费入口。实测状态来自本次两run的diagnostic，使用真实vy；居中静止沿用原几何工具的`.05 m/s／.05 m`口径。positions第四项没有当成横速。没有修改控制器、已有数据或启动仿真。
