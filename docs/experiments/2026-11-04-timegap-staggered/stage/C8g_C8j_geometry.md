# 相位试验g/j：直路形成明显提速，45车重排时间变化小

只分析新C8g/C8j四例：24直路观察出口2400 m，45缩道观察出口3600 m、瓶颈仍1000 m。g仅将跨道相位增益改为.6，共用纵向增益仍.3；j保留.3，仅去掉相位与真实前车调速反向时的归零门。旧C8只引用已保存表，没有重读其raw。新数据见 [C8g_C8j_geometry.csv](C8g_C8j_geometry.csv)。

**两种改变均明显加快24车相位形成，并保持45车单向、低换道量与最终完整恢复；但45车第一次颜色顺序闭合仍在约70 s，没有明显提前。**

全部四例安全排空。24车固定时点全部24/24、0离场；45车所列时点全部45/45、0离场。沿用完整同道真实前车D误差、原mutual50相位、两道全部x排序半D与颜色交替口径，无新增达标门。

## 45车实际恢复与保持

“颜色闭合”表示全部45车同时稳定居中且44/44交替；该时刻纵距仍在恢复，不能直接当作间距误差为零。旧C8来自已保存3600 m长观察表。

两条新45车均为15次2→1、7次1→0，无0→1、无人多次横移；首次颜色闭合后均无中断地保持至首车109.2 s离场前。g只比旧C8晚.1 s，j早.8 s；j在80 s的间距恢复更快，随后三者都趋近原动态半D。这些数值支持“形成反馈变快”，不支持“45车结构重排大幅提前”。

g仍有357个全车帧出现>50 m孔，峰值63.364 m，最后一帧67.9 s；j为366帧、峰值63.389 m、最后一帧68.4 s。两者均在完整45车还在场时闭合大孔，未破坏单向恢复，但也未根本消除这一过渡代价。

本次结论限定于新四个实际几何过程。连续流进入缩道前的成熟度及交通附加收益，按root安排等待对应短批完成后再分析；这里没有消费那些新交通raw或重算交通主表。
