# 固定seed211的正式局部相位过程

预先固定seed211，仅消费C12/P12 transform的两种道路可见范围×三流量，共12条正式raw。这是单种子的代表过程，不能替代五种子交通主统计。NOA的0状态不在这里解释为形成。

**这组正式持续流中，进入缩道前仍有数米相位残差。** C12前段MAE为6.359–8.244m，近段为6.782–9.389m；P12对应为4.942–6.842m、5.273–7.670m。没有据此声明整队已完成目标几何，也不以局部互选MAE替代全排序交替或实际D/半D。两法目标不同，不能仅凭两列MAE的绝对大小排序交通收益。

时间严格为`[100,600)` s，按本车位置分别取`[200,600)`、`[600,800)` m。各自冻结源的`_pair_error`与mutual50决定匹配；C12目标为动态半D，P12目标为0，均使用实际y插值。车辆帧不是独立车辆；MAE按有向匹配加权，双方都在区域时关系计两次，覆盖为至少获得一个互选关系的车辆帧比例。

lane由trips的实际lane_events重建，vy由连续positions的y差分重建；第四列是纵向加速度。双方无横移沿用`.1m/s/.15m`的实际执行判据，未设置新的形成门。600–800m已混合接入与运动传播，对300m道路可见范围尤其不能称为全部未知道路的纯形成区。

数据：[formal211_phase_maturity.csv](formal211_phase_maturity.csv)。CSV另列01/12、匹配机会、去重关系、横移比例和逐run来源；没有读取其他正式种子或重扫开发raw。

## 解释与数据可用范围

剔除任一方实际横移后，所有24个方法/信息/流量/区域组合的MAE变化均不超过0.296m；数米残差仍保留，不能把它全部归因于横移混合。600–800m同时含较晚形成与缩道接入，保留该混合含义。各run均有5000个正式时间帧，原状态和安全/排空字段也保留在CSV中。

先前dev201的C12/P12值只见[既有消费表](C12_P12_phase_maturity_comparison.csv)，本次未重读开发raw。其种子和窗口长度不同，不作为本次正式211的成对对照。

必要脚本为[../tools/phase_maturity.py](../tools/phase_maturity.py)，仅用标准库和各run的冻结rules，不依赖其他tmp helper。随仓库保留的是脚本、读数CSV与说明；固定211这12条原轨迹在本机保留用于后续时空图，完整全路raw不全量入Git。从原轨迹复算需要CSV run列对应的positions.jsonl.gz、trips.json、result.json与source/noa/native_rules.py；汇总表不能替代这些逐帧输入。
