# 已成形45车群的控制机制探针结果

给定充分成形的交错初态，C12在本次45车探针中没有末道停车，平均过1000 m时刻略早于两个对照；最后一辆通过则稍晚。结果体现的是局部等待与通行顺序的变化，不能据此写成所有车辆都更快通过。

三组实际`result.json`均为`status=drained`、`safe=true`、`all_completed=true`，requested／completed均为45／45，collisions与teleports均为0。安全与排空结论来自结果字段，没有以进程rc0替代。各45车也都有实际跨1000 m的轨迹括号。

## 同初态：C12与NOA

C12与NOA使用同一冻结源中的不同mode，输入初态逐车完全相同。两者第一实测帧均为t=.1 s，45车的实际x、y、速度和加速度逐项一致。NOA是给定交错初态上的单车对照，没有由NOA形成编队：实际positions的1375帧、54754个车辆帧状态标记全部为0；result中的参与时长、参与率、峰值与episodes也均为0。

C12比NOA的平均瓶颈延误少0.266 s，末道停止暴露少19.9 vehicle-s，整个观察段少2次实际横移；但最后一辆通过晚0.299 s。两组在1000 m前实际LC都为22次，C12每车最多完成1次，NOA最多3次。给定同样的初始交错间隔，普通当前gap合流仍有2辆车在末道停车，而C12接收与单向重排避免了这项局部等待。这个对照同时包含C12的纵向关系与变换规则，不能把差异单独归给某一条规则。

## 同中心：交错C12与并排P12

两组均为45车、速度28.8 m/s、同道距30 m，初始纵向均值同为240 m。并排输入按协议将原道1纵向加10 m、道0／2减5 m，所有道各排位置为`30+30i`；交错初态仍为原输入。其纵向范围分别为并排30–450 m、交错20–455 m，逐车位置差保留在记录与自由基准中。

P12采用与C12匹配的规则，仅将跨道相位置0，并将slot几何进步的相邻道目标从`q=F.x−D_entry/2`改为`q=F.x`，对应并排结构；h、接入尺度、物理、道路信息与单向动作相同。因此这里比较的是各自已成形几何及对应目标，包含初态结构差异。

C12比P12平均瓶颈延误少0.340 s，末道停止暴露少5.2 vehicle-s，全段实际LC少2次；最后一辆通过则晚0.223 s。P12每车最多完成2次横移。两组平均延误差较小，而末道停车有所不同，说明在这个已成形车群中，交错几何及其控制有助于减少局部等待。该探针不替代正式连续流结果，也不证明连续流进入瓶颈前已充分成形或具有更高全局容量。

完整数值与逐车通过记录见[summary.csv](summary.csv)、[per_vehicle.csv](per_vehicle.csv)和[summary.json](summary.json)。原始run、mode、initial和rules路径都保留在summary中；运行与计算口径见[探针协议](../cohort_mechanism_protocol.md)。本次只读取三组已完成数据，没有新增仿真或更改控制器。
