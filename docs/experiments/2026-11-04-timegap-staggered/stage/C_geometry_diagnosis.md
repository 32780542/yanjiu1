## 24车直路

24辆全程没有横移，最终安全排空于81.8 s，首车离场73.5 s。t60仍24/24；各道真实前车CTH MAE为 **.0027 / .0023 / .4284 m**，但相邻道互选 phase01 / phase12 MAE为 **3.106 / 5.990 m**。道0/1实际排序交替率虽为100%，半D误差MAE仍3.106 m，不能将道色交替当成相位已经收敛。全24仍在场的全部735个诊断帧没有>50 m孔，最大原始间距44.891 m。

C在无缩道、无接入横移的直路上也保留相位残差，说明问题不全来自接入时关闭软相位。源码中相位只作为主前向CTH速度上的修正：与基础调速反向时取消，最后又以真实前车CTH请求作上限；因此真实CTH职责较强，相位并不是独立且完整保留的收敛反馈。几何证据支持“稳定恢复真实前车间距、避免大孔及重复横移”，截至所查全车时点还不支持“动态交错完整形成并恢复”。
