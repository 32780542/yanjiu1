# 所选2000/201两例：进入缩道前相位尚未成熟

仅分析200 m道路视野、2000辆/h/车道、seed201的两条现成transform raw：C8批`20261104_C8_dev180_201_202_r01`的`f38f30`，P8S批`20261104_P8S_dev180_drop_201_202_r01`的`18fad5`。完整来源见 [C8_P8S_phase_maturity_2000_201.csv](C8_P8S_phase_maturity_2000_201.csv)。没有新增仿真、修改代码、重算主交通表或设置新达标门。

**该时空窗口内，两者都尚未接近各自目标相位。交错附加收益小，当前不能解释成“已经充分成熟的交错几何仍无作用”；相位形成速度不足是有过程数据支持的限制。**

统计`t∈[100,180] s`，每法801帧；空间按本车位置分为`[200,600)`、`[600,800)` m。每个本车向相邻车道按原mutual50规则选邻：50 m内先最小化本法相位误差，再以原物理键排序，并要求互选。C8目标为动态半D，P8S目标为全0；均调用本法冻结源的`_pair_error`，保留实际横向位置插值。

表中车辆帧是本车观测样本，不是独立车辆数；有向匹配按每车每个相邻道关系计一次，双方都在窗口时计两次。去重配对数按“同帧同一对车辆”计一次，至少一方处于该空间窗。MAE按有向匹配样本加权，覆盖率为至少获得一个互选关系的车辆帧比例。

C8两段匹配的平均目标相位尺度分别约16.448、14.695 m，残差仍约10–11 m；P8S对0目标也仍有约10 m残差。匹配覆盖约四分之三，并非只挑到少量完美配对。CSV另保留01、12两组，避免合并掩盖不同相邻道关系。

600–800 m已混入实际接入传播，但横移不是主要解释：C8车辆帧中横移比例由200–600 m的.55%增至2.56%，涉及横移的匹配对由.53%增至3.71%；P8S对应为.49%→3.51%、.37%→5.09%。剔除任一方正在横移的配对后，两法近段MAE仍约9.9 m，前段也几乎不变。因此该窗口主要仍是未完成相位恢复的实车关系，并非大多数样本都已处于横移而失去目标含义。

原raw未保存diagnostic。已核实`positions`第四项是纵向acceleration，不能作为横速；本次lane由原始`lane_events`重建，横移由连续实测y差分及原控制器的`.1 m/s / .15 m`执行判据识别。该判据仅分离既有横移状态，不作为新的形成达标门。

这些结果支持继续检验**仅相位通道**的形成增益，而不是据本短筛认定成熟交错的收益天然很小。它们本身没有证明增大增益会改善交通或安全；后续因果判断仍需对应试验。若只检验相位增益，应保持共用真实前车CTH与入口、物理限制不变，避免通过共享`POSITION_GAIN`同时改到纵向跟驰。这里只保存成熟度诊断，不启动参数试验。
