# 相邻车群端点的逐车互惠

严格端点规则准确修复了 69 m 实测间隙的配对，三档持续流的上游双层保持都有改善。代价是稀疏整队从同源基线的 24/24 降到 16/24。开放远距离后车单边追赶，稀疏结果恢复至 21/24，下游瞬时形成率也在三档提高，但持续 3 秒的收益随流量变化。

### 局部规则与保证

车辆按纵向物理位置、车道编号组成的键 $(x,\ell)$ 排序。每车只检查此顺序中的直接前后车。间隔 $g>50$ m 时，两辆相邻车恰为不同连通群的真实边界。令 $D=5.5+0.85(v_a+v_b)/2$，取 $s=[g-D]_+/2$。在 $50<g\le100$ m 范围内，后端点的纵向目标加 $s$，前端点减 $s$，该边对其他车贡献为零。单车可以同时是两条边的端点，各边贡献相加。不同车道同纵位按车道顺序选端点；若选中的物理键本身重复，同侧及对侧都能观察到歧义，共同放弃这一边。

**为什么局部选择一致。** 对任意符合距离条件的两端，前后视距 200/100 m 都能覆盖两者之间的闭区间，包括与端点同纵位的全部车辆。若一端将对方认作直接邻车，则区间内没有处在两者物理键之间的第三辆车；另一端也必然选回同一车辆。双方用相同观测时刻与均速计算同一 $s$。因此各车原始外移总和恰为零，未裁切的外加速度 $\omega^2s$ 也逐边抵消。无需整群共享成员、锚或通信。该结论要求两端同处形成阶段并获得一致的物理测量。逐车限幅、前车跟驰、单车换道优先、真实安全限速和跨阶段边会改变实际执行的合力。实车质量不等时，相等的加速度增量对应不同的物理力。

独立对照 `extended` 在 $100<g\le200$ m 时允许后车额外加 $s$，前车不作对应响应。此时所有原始外移的合计正好等于这些远距有向边的 $s$ 之和。两个试验均只改变上游纵向槽外移，槽位指派、换道与原生执行使用同一冻结底座。

在[前一试验](reciprocal_potential.md)的 69.366 m 真实间隙（3→2、12 车、8722、1.6 s）上，后端点 `initial_5` 得 +19.596025 m，前端点 `initial_4` 得 −19.596025 m，该边的组内其他车辆均为零。该帧另有两条互惠边，全部 12 车的请求代数和为零。按全局物理顺序独立枚举，再随机打乱本车观测列表，分别核对了两个模式各 1212 个场景、13928 次本车请求；严格版 4064 条有效边、扩展版 7187 条有效边，均与逐边真值相符。

### 复算

[底座与物理评测器](endpoint_reciprocity_base.zip) 是本次实际使用的 `topology_product_demo/source` 及稀疏评测器。根目录运行以下 PowerShell 命令，使用新的输出目录名。

```powershell
$studyDir = "docs/experiments/2026-11-25-formation-transport"
Expand-Archive "$studyDir/endpoint_reciprocity_base.zip" tmp/endpoint-repeat-base
python -B "$studyDir/endpoint_reciprocity_trial.py" tmp/endpoint-repeat --prepare --source tmp/endpoint-repeat-base --evaluator tmp/endpoint-repeat-base/measure.py
python -B "$studyDir/endpoint_reciprocity_check.py" tmp/endpoint-repeat/frozen/endpoint
python -B "$studyDir/endpoint_reciprocity_check.py" tmp/endpoint-repeat/frozen/extended --reach 200
python -B "$studyDir/endpoint_reciprocity_trial.py" tmp/endpoint-repeat
python -B "$studyDir/run_study.py" --stage traffic --variant tmp/endpoint-repeat/frozen/endpoint --label endpoint_repeat_600 --roads 3to2 --seeds 6 --flows 1500,1750,2000 --duration 600 --workers 3
```

将最后一条的源目录和标签改为 `extended` 可复跑单边对照。[计算核与构造器](endpoint_reciprocity_trial.py)、[独立枚举](endpoint_reciprocity_check.py)、[全轨迹物理审计](endpoint_reciprocity_audit.py) 及每案来车、实体首帧和源码指纹均随结果保留。
