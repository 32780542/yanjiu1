# 已在预视线前排齐的车辆，过界后能否以原成员重排齐

本指标跟踪同一组真实车辆。每种控制器的分母都是它自己在门线前实际形成的完整队列。共同的请求发车表控制了需求，真实入场与上游配组均会受控制器影响。下列比率描述各方法已形成组的条件转化，不构成相同车组的因果对照。

同一分母可直接连接几何与运输下界。对每个保持门槛，计算“原成员重齐且总跨道与单车最大跨道同时取下界的组数 / 上游已形成组数”。600 s 持续流中，至少一帧达到该联合指标的比例，三变二为 11.24 的 147/219、e186 的 91/203；四变三为 0/67、94/131。若要求持续 3 s，四项分别为 63/219、45/203、0/67、13/131。下表另列单纯的几何成功数，可查明损失来自重构还是跨道代价。

## 门线与记录口径

- 由实际网络读取上下游道数 $K,L$。取 $N=\operatorname{lcm}(K,L)$，三变二为 6 辆，四变三为 12 辆。两端道数均整除 $N$，队列必须整层。门线为实际道路变化点上游 200 m。主窗仅纳入需求仍在注入时队首首次过线的组，然后跟踪到第一名组员驶出；需求停止后过线的组另表列出。
- 若相邻两帧满足 $x_0<x_g\leq x_1$（$x_g$ 为门线位置），在前一帧以该车的实测纵向位置为前缘，向后取连续 $N$ 辆。实测 $x$ 完全相同的前排必须全部入组，尾排也不得被截断。组首时间相同时按该步内线性插值的过线先后，再按物理位置去重。从早到晚锁定成功候选，同一车辆在一场内只入选一次。真实 ID 仅供离线跟踪。
- 原点容差、车道相位与固定队列评估共用同一函数。各车距道中心 ≤0.3 m，组内速度极差 ≤0.5 m/s，层间距 $D=5.5+0.85\bar v$ m。各道按纵向排序，反推的交错原点极差 ≤2 m。两道允许任一侧领相位，三道和四道沿用车道 0 所在相位领头。纵向闭区间内不得出现组外车辆，异道外车也计入。下游全员均须在真实路段内，并通过相同几何及闭包检查。
- 原生轨迹每 0.1 s 一帧。一帧、连续 1 s、连续 3 s 分别至少需要 1、11、31 个连续合格样本。每个持续门槛的跨道统计从上游选择帧至首次达到该门槛的合格区间起点，端点用实际采样时刻。相邻车道物理跨越按 SUMO 的车道分界事件累计，同时核对每辆车的起讫道和事件链。总跨道下界为各车道边界所需净流量绝对值之和，单车最大下界由起终车道序列同秩配对给出。三变二两下界为 3 和 1，四变三为 6 和 1。

“观测机会”指全组同时位于下游的实际连续时窗达到 3 s，可以包含外车减速或穿插。连续流的上游长 1000 m、下游长 200 m；按 28.8 m/s 匀速，理想 6 车两道列长约 75 m、12 车三道列长约 105 m，在该下游可供整组同时观测约 4.34 s 和 3.30 s。四变三中，多数组仍有至少 3 s 的观测机会，实际达到 3 s 的少。未锚定版本 e186 在三变二的原成员转化低于 11.24，在四变三则同时增加了上游组数、转化率和单车横移最优性。纯 NOA 在两个门线分别有 5169、6794 车驶过，均未形成合格整组，转化率无定义。11.24 与 e186 在同一发车表上选中完全相同的 ID 集合，三变二只有 99 组，四变三只有 27 组。

队首跨过预视线至首次完整下游帧（未成功则至首车离场）期间，11.24 三变二 / 四变三分别有 40/219、17/67 组的纵向闭区间出现外车；e186 分别为 15/203、7/131。11.24 四变三有 3 个被穿插的组后来恢复，其余三行中被穿插的组均未完整恢复。36 场含排空共锁定 658 组；用独立的闭区间枚举重新选择、直接从横向位置逐帧重数跨道，658 组 ID 及 394 次成功的时点、总跨道与最大单车跨道均与主台账一致。182 组具有完全同坐标的双车首排，均同一步过线。

## 独立持续需求与分母

三变二的 1200 s 独立样本包括种子 9301–9304 与三档流量，共 12 条发车表。未锚定 e186 的 862 个上游组中，424 个原组在下游重齐、334 个保持 1 s、168 个保持 3 s。采用可见前群队尾锚定并保留原跟驰的版本为 14 / 6 / 1 / 0。两版下游一帧转化率为 49.2% 和 42.9%，更大的差异出现在进入分母的组数。这与稀疏固定队列的结果衡量不同运行条件。[同一初始队列在三个道路长度下的实验](splice/README.md)

|---|---:|---:|
| 实际闭合的六车连续窗口 | 19,716 | 20,398 |

速度和原点两行均以第二行为起点独立计算。保留相同平均速度，单独考察位置也能看到差异。若另允许相反的领头相位，在未通过原相位的窗口中仅分别多出 5 个和 0 个，同时合格分母的落差仍在。

在 3600 s、2000 辆/(小时·车道)、独立种子 4801 的单次高流量试验中，按“上游组 / 下游一帧 / 下游 3 s”计，三变二 11.24 为 166/87/28、e186 为 179/49/16；四变三分别为 40/10/0 和 88/47/1；纯 NOA 两路均无合格上游组。这一小时中，独立的两道连续模板版本 `path_product`（`noa/staggered.py` SHA-256 前八位 `2e914876`）四种道路各有 1 个上游组，2→3、4→3 各有 1 个原组在下游重齐，四路均无原组保持 3 s。每路只有一个种子，分母也很小。

三变四需要特别保留负结果。两策略的九个上游组在同一发车表中逐一对应，ID 集合与上游选择时刻全部相同；其中 5 对上游帧的整个交通现场状态也完全相同。保留跟驰版有 4 个原组下游重齐，开道子流为 0。两种方法下，这九组均具备全员同时处于下游 3 s 的观测机会。

覆盖 600 s、1200 s 与 3600 s 共 190 场，均完整排空且零碰撞、零传送。含排空阶段，台账共有 2752 个不共享上游组，1193 组的实测首排有多个同坐标车辆；其中 1193 组的所有同排队首均在同一记录步过线。阶段及开道子流全部 48 场还经过独立核算：重建 66 个组的 ID 集，并直接用跟踪到的横向坐标核对 47 组正例的首个下游时刻及跨道次数。

按需求窗和排空分别汇总的数据见[分层表](boundary_strata.csv)。逐道路、种子、流量的分母与源码 SHA-256、可复核的逐组成员及各保持门槛台账见[压缩明细](boundary_evidence.zip)。`runs.csv` 中 `d*_exposed` 统计在有限下游有充足时间的组，`d*_groups` 为实际合格组；`groups.csv` 的 `d*_t` 为首个达标连续段的起点，`foreign_before_first` 统计首次合格前出现外车。`path_trial` 是中间两道连续模板试验，`path_product` 为不同冻结源码的小时试验。`subflow` 为本节候选，`noa/native_rules.py` 和 `noa/staggered.py` 的 SHA-256 前八位分别为 `c06b8976`、`6697aea0`。

镜像矩版本另做了固定发车表的实际路长对照。三变四和四变三各有两个可逐一匹配的 12 车上游组。相同四组在实际短路均未保持 3 s，在长路分别保持 22.5–29.8 s。需求窗、截取长路首 200 m 的同轨迹对照、入场核对和上游反馈详见[延长实际下游的独立研究](boundary_length_flow.md)。
