# 最近邻车群互选后向前拼接

最近邻互选保住了 24/24 个稀疏案例的全队完整性，但上游全队保持时间缩短，三档持续流的上游连续 3 s 占比也仅变化 −0.001、−0.002、+0.005 个百分点。下游瞬时形成率三档均提高，持续保持在前两档提高、最高档略降。这组开发结果支持保留已确认的镜像基线。

### 判据与有限观察

以相邻纵距不超过 50 m 划分每一帧的可见物理车群，从后到前编号。$d_i$ 为第 $i$ 群最前车至第 $i+1$ 群最后车的正间距；缺失边取 $+\infty$。每群选择较小的前后间隙，平距时选前方。因而，仅当

$$
d_i\le d_{i-1}\quad\text{且}\quad d_i<d_{i+1}
$$

才让第 $i$ 群调用原有前锚共同平移。第 $i+1$ 群对这条边无外移。控制器继续使用原来的距离、速度和横移规则。冻结镜像底座中唯一的行为改动是选择是否交给原控制器前锚。

**共同观察的结论。** 相邻两边若同时入选，就要求 $d_i<d_{i+1}$ 且 $d_{i+1}\le d_i$，故入选对互不共用车群。有限开链至少有两群时，选取最小间隙中最靠前的一条，它的后边不小于它，前边严格大于它或不存在，因而必能入选。若各步至少有一对完成实际合并、没有新车群进入、已连通段不分裂，则每轮段数至少少一，最多经初始段数减一轮可全连。动力学、有限路长、安全限速和可用换道空间都会影响一次实际合并能否发生。

**车载视窗的边界。** 后视 100 m、前视 200 m。例取三个单车段位于 0、140、220 m。后车看见 140 m 车，看不见再前面的 80 m 间隙，允许追中车；中车看见前车，看不见后车，也允许向前追。两条边同时在不同窗口获得许可。全视野下只有前方 80 m 边能入选。独立按每段最短边给出真值，对 1093 条完整链和 850 个带截断的物理场景核对 18487 次车辆判定，结果一致。

### 稀疏固定组

四种增减道、12/24 车、稀疏 2800 m 上游、8721–8723。镜像前群锚和最近互选各有 24/24 案在两区均形成同一完整实体车队。与原锚相比，互选使首次全连时刻的跨案例中位数从 25.50 推迟至 31.95 s，首次上游全形成从 44.80 推迟至 47.90 s。按同一初态配对，15 个案例的上游全队保持变短，最长减少 13.0 s；一个多 0.1 s，其余相同。两方案上游全队保持中位数为 27.15、24.60 s，下游均为 27.45 s。

各案下游最大单车和总跨界数都达到对应下界。两区四个横移下界全部同时达到者，原锚为 8/24，互选为 9/24。另有四个标准 12 车演示，两边均在两区全队成形且同时达到四个下界。56 次固定运行均全部驶离，记录碰撞和瞬移为零。逐案首帧、来车指纹、持续时间和横移见[固定车组表](nearest_segment_fixed.csv)。

### 持续流与窗口边界

3→2、种子 6，供车 600 s 后排空。按 0.1 s 原生轨迹，在上游 [0,800) m、下游 [1000,1200) m 内判定固定 30/15 m 几何。连续 3 s 指同一有序双层持续合格，重叠双层按每车每时刻计一次。以下均为区域车辆时间百分比，每格依次对应 1500、1750、2000 辆/时/道。[逐档原始表](nearest_segment_traffic.csv)

| 物理指标 | 原镜像前群锚 | 最近邻互选 |
|---|---:|---:|
| 上游瞬时 | 0.491 / 0.775 / 0.738 | 0.487 / 0.771 / 0.966 |
| 上游连续 3 s | 0.121 / 0.410 / 0.343 | 0.120 / 0.408 / 0.348 |
| 下游瞬时 | 46.698 / 43.677 / 30.621 | 50.683 / 49.108 / 36.433 |
| 下游连续 3 s | 10.857 / 9.477 / 3.858 | 13.020 / 11.146 / 3.734 |

两边逐档实际发车并驶离 817、941、1087 辆，碰撞和瞬移均为零。来车带和路线摘要相同。按实体编号核对，首次出现的纵横位置、速度全部一致，最近邻互选分别有 3、13、14 辆首帧时刻与原锚不同。平均行程从 39.186/39.491/40.252 s 变为 39.329/39.639/40.177 s。原镜像的三个持续流对照使用字节完全一致的既有冻结源码。

在中流量互选轨迹的 638 个整秒帧中，原规则有 7258 个上游本车视窗看到前段，互选仍放行 6744 次（92.9%）。其中 3103 次的物理边在全视野互选中落选。394 帧至少有相邻两条物理边分别从不同的本车视窗获准。该计数衡量选锚许可，实际位移再受速度裁切和跟车优先限制。原镜像轨迹上的离线对照也表现出类似现象。详见[视窗计数](nearest_segment_gates.csv)。

### 复算

从项目根目录运行，使用新输出目录名。镜像底座和稀疏评测器随 [冻结源码包](nearest_segment_base.zip) 提供。

```powershell
$studyDir = "docs/experiments/2026-11-25-formation-transport"
Expand-Archive "$studyDir/nearest_segment_base.zip" tmp/nearest-repeat-base
python -B "$studyDir/nearest_segment_trial.py" tmp/nearest-repeat --prepare --source tmp/nearest-repeat-base --evaluator tmp/nearest-repeat-base/measure.py
python -B "$studyDir/nearest_segment_check.py" tmp/nearest-repeat/frozen/nearest
python -B "$studyDir/nearest_segment_trial.py" tmp/nearest-repeat
python -B "$studyDir/run_study.py" --stage traffic --variant tmp/nearest-repeat/frozen/nearest --label nearest_repeat_600 --roads 3to2 --seeds 6 --flows 1500,1750,2000 --duration 600 --workers 3
```
