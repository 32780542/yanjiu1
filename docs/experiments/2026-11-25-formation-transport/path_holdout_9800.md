# 连续二道半间距模板的独立验收

固定 9801–9806 六个新种子，二变三、三变二各取 12/24 辆、紧凑/稀疏两种初态，共 48 个物理初态、96 次 SUMO 运行。全队在上下游都形成并保持正时长的工况由 41/48 增至 48/48。新增七例全部发生在二变三上游。代价集中在三变二 24 车，12 个工况都出现同一辆车连续跨两道，单车理论下界为一道。全部 48 个连续路径工况的变换总跨界次数仍达各自下界。

## 连续裁切的适用前提

设实际有限二道队形的前后序位 i = 0,…,N−1 满足 xᵢ = a−iD/2，车道为 p XOR (i mod 2)，p 可为 0 或 1，D>0。任一连续可见位置区间与有限等差列相交，只能取到空集或连续索引 i₀,…,i₁。因此相邻车间距仍为 D/2，车道交替，局部首相位为 p XOR (i₀ mod 2)。偶数窗两道等人数，当前首车给出零跨界的原位姿态；奇数窗中首道多一辆，该相位的占道下界为零，另一相位需要一次横移。单车仅决定其本地位置，不能认出全队哪端或全队首相位。实际实现对这些合法窗的横移下界均为零，同道按纵向排序的位置匹配唯一。

设观测 x′ᵢ=xᵢ+eᵢ，|eᵢ|≤ε。如果 D/2>2ε，排序不会颠倒，按真实或测得位置硬裁切都仍取得连续索引。实测相邻间距误差至多 2ε。对 n 辆可见车拟合公共均值，目标位置为理想点加该窗口的平均误差，故目标与对应实测车的位置差至多 2ε(1−1/n)。无其他前方外部锚、车道观测正确、D 固定时成立；未知内部漏检和外加纵移会改变结论。真实终点若要保持，也须采用同一套连续半格占位定义。

旧定义允许不完整末层省去领先半层、留下后半层。取 D=29.98 m、首相位 0，真实有限序列占半格 0,1,2,3,5，车道为 0,1,0,1,1。旧函数对五车原位驻留。新函数保持每车原车道，却分别要求纵移 −17.988、+11.992、−17.988、+11.992、+11.992 m。跨窗闭合的性质来自这个明确的真尾假设改变。只凭一个看似连续的窗口不能推断其后确无缺位或车队已经结束。

对 N=1–24、双镜像的 5,200 个理想连续切窗，用冻结实现完成 16,290 次本车指派，含 600 个单车窗。另有 4,000 个随机硬边界工况，ε=0.05 m；3,904 个非空、96 个空窗。非空窗均保留车道、连续索引和上述纵移界。原生闭环验收使用未加噪的实际物理轨迹，扰动结论仅关乎给定窗口的几何构造。
