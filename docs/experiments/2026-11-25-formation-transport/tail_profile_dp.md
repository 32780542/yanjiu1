# 不完整末层选道的精确动态规划

对同一本车观测，未裁切模板末层在 K 条目标车道中占 r 个位置。两趟路径动态规划可复现冻结版 `_tail_lanes` 选出的升序车道元组，包括头部裁切和所有平局。实际头裁切至多涉及 K 道。给定已排序的源车道，算法使用 O(n + K(r+1)) 次整数运算和 O(n + K(r+1)) 空间，其中 n 为可见车数。未排序输入另需 O(n log n) 排序；若接受任意长的重复裁切列表，还需线性读取该列表。实验路网的 2–4 车道上，原枚举更快。20 车道、半满末层的冷调用耗时由约 3.14 s 降至 0.46 ms。

## 目标人数与选位次序

设头部裁切在车道 j 省略了 oⱼ 个格位，令 (L,r) = divmod(n + Σoⱼ, K)。末层选择位 eⱼ ∈ {0,1}，Σeⱼ = r。实际目标人数为 tⱼ = L + eⱼ − oⱼ，必须非负。oⱼ = L+1 的车道必选。如果裁切涉及目标范围外、oⱼ > L+1，或必选多于 r，则不存在合法人数配置。研究函数此时复现旧函数的行为，返回词典序首个 r 元组，另将两项横移费用标为空。

记 P 为末层选中格位里与头部相位同奇偶的车道数。按原顺序比较 `(严格末层时 −P，否则 0, 最远横移 R, 总横移 C, −P, 升序选位元组)`。上游三车道真实末层采用相位 0，优先外侧 0、2 道。严格时先留足所有裁切必选项。余下若有 d 个名额，尚有 f 条可选偏好车道，d ≤ f 时禁选非偏好自由车道，d ≥ f 时强制选入所有偏好自由车道。等号时两者同时成立。这恰好保留全部最大 P 解。若以后增加逐车道必选或禁选，可以同样约束每个状态的两条转移；跨多个选位的额外规则需要单独建立状态。

## 路径证明与递推

令 x₀ ≤ ⋯ ≤ xₙ₋₁ 为实际源车道，可在目标区间 [0,K−1] 之外。S(k) 为源车在车道 k 及其左侧的数量，Q(k) 为对应目标数量。排序配对同时达到最小最大横移和最小总横移。前者的等价条件是每一侧超出 R 的分位都已获另一侧覆盖，即对所有整数切口 k 都有

```text
S(k−R) ≤ Q(k) ≤ S(k+R).
```

必要性来自最远 R 道的可达范围。充分性可取相同排名的源与目标配对：若第 i 个目标比其源早超过 R 道，在目标所在切口便有 Q(k) > S(k+R)；若源比目标早超过 R 道，取该目标的前一切口，即有 S(k−R) > Q(k)。不论怎样配对，切口 k 两侧至少须交换 |S(k)−Q(k)| 辆；排序配对横跨同一切口的车辆都朝同一侧，故总横移正是所有切口该数值之和。

前 k+1 道选了 s 个末位时，q = Q(k) = (k+1)L − Σⱼ₌₀ᵏ oⱼ + s。保持同一 q 所需半径由两项秩统计量直接给出，无需搜索 R。

```text
D(k,q) = max(0, x[q−1]−k（q>0 时）, k+1−x[q]（q<n 时）).
```

1. 第一趟按车道从小到大，在允许的 e = 0 或 1 中，递推 `B(k,s) = min_e max(B(k−1,s−e), D(k,q))`。空前缀 k = −1 的起始值为 max(0,−x₀)，无车时为 0。最后一道也要检查 D(K−1,n)，它限制最右侧源车。其余外部切口的半径限制由这两个端点推出。末状态给出全局最小 R。
2. 第二趟固定此 R，从末道向前求最小剩余费用。每次转移检查 D(k,q) ≤ R，在 k < K−1 时累计 |S(k)−q|，并累计选中偏好车道数。先求总费用最小，再求偏好数量最大。两者完全相同时优先在当前较小车道选 1；因剩余选位总数固定，这就给出词典序最小的升序元组。用每状态一位选择即可恢复全部选位。
3. 目标边界外的切口再贡献常数 Σᵢ[max(0,−xᵢ)+max(0,xᵢ−K+1)]。右侧源车会影响第一趟的半径和最优选位。以 K=3、源车道 (0,0,3,3)、无裁切和相位 0 为例，正确末位为 2，四辆车最大横移 1 道，合计 3 道。事先把源 3 截到 2 会选出末位 0；用于实际源时，该选择迫使一辆车跨 2 道。

两趟分别保留当前最小瓶颈、固定瓶颈下的最小加法费用。每个状态至多两条边，状态只包含车道位置和已选数量。严格外侧优先已在可行边中实现，存储末层子集或逐一生成完整槽表均可省去。所得横移费用属于当前观测下的静态槽人数配置，车辆对纵向槽的最终指派仍由后续匹配完成。

## 独立核验与耗时

51,536 组三方穷举逐例核对了动态规划、冻结枚举函数以及显式遍历所有末层子集和全部车到槽排列的独立实现。车道数为 1–5，包含空车组、任意省略车道子集、两个相位、两类严格标记、重复源车道及两侧外部源车。其中有 47,932 组裁切、29,800 组含高于目标末道的源车。另在 1–12 道做了 1,200 个随机对照，含无序源车、重复裁切和 615 个全部候选非法的输入，返回选位全部相符。冻结版与当前版被核对函数的语法树相同。
