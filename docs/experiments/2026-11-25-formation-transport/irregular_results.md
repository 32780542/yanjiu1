# 车数不能整除车道数时，队尾怎么办？

7、11、13、17 辆车是这次的四个规模。例如 11 辆车可以在三条道上形成 4/3/4，转成两道后则可排 5/6 或 6/5。这两种两道终态都均衡，但从同一个三道起点到它们所需的最少换道数可能不同。下面分别报告“到实际终态最少几次”和“允许在所有合法队尾里选时最少几次”。

## 新种子的闭环结果

每条路有 4 个车数、2 个初始疏密度和 4 个未用于前述过渡模板开发的随机种子（9901–9904），共 32 个初态。每个初态的两次 SUMO 运行共用同一批车、车道、位置和速度；0.1 秒首帧逐车核同。上游 2800 m，减去 200 m 的可视预览区后审核形成。下游 1000 m，全队过界后审核变换。两道要求每两辆纵向相邻的车左右交替。速度、居中与纵向位置按主文的同一套条件审核。两种方法各实跑 1,536 辆次，全部驶出，碰撞和瞬移均为零。

“原”是可见前群锚定但沿用旧两道尾层的版本，“新”加入了连续半间距、缩道过渡模板及扩道开放子流。四列的分母都包含没形成的工况。表中每格按原→新的顺序。

| 道路 | 上游全齐 | 下游全齐 | 同一批车两段全齐 | 形成且变换两项达到实际目标下界 |
|---|---:|---:|---:|---:|
| 3→2 | 32→32 | 8→18 | 8→18 | 8→16 |
| 4→3 | 31→31 | 32→32 | 31→31 | 28→28 |
| 2→3 | 23→28 | 32→32 | 23→28 | 22→28 |
| 3→4 | 31→31 | 32→32 | 31→31 | 31→31 |
| 合计 / 128 | 117→122 | 104→114 | **93→108** | **89→103** |

变换成功的 108 例里，107 例达到了各自实际目标人数的全队最少总跨界，103 例也实现了最小单车最大跨界。若允许每次重新选择最省换道的合法末层，把未成队者也保留在分母，两项同时达界数分别为 **8、28、28、31**，共 **95/128**。两版本逐个对照，有 16 个原先未能双阶段排齐的新达标工况，也有 1 个原先达标而新版未达标。初态、逐道终态、两类下界和实测数均列在[逐次结果](irregular_runs.csv)。

**一个真实失败。** 三变二、11 辆、紧凑、种子 9901。上游形成了 4/3/4。下游 11 辆全在场的 301 帧中，纵向车道序列始终有一次同道相邻。最后一个全员在场帧为 111.4 s，道序是 `0 1 0 1 1 0 1 0 1 0 1`；各相邻车的纵向距离约 11.4–17.9 m，组内速度极差只有 0.37 m/s。虽然实测总跨界已达最终人数所需的 5 次，那两辆连续同道车使整队几何不合格。重复出现的断点在车队内部。接下来的工作比较两种更换领相位的依据，并复查是否以额外横移换取表面整齐。

**复现。** `irregular_cohorts.py` 固定了路网、车数、种子、车辆初态生成及审核代码。基线源码逐文件等同 [48 初态归档](path_holdout_9800_inputs.zip) 中的 `retained`，新版等同[过渡源码差异](transition_overlays.zip) 中的 `subflow`。从主仓库根目录执行以下命令，每次使用新的输出目录。

```powershell
$study = "docs/experiments/2026-11-25-formation-transport"
python "$study/path_holdout_9800.py" --out tmp/review_base --inputs "$study/path_holdout_9800_inputs.zip" --prepare-only
python "$study/transition_replay.py" tmp/review_sub --roads 3to2 --sizes 12 --profiles compact --seeds 9801
python "$study/irregular_cohorts.py" tmp/review_irregular --baseline tmp/review_base/frozen/retained --candidate tmp/review_sub/frozen/subflow --workers 4
```
