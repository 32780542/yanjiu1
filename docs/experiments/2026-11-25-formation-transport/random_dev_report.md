## 随机化与可复算边界

种子 1511、1512、1513 是开发种子。每个主种子按路网、车数、跨度派生独立随机流，两控制器读取同一张表。所有请求均为 0 s，车头最前位置固定在 650 m，使各初态到边界的可用前进距离相同。12 辆紧凑/长列的首尾车头距分别为 95/380 m，24 辆为 185/580 m。路网采用原演示 1600 m 上游与 1000 m 下游。

生成器逐车在仍可容纳车辆的车道中均匀抽取。道内纵向位置用有序均匀随机数叠加 20 m 的最小车头距，然后将整队伸展到指定跨度。全开发集实际最小同道车头距为 20.0409 m。各车初速独立抽取自 26.5–30 m/s。安全性另外由实际碰撞、瞬移和完成数核查。每对要求首帧全体 ID、纵横位置及速度一致。冻结运行器及控制模块在模拟开始前核对实际加载路径与文件哈希，评估器在原生车辆全部运行之后载入。

首次调试批次 `tmp/nov25-random-dev` 中，评估器提前改动了 Python 的导入顺序，造成两种名称下实际使用同一工作树控制器。复核决策原因后弃用整批；本报告数据全部来自修正导入顺序后重新执行的 `tmp/nov25-random-dev-verified`。

几何完整要求全部原始 ID 同时成队且保持正时长。某次没有完整端点时，CSV 中相应的形成/变换下界和超额列为空。`observed_population_*` 单独比较上下游最后一个全员居中快照的实测跨界与其占用下界，只描述该次实际形成的人数分布。开发集只有三个种子，完整率及差异以这些固定工况为分母。[物理判据](measure.py)

冻结包包含两版源码、共同评估器、24 张发车表和清单。运行下列命令可在新的输出目录复算，并可替换 `--candidate-source` 与 `--seeds` 测独立候选。需要 Python 3.12、SciPy，以及 SUMO 1.27.1 与配套 TraCI。[随机初态脚本](random_cohorts.py) · [配对汇总脚本](random_pairs.py) · [冻结源码与发车表](random_dev_inputs.zip)

```powershell
Expand-Archive random_dev_inputs.zip -DestinationPath random_dev_frozen
python random_cohorts.py --base-source random_dev_frozen/frozen/base --candidate-source random_dev_frozen/frozen/candidate --evaluator random_dev_frozen/frozen/measure.py --seeds 1511 1512 1513 --output random_dev_replay
python random_pairs.py random_dev_replay/summary.csv random_dev_replay/pairs.csv
```
