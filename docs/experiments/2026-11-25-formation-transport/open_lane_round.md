# 扩道前可执行的最大单步子分配

在所有车辆共享同一观察、目标人数和固定的一步指派时，向外侧未开放车道的净流取零，沿指向它的连续同向边向上游回推，即得到**每条边同时可达到的最大本轮跨界数**。所有其他边可保留原计划。该结论针对同步批次完成后的各道在场人数。每辆车只需执行其被选中的原定一步。

## 模型与证明

把源车道和目标车道嵌入同一条整数路径，车道 i 在轮初有 nᵢ 辆，目标为 qᵢ 辆，两者总数相等。新外道的 nᵢ 为零。完整指派已固定，每车保持或移动至相邻一道，总跨界数达到静态下界。对切口 k（车道 k 和 k+1 之间）令

```text
Hₖ = Σᵢ≤ₖ (nᵢ − qᵢ),    Fₖ = |Hₖ|,    dᵢ = max(0, qᵢ − nᵢ).
```

Hₖ 的正号表示向大编号车道移动。每个切口至少要跨 Fₖ 次；总数量最优意味着该切口全部 Fₖ 辆同向。给定人数时，完整计划的一步可行性还要求每条车道所有向外的 F 之和不超过其初始人数。若该条件成立，从现有车辆中分配相应数量给每条出边，其余原地保持，即可实现完整计划。脚本会拒绝需多跳或同一切口双向互换的输入。

令 Uₖ ≤ Fₖ 为固定指派中该切口当前可选的人数，仅考虑道路开放时，开边 Uₖ=Fₖ、闭边 Uₖ=0。令 aₖ 是本轮实际选中的无符号跨界数。车道批末占有量为 nᵢ + 入流(a) − 出流(a)，上限为 max(nᵢ,qᵢ)。故全部容量条件等价于

```text
0 ≤ aₖ ≤ Uₖ,    入流ᵢ(a) − 出流ᵢ(a) ≤ dᵢ.
```

由于每辆车只来自其轮初所在道，从任意预先指定的跨界车池取子集都不会使源道人数为负。车道节点只有三种有关情形。

* **只出不进。** 容量条件自动满足，即便该道同时向左右两侧供车。两个出边使用固定指派中不同的车辆。
* **只进不出。** 完整计划的总入流恰为 qᵢ−nᵢ=dᵢ。来自一侧或两侧的任意子集都满足容量条件。
* **单入单出。** 入边 e、出边 f 的唯一额外约束为 aₑ≤dᵢ+a𝒻。这些节点串成一条条单向路径。

从每条有向路径的下游端开始。进入汇点的边取 Aₑ=Uₑ；若进入单入单出节点 i，取 Aₑ=min(Uₑ,dᵢ+A𝒻)。该整数向量逐节点可行。对任意可行向量 a，从汇点向上游归纳，先有 aₑ≤Uₑ，再有 aₑ≤min(Uₑ,dᵢ+a𝒻)≤Aₑ。因此每个可行向量均逐边不超过 A。A 是唯一的逐边最大向量，也是唯一最大化本轮总跨界数的**边计数**。具体被选车辆可以有平局。以上归纳对实数 LP 的可行点也成立，原数据为整数时无需将 LP 解逐车取整。

若唯一闭边 b 通向右侧外道且 Hᵦ>0，则 Aᵦ=0。在紧邻其上游的正流后缀中依次取

```text
Aₖ = min(Fₖ, max(0, qₖ₊₁−nₖ₊₁) + Aₖ₊₁),    k = b−1, b−2, …
```

到零流或反向流处即止。若闭边原计划流为零，直接执行全部原计划。其他开边可全量执行这一简化以这些边没有其他可用性限额为前提。若已知某些具体车也不可执行，把其从各自车池排除、更新 U，再对所有有向路径作同一回推；左右方向各扫描一次即可，边计数耗时 O(K)。

## 数值与实体选车

取 n=(0,3,1,2,0)、q=(1,0,2,1,2)。四道切口的有符号原流为 (−1,+2,+1,+2)。最外边关闭后，进入车道 3 的流须为零，车道 2 却还有一个目标名额。最大子流为 **(−1,+1,0,0)**，批末人数为 (1,1,2,2,0)。其余开边若全部照搬原计划，车道 3 会从两辆升至三辆，超过上限两辆。若把闭边上游整段一律停掉，又会丢掉通向车道 2 的一次合法移动。

对每条**有向边**，在该边已指派且目前可选的车中，取 Aₑ 辆到其原纵向槽平方残差最小的车。边配额固定，各池互斥，以更低残差车辆替换同边较高者不改变任何人口，故这种选择也使本轮被选车辆残差之和最小。若实际次目标定义为执行相比暂缓的增量代价，应按该差值排序。相同残差时按同一源车道的真实前后次序排序。脚本使用前车优先，输入排列及真实 ID 均不影响选取。若选择边界的两个候选连物理位置也完全相同，单靠所给信息不能无身份地区分两者，脚本会标出该平局。

同步条件有实际意义。令 n=(1,1,0)，q=(0,1,1)，计划为 0→1 与 1→2 各一次，两步在同一批末结算恰得 q。如果后一个移动被驾驶安全检查否决、或要到稍后才离开车道 1，前一个先完成就会使车道 1 瞬时有两辆，上限为一辆。不同车辆的可见成员、指派、开放信息或决策时刻不同，也可能发生同样的不一致。局部车辆仍须独立检查实际空隙；定理不涵盖车身在横移途中占两道的连续过程，也不保证全队异步闭环达到共同目标。

## 独立核验

穷举 2–5 条车道、0–5 辆车的全部源/目标人口组合，要求最外新增道初始为空、完整排序配对每车至多一步。得到 4,495 个工况。每个工况逐一枚举全部原定跨界车辆子集，直接移动具体车辆并检查批末人数、逐边最大数、总数和固定配额下最小纵向残差。另取 512 个 2–11 道的随机一步指派，含两向分叉、汇合及任意个体不可用。

两组共检查 **43,006 个实体子集**，并独立求解 **18,346 个连续 LP**。LP 直接以每辆车的执行比例为变量，从源道扣除、向目标道增加。分别最大化总跨界数、最大化各非空边流量，再于最大跨界数固定时最小化被选车辆的纵向残差之和。所有逐边值、最大总数和最小残差与显式枚举、整数递推相符。自然前后次序还与穷举得到的并列最优子集相符。这项核验没有改动控制器或运行 SUMO。
