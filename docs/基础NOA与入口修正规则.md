# 基础NOA与持续车流入口规则

本轮把基础行驶、编队组织和实验边界各自的职责明确下来。基础NOA负责巡航、跟车、当前碰撞威胁和物理终点；编队组织改变车辆的相对位置目标；实验入口只负责把外部请求接入物理道路。

## 1. 常规跟驰

常规跟驰采用常时距线性ACC。净距g是前车尾部与本车头部之间的距离，v为本车速度、vL为观测前车速度。目标净距为：

\[
g^*=3+1.8v.
\]

巡航请求为`0.6×(设定速度−反馈速度)`；跟驰请求为`0.15×(反馈净距−目标净距)+0.8×(前车速度−反馈速度)`，取两者较小值，再按车辆舒适加减速度限幅。反馈速度与净距保留原半个控制周期的执行补偿。运动模型的0.1s控制、0.01s RK4、执行滞后和jerk限制保持原样。

这一规则使等速车辆在目标时距附近保持运动。原来叠加的“前车立即以−10m/s²停车、本车按含jerk的过程停车”的距离差，不再用于日常运动前车。原舒适停车速度罩只用于已静止前车和物理道路终点。

常时距间距误差与相对速度反馈是已有ACC控制形式；例如[2020年原始研究](https://www.mdpi.com/2071-1050/12/18/7568)的§2介绍CTH线性反馈。本项目沿用自己的3m、1.8s和现有增益，未将其称作文献标定的真实交通参数。

## 2. 两种模式共同的响应保护

仅NOA与NOA＋编队共用同一个可见车身候选生成器和应急函数。候选包括本车前方当前占用行驶区域的车辆，以及按观测横向速度投影会切入的车辆；同中心重叠也纳入。

对每辆候选计算当前净距和闭合速度`c=max(v−vL,0)`。下列任一条件成立，当前拍请求紧急制动：

1. 净距不大于3m。
2. 闭合速度为正，当前净距除以闭合速度小于已有TTC阈值。
3. 闭合速度为正，当前净距小于3m加上本车消除该闭合速度所需的响应、制动力建立和制动距离。

第三项使用原`stop_distance()`计算，保留响应时间、执行滞后和jerk。它根据当前测得的闭合状态作短时响应筛查；等速运动时闭合速度为0，不会把整辆车的停车距离强加到正常间距上。前车静止时，闭合速度等于本车速度，可提前识别高速接近静止障碍的制动需要。

普通跟驰仍只选最近前车计算期望加速度；应急检查对全部当前/投影威胁求并集。两种模式使用完全相同的这一候选集合与响应计算。活动换道还保留当前车身重叠保护，物理道路终点继续使用原停车逻辑。

## 3. 编队的速度与几何目标

编队继续按同车道30m、跨车道相位15m的目标选择参考车和补位车。位置误差转换为目标速度时，保留原有最多±2m/s的相对调整，但最终期望速度封顶为共同巡航设定。前车暂时较快时，后车不再逐层继承并继续抬高巡航速度。

普通NOA的时距间距与编队的几何间距是两种期望组织方式；两者共用的是上述响应保护、物理运动模型与巡航设定。修正后可观测到多大队伍、能保持多久，由[编队规模与稳定度评价](编队规模与稳定度评价.md)直接统计。

## 4. 入口与测量段

物理道路在测量入口上游延伸300m，源端接入坐标为−300m，测量范围为0至1200m。两种模式在上游段均执行普通NOA，跨过0m后按各自模式行驶。

每车道保留一个请求FIFO。源端放行速度取入口自由速度与本车道前方200m内最近车辆实际速度的较小值。空隙不足时，请求留在源端队列；已有车辆继续按本车观测运动。代码不会因为请求间隔太短，就从短空隙反算一个很低速度并把新车插进去。当前车流已经慢行时，新车才按实际前车速度接入。

每辆车记录四个时刻：

| 时刻 | 含义 |
| --- | --- |
| `requested_s` | 外部随机需求产生。 |
| `inserted_s` | 在−300m源端实际放行。 |
| `entered_s` | 车中心跨过0m测量入口，积分子步内插值。 |
| `exited_s` | 车中心跨过1200m出口，积分子步内插值。 |

源端未放行等待=`inserted−requested`；上游运动时间=`entered−inserted`；在网行程时间=`exited−entered`。系统时间保留三部分之和。燃油、距离与车辆在网时间只累计0至1200m内的同一段运动，包括边界处不足一个积分子步的部分。

v3数据中，`mean_entry_wait_s`明确指源端未放行等待，`mean_upstream_travel_s`单列上游运动；`mean_entry_delay_s`是请求至测量入口的合计时间。源端队列与上游运动人数分别保存。需求持续超过道路实际接纳能力时的队列仍完整记录。

## 5. 本轮修改清单

1. 删除运动前车的额外舒适停车罩和瞬间硬刹停车差。
2. 合并两种模式的车身/投影切入候选与闭合速度应急检查。
3. 编队期望速度封顶为共同巡航设定。
4. 加入−300m物理上游段；两组在该段均为普通NOA。
5. 源端按实际局部前车匹配速度；短空隙保留请求，不制造低速插入。
6. 拆分源端放行、测量入场、出口及三段时间，燃油只计测量段。
7. 增加规模、参与率、队形误差、速度一致性和关系稳定性的独立物理评价。

旧版持续流结果和源码快照保留为历史实现。当前方法以修正后代码重新执行的批次为准；直路用于检查基础行驶与编队组织，车道减少场景另用于研究合流与瓶颈表现。
