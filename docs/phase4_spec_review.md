# 阶段4规格审查

审查范围：第六版研究规格§6–8和阶段4、`phase4_entry.md`、`phase4_implementation_plan.md`；只读检查 `noa/*`、`configs/phase4.json`、`simulation/noa_clock.py`，并运行登记Python3.12的局部数值复现。生产文件由实现方修改，本审查仅写本文及 `results/phase4/reviews/spec/`。

最终状态：本审查发现的两个可操作问题均已修复并独立复核，当前范围内无未解决的规格缺陷。该结论不等于M1通过；完整真实SUMO驾驶、舒适性与证据门槛由根代理的最终冻结实验判断。

## 已验证问题

1. **P1：速度饱和时把实际加速度当作自车执行器状态，会返回错误的安全预测。** 原 `noa/prediction.py:82–84` 用 `EgoState.acceleration_mps2` 初始化 `VehicleState.a_drive_mps2`。`NoaClock._frame()` 提供的是模型约束后的实际加速度；在最大速度且执行器仍为正、或停车且执行器仍为负时，该观测为零，不能恢复执行器状态。原 `noa/controller.py:98–101` 的制动距离输入也有同一问题。

   - 上限复现：x=100 m、v=33.3 m/s、a_drive=+2 m/s²；局部道路止于245 m；5 s贝塞尔，连续请求−10 m/s²。预测返回安全、检查5.5 s；相同模型与参考的实际轨迹在4.89 s车身越界，5.5 s时x=252.727 m。`cap_candidate.py/json/log` 保存原始证据。
   - 下限复现：x=100 m、v=0、a_drive=−4.5 m/s²；已有参考剩余2.5 s，检查含0.5 s收敛；请求+2 m/s²。后车从x=75 m、v=0、a_drive=+5 m/s²起步，满足已有纵向硬界。预测返回安全；实际自车因制动执行器释放滞后，在2.91 s与后车碰撞。`stop_candidate.py/json/log` 保存原始证据。
   - 制动距离单独复现：上限处按观测0计算138.449 m；真实a_drive=+2时持续硬制动停止距离161.606 m（`probe.json`）。这不是邻车意图不确定性，而是自车内部响应与预测初态不一致。
   - 状态：**已修复并复核**。当前 `noa/prediction.py:45` 的本车执行器上界函数在速度上限且实际加速度为0时，使用继承的正加速度硬界；制动筛选使用这一保守上界。`noa/prediction.py:92–95` 对速度上限/停车且执行器不可恢复的候选明确返回不安全，不新增真值入口。上述两个原始复现重新运行后分别得到 `own_actuator_unobservable_at_speed_cap` 和 `own_actuator_unobservable_at_stop`；原始失败结果保持不变，修复后结果见各自的 `_after_fix.json/log`。控制器24项测试全部通过，含两个边界及上限紧急制动回归。处理范围和初始执行器处于硬界内的前提已在 `phase4_controller_notes.md` 登记。

2. **P2：多车处理后续异常会丢失同阶段已获得的证据。** 原 `NoaClock.tick()` 先完成输入/决策/动作/积分的整个推导式，再写入 `last_record`；后续车辆异常时，前面已计算的结果未进入失败记录，违反提前失败保留已有证据的要求。根代理已改为逐车增量记录。独立复核：后续actor异常保留前面决策、逆序不变、遗漏actor终止3项测试全部通过，见 `clock_regressions.log`。本审查不代替独立重放/哈希审查。

## 通过的规格边界及范围限制

- `decide` 及其规划辅助模块仅消费本车 `ControlInput` 和参数；没有TraCI、文件、全局路网、邻车真类型/真实ID/未来命令或共享计划访问。邻车运算排序使用可见物理量，局部track ID不参与裁决。时钟的全局状态只用于冻结观测和统一物理推进；脚本车只读自身状态与预登记工况。
- 本地记忆保存本车状态、目标、准备/完成时间和本车贝塞尔参考，观测历史由本车传感器裁剪。道路由当前可见边界/标线重建；没有1000/640坐标触发。道路平移和正负小航向的局部重建检查保留同一物理终止点（`probe.json`）。观测裁剪端作为未知区域，不冒称物理车道终点；候选超出已观察完整横截面时拒绝。
- 候选包含所有自车积分段的车身扫掠、道路包络及邻车前后纵向可达占用，覆盖剩余参考及收敛段。邻车纵向使用完整继承加速度/速度边界；当前横向加速度预测界为0，属于配置中明确登记的有限假设，不能据此宣称任意突发横向动作安全。
- 六个要求状态均有入口和持续/退出逻辑；换道准备重查空隙，执行保存本车参考并重查安全。失效时继续原参考并制动是明确的策略范围限制，不是对任意切入的安全保证。没有位置/航向直接设定、隐含配合或中心调度补救。
- 初版稀疏“无空隙”单测中，两辆静止邻车在等待后允许自车从队列前方安全并入，最终x超过车道终点不能单独判为错误；`probe.json`显示7.5 s完成并道。这是工况预期不准确，应保留原失败记录并使用真正连续阻塞队列补充无空隙停车工况。舒适性或驾驶门槛失败仍应保留，不因纯函数、几何复核或记录重放通过而放行M1。
