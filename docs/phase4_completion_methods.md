# 阶段4补齐：方法依据与适用范围

2026-09-11。延续第六版规格；不改14个普通案例、1个压力案例、原硬界/舒适界/误差容差。所有新方法是本研究开发设置，不是品牌NOA标定，也不声称复现下列外部系统。

## 外部资料

- [Berscheid与Kröger，RSS 2021，Jerk-limited Real-time Trajectory Generation with Arbitrary Target States](https://arxiv.org/abs/2105.04830v2)：终态速度、加速度和jerk需要一起考虑。本轮借此核对停车边界的状态语义，没有安装Ruckig，也没有实现其时间最优求解器。
- [Autoware官方PID Longitudinal Controller说明](https://autowarefoundation.github.io/autoware_universe/latest/control/autoware_pid_longitudinal_controller/)（2026-09-11访问）：区分行驶、停车过程、停车保持和紧急控制，并讨论停止前减弱制动及执行延迟。本轮采用本模型推导和既有参数，不照搬其车辆参数。

## 局部纵向控制

原制动距离近似把已在制动的实际负加速度替换成0，导致切入时持续请求急刹；舒适距离阈值又把请求直接切换到−3，与控制周期产生耦合。现在保守响应距离仍保留，jerk斜坡初态使用有符号加速度；低于保守尾部制动力时取较弱制动，保证筛选没有假定瞬间增强制动。对速度饱和且本车执行器不可恢复的情形保留原拒绝与硬上界。

舒适速度上限通过二分求解 `D_brake(v,max(0,a))+v/k <= 可用停车距离`，其中 `k` 是现有0.6/s速度反馈增益。额外 `v/k` 预留速度反馈到达目标的响应距离，不能把速度上限当作即时执行速度。它仍是开发筛选，不是闭环不变集安全证明。对可见前车扣除车身/静止间隔并加入其立即硬制动停车位移；道路物理终点作为静止目标。真实车身安全另由候选扫掠和外部审计检查。

固定规划响应预算0.3s来自原0.1s同步加0.2s执行器滞后，在采样对照中保持相同；要求实际控制周期与滞后之和不超过该预算。这样同步减半不再顺便重调停车距离。该预算没有引入测量延迟或扩大传感器范围。

保守性数值复核只针对当前时刻立即下发指定制动命令的现有时钟语义。这个响应预留不是“先继续任意旧加速命令、延迟一段时间再制动”的可达上界；独立审查保留了该更强解释的低速反例。若未来加入真实执行死区/延迟，必须建立包含等待期正jerk增长的新包络，不能沿用本次保证。

停止捕获在速度≤3m/s、静止前车/终点距≤12+1.8×3=17.4m的局部区域触发。低速请求按 `−v−0.005` m/s²衰减，继承硬界、舒适界、执行器响应与jerk；紧急安全请求不被此舒适限幅覆盖。可见前车再次运动或离开局部间隙后恢复行驶。不直接修改物理速度或执行器，也不把执行器jerk作为实际jerk。

补充半采样暴露了舒适停止目标与最后硬制动筛选位置重合的问题：低速误差仍可能触发急刹、来不及释放制动。舒适目标额外提前3m，原硬停车位置和车身裕量保持不变；该开发余量登记为 `noa_stop_position_reserve_m`。不能把初次原套件通过代替补充对照，其原7.038m/s³失败证据继续保留。

**停车jerk结论的严格范围：** 实际加速度仍按原模型在速度0处投影，有限弱制动尾使该点有约0.005m/s²的小跳变。验收使用原协议的积分子步实际加速度差分，并检查0.01/0.005s；这不构成连续时间jerk有界或任意步长收敛证明。更严格的连续时间终止需要联合规划v和a在同一时刻归零，应另立模型/控制验证，不能由本次数值门槛通过代替。

## 并道与横向控制

执行中的本车参考先以当前实际横向位置相关前车和可见切入约束生成请求，再验证该请求覆盖剩余参考和收敛段的完整车身扫掠。目标车道所有邻车仍进入全时域可达占用；不提前把尚未重叠的侧前车当作已在正前方并强制急刹。只有该实际请求通过完整预测，才解除源车道终点停车约束；预测失败仍保留该终点约束及制动，并单独登记最终回退动作预测，不把未验证的回退解释为安全。

横向跟踪中用 `ÿ=a_long sinψ+a_normal cosψ` 将世界y方向反馈转换为模型的法向加速度。当前自车实际加速度来自原允许的EgoState；预测用同一模型观测自身积分状态。没有读取邻车执行器、真类型或未来动作。实际转向继续经历滞后、转向速率与硬界。

NOA参考在0、T/2、T三个既有事件以1e−9s等时刻容差使用右连续取值，避免同一物理中点因浮点积累落在C1参考的不同二阶分支。模型和阶段3原贝塞尔实现不改；参考仍为两段二次贝塞尔C1，既有跟踪误差审计继续比较原参考位置。

阶段4脚本车也只在原预设起点/中点/终点规范浮点等时刻，避免0.1/0.05s对照在同一时刻使用相反参考分支。预设日程、曲线、初态和增益不变；脚本仍只读取本车状态，不读取NOA行为，不因本车请求安排配合。原脚本执行证据不回写。

新换道计划只在已登记 `behavior_dt_s=0.5s` 的本地行为更新事件启动；等待准备时长满足并在该事件重新验证候选。感知、连续控制、紧急判断、执行中安全检查仍每0.1/0.05s进行。各车独立使用同一公开时钟频率，没有按车辆编号分配时间槽、改变其他车辆动作或共享候选。本研究支持行为周期是同步周期整数倍的设置。

连续巡航/跟驰/终点接近反馈用半周期中点近似：`v_feedback=clip(v+a_actual Δt/2)`，前车反馈净空为 `gap+(v_lead−v)Δt/2`，终点反馈净空为 `gap−v Δt/2`。这些量由当前允许观测计算，不读取未来测量或真命令；制动硬筛选和终末停止仍使用当前状态。候选预测继续用实际最终输出动作，而非该近似反馈状态。此项减少零阶保持的采样误差，不改变反馈增益或假装高频采样仍低频控制。

## 证据要求

旧固定运行与269份哈希保持只读，新尝试独立保存。除原正常换道采样门槛，再登记有空隙并道、无空隙停车、可见切入的同步减半对照；它们是补充敏感性证据，任何未改善或失败均报告，不以事后放大容差获得通过。先前失败的开发实验继续保留。
