## 推荐顺序

1. **停车完成与实际jerk。** 无空隙案例在规定16 s内仍以约1.477 m/s缓慢前行，尚未达到0.1 m/s停车门槛；不能将更长测试中的停车替代该固定工况验收。停止再起步案例则已停车，但实际jerk约50 m/s³。分别重放两类失败，区分执行器加速度、边界限制后的实际加速度和有限差分jerk。先建立可复现失败测试，检查有限时间停车、提前减弱制动和保持停车的局部控制与模型边界语义是否一致；不能在停车瞬间直接把执行器或速度复零，也不能用执行器jerk替代实际jerk。安全、保持停车与再起步分别验证。
2. **执行中参考失效后的恢复。** 使用 `merge_gap_after_queue` 的局部观测和本车参考，分析为何在尚未完成并道时停车、横向误差扩大。改动必须由本车可见几何与可达预测决定；保持、取消或恢复参考均检查连续状态、全时域车身及道路占用。没有安全动作时如实等待/失败，不能安排其他车辆配合，也不能读取队列未来动作。
3. **切入的舒适性与安全权衡。** 对 `observed_cut_in` 定位由可见横向运动触发的减速及行为切换。保留最不利预测假设与急刹压力案例。不能把真实制动超出日常舒适界写成舒适达标；若工况必须牺牲舒适性，应明确结果和适用范围，不事后修改压力案例归类来通过总门槛。
4. **采样敏感性。** 对正常换道的0.1/0.05 s控制感知对照逐步比较PREPARE/EXECUTE触发、纵向命令和实际轨迹。与固定原命令的积分减半分开分析。保留已有未改善结果，重复原工况后再检查代表性工况，不能以增大误差容差替代稳定性证据。

每项按失败测试、单一原因修复、受影响测试与新独立运行验证；所有新增参数登记值、单位、来源、状态和理由。保持此前运行、失败记录、输入快照和哈希不变。再运行完整测试、完整阶段4真实SUMO案例、固定重放和反事实/篡改审计，检查前置阶段仍可重放。

## 放行条件

全部普通案例的驾驶任务、几何安全、跟踪和舒适性达到已登记门槛；积分/采样对照条件通过；全变体证据可复算，局部信息审计与可见信息正例通过；失败与中断记录仍可核对；独立审查无未处理重要问题。否则明确保留M1未通过，继续阶段4，不开展交错结构、交通效率或节能收益结论。

压力案例允许失败，但必须保留原定工况、物理终止时刻、碰撞/越界及舒适性事实。能发现失败或能重放失败都不等于驾驶成功。
