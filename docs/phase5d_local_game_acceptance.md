## 实际实现及参数变化

按[预登记计划](D:/yanjiu1/keyan1/docs/phase5d_local_game_plan.md)，新层仅在R5阻断的非紧急等待阶段、角色依据明确且当前唯一可见参与者时排序本车纵向请求。多参与者、UNKNOWN、缺少当前依据等沿用原固定等待。已提交换道plan、换道准入、最小换道速度、episode/私有随机链、形成规则均不变。

本车候选为原NOA请求、限制为不加速的请求、原R5固定减速请求，经过同一停止尾部与舒适/硬界处理。模型中的对方是leader、本车是follower；这只是本车内部根据可见让行关系作出的定向假设，并不意味着双方达成角色协议或对方知道这张矩阵。

minimax在三个对方假想动作上选本车最坏代价最小的请求。Stackelberg先枚举每个对方动作下本车的完整最优响应集合，再按其中对模型leader最不利的响应选对方模型动作。精确并列按动作数值处理，不用真实ID或私有状态唯一性。**实际只执行本车请求；完整收益表、BR集合、模型选择与实际采用/回退分别保存。**

若模型请求不同于原固定请求，先走原5.5s保持车道守卫；拒绝则回到原固定请求及其守卫；两者均拒绝时，保留原NOA处理。没有把模型对方的假想动作传给它，也没有缩减原邻车硬加速度可达包络。最后一种回退不能写成新模型已获得安全认证。

|新增字段|正式值与含义|
|---|---|
|r5_waiting_policy|minimax或stackelberg；缺省fixed，原OFF和旧无车道优先等待基线固定不启用新层|
|r5_game_horizon_s|5s，仅用于动作排序的常加速度预测|
|r5_game_peer_accel_mps2|0.5m/s²，假想对方动作−0.5/0/+0.5|
|r5_game_gap_weight / speed_weight / effort_weight|1 / 1 / 0.05，分离偏好、速度偏差和请求用力代价|

对方目标5m/s是代理模型假设，不是从观测获得的意图。分离项偏好对方在纵向前方，不能称为碰撞安全证书。所有继承数值不变，包括目标/最低换道速度5m/s、换道5s、控制/感知0.1s、物理0.01s、让行0.5m/s²、clear1s、原舒适/模型/感知限制。未修复旧速度求解端点，未调优权重、重抽种子、延长正式窗口或替换判据。

## 已验证结论、未通过条件及下一入口

本轮证明的是本车内部有限双层求解与守卫接入可实现、可记录和重放；**没有验证主从博弈改善本项目编队效果**。减少部分等待减速度会改变相对位置，从而改变原R5近邻/clear时刻；三份轨迹显示较高的clear时速与更晚清除同时发生。它们随后仍面对真实低速和自身慢前导，不能靠模型最佳响应凭空获得一个可行换道计划。

本轮只有一个活跃新策略的三车物理场景，single_clear主要用于无竞争兼容与数值检查；不是多个独立交通场景或留出集。两包半控制步/0.005s固定动作细化结果只覆盖single_clear，未验证活跃博弈的采样鲁棒性。原几何检查与SUMO原生失败分别保留，不把任何一方静默删除，也不宣称普遍安全、收敛、公平或有限时间形成。

此前留出集无改善、并排无前参考、扰动后未恢复、UNKNOWN保守阻断、停止端执行器不可观测等未通过条件继续有效。下一入口为[阶段5内的低速换道可行域与联合候选研究](D:/yanjiu1/keyan1/docs/phase5_next_entry.md)：先区分真实低速、严格速度门槛/端点、物理走廊和形成守卫，再为实际可行候选加入博弈排序；不能通过强放行或全局调度制造改善。
