# 阶段5E预登记：精确可行速度上端

## 研究问题与单一假设

阶段5D已证明等待博弈不会产生新的换道完成或形成区间。下一入口同时记录了两个不同问题：`_comfortable_speed`在配置上端已经满足原停止表达式时仍返回二分下界，以及等待后车辆真实速度约1.70--1.85 m/s、明显低于5 m/s。阶段5E只处理前者。

预登记假设：若配置上端 `u=min(noa_target_speed_mps,max_speed_mps)` 满足当前同一停止表达式，则连续可行域的最大值就是 `u`，应精确返回 `u`；若上端不满足，继续返回原二分所得的保守下界。修复不得添加速度容差、降低 `noa_min_lane_change_speed_mps=5`、改变换道5 s、邻车可达包络、道路/碰撞/舒适守卫或R5/博弈规则。

## 版本与来源

从阶段5D两份正式包的相同 `code_snapshot` / `input_snapshot` 建立只写新目录 `variants/phase5e_exact_endpoint`。阶段5D目录、正式运行、失败前缀、标准重放、计划及最终交付保持只读。原8案例以 `parent_frozen_r5_cases.json` 恢复；5C扩展另存 `phase5c_extension.json`，不得覆盖原8案例。

根仓库没有git HEAD，不能建立真实git worktree；项目已批准的哈希校验独立variant是本单元的隔离机制。新版本必须记录来源包、克隆脚本和逐文件SHA-256。

## 实现边界

唯一策略语义变化位于 `noa/controller.py::_comfortable_speed`：复用函数内原停止距离与速度反馈距离表达式，先检测配置上端；上端可行时直接返回该浮点端点，否则执行原二分。`experiments/phase5_r5.py`仅增加本计划的输入绑定，不是控制变化。

参数变化：无。特别保留目标速度5 m/s、最低换道速度5 m/s、换道持续5 s、控制0.1 s、物理0.01 s、原纵横向舒适/硬界和有限局部观测。

## 测试与实验顺序

1. 在未改实现上新增两项真实函数测试：精确可行上端必须等于5.0；仅差1e-6 m的不可行上端必须仍低于5且满足同一表达式。第一项必须先有效失败，第二项必须通过。
2. 最小实现后运行阶段4控制/记录、R5控制/案例/记录/重放、5C优先和5D等待博弈相关回归；0失败、0错误、0跳过。未受影响的旧模块沿用阶段5D已封存347项证据，不重复旧车辆实验。
3. 固定策略、原8案例、原初态和私有状态只运行一次新正式包；与阶段5C/5D固定父包按同名变体比较。标准语义重放绑定新源码和输入。

## 固定指标和解释边界

逐方法、逐变体记录：求解上端与返回值、首次PREPARE、首次提交plan、完成换道数、最小/均值/末速度、低于5 m/s时长、候选/守卫拒绝原因、完整/失败前缀、形成/候选区间。OFF和ON分开，不用一次OFF变化替代R5结论。

工程通过要求：端点测试通过、不可行分支仍保守、受影响回归通过、正式运行全部已启动变体有可追踪终态、标准重放通过且源码/输入前后相同。科学结果允许无改善或恶化；阶段5形成、保持、恢复门槛仍按旧定义判断。修复端点不等于解决真实低速，也不自动开放阶段6。

## 禁止项

不使用隐含通信、车型真值、真实ID优先、邻车私有意图、全局槽位或中心调度；不缩小邻车可达包络，不压制SUMO失败，不重抽初态/seed，不从结果选择门槛、窗长或规则。
