## 2. 指定论文：作者原有假设与结论

### Geary 2021：角色冲突并非优化器精度问题

**作者论述。** 第1-3页、Section III把Conflict定义为：未就leader/follower达成一致，双方算出不同纯策略均衡。第4页、Section IV-B例子中，双方都自认leader会执行“前插/不让”，双方都自认follower会共同让行并无法完成。第3页仿真假设规划时完美知道双方状态；第5页、V-A明确假设双方知道真实收益矩阵和双方利他参数。V-B式(3)的Augmented Altruism同时依赖两方参数；第6页Table I与Appendix A/B表明降低的是限定收益与参数范围内的冲突面积，并未消灭全部冲突。[全文](https://www.roboticsproceedings.org/rss17/p049.pdf)

**作者实验边界。** 第6-8页的11名参与者、超过1400次示范支持对人类决策的有限模型比较。第8页、VII-A还主动告知人类对方更激进/更被动的信息；该实验不能用来证明只靠本项目被动局部观测即可取得邻车利他参数。[全文](https://www.roboticsproceedings.org/rss17/p049.pdf)

**我方推断。** 本车求解双层优化不会自动产生另一车可见的承诺或一致的角色。5C从物理几何得到的让行关系可以作为本车条件模型的定向依据，但不能升级为双方共同知识。直接复制Augmented Altruism需要当前接口中没有的真实收益和双方参数；猜测值只能登记为模型假设。论文“减少冲突面积”也不是本项目公平性、无死锁或有限时间完成证明。

### Wang 2019：本车可自行计算对手优化，但这是Nash近似框架

**作者论述。** 第1页明确无显式车间通信；第3页、III-A说明对方规划轨迹不可获得，玩家无信息优势，所以采用Nash而非Stackelberg。已知赛道、竞争进度目标、模型与碰撞约束用于本车内部交替求解。第4页、III-B仅给出“若SE-IBR收敛，则满足Nash必要条件”的有条件结论；第6页Algorithm 1实际设L=2，不等收敛，并只在预测轨迹前半段强制曲率约束。[全文](https://www.roboticsproceedings.org/rss15/p48.pdf)

**作者实验边界。** 第7页RC实验由Optitrack广播双方位姿，单台笔记本分别跑两规划器；第8页实车与模拟车通过ROS传输GPS/模拟GPS作为感知替身，除状态外规划独立。论文主要是GTP对较保守MPC的赛车比较，并未验证本项目有限视野、遮挡、失联关联和慢前导换道恢复。[全文](https://www.roboticsproceedings.org/rss15/p48.pdf)

**我方推断。** “在本车内部为对手解一个模型”不等于隐含通信，前提是所有输入来自获准观测和公开假设，且不向真实对手发布/读取解。但是，该论文不能支撑“本地求解一定收敛”或“对手一定让出安全空间”；更不能用其预测碰撞约束替换本项目原可达占据守卫。其Nash标签也不能当作本轮主从求解的文献背书。

## 3. 两篇补充能借鉴什么

**Li 2018，作者方法与限制。** 第2页、II-B/C给出有限动作和滚动时域，只执行首动作；第3页、III用level-k预测另一车为level-(k-1)，并明说预测对手动作独立于本轮最终ego动作，以避免相互嵌套。第3-4页、IV、式(7)-(9)依据对手实际动作与各模型预测的差异更新信念；若所有模型预测相同则不更新。第2页state包含路口所有车辆状态，未提供本项目式有限观测证明。第4-6页仍存在失败，Auto-vs-Auto冲突解决率93%，不是100%；碰撞项采用有限惩罚。[全文](https://repository.bilkent.edu.tr/server/api/core/bitstreams/b9f35899-5528-40c4-ba4a-52a946eba854/content)

**我方推断。** 可借鉴有限动作、个人记忆、模型不可辨识时不更新；不应把level-k等同Stackelberg双层优化。当前接口若不提供邻车真实动作，可用连续可信局部状态差分获得加速度区间，而不能读对方控制命令。该估计需要明确噪声、采样与关联处理；失去唯一关联时不能沿真实ID续接。5D暂不新增估计器，使用固定假设并承认未知更易独立验收。

**Bouzidi 2025，仅摘要可证实的内容。** 作者称通过邻车横纵响应、无通信且不直接访问邻车目标函数，使用LSTM逆微分博弈估计可能的路径跟踪目标，再进入滚动博弈控制，并以CarSim及人在环案例评估。[出版社摘要](https://www.sciencedirect.com/science/article/pii/S0921889024002926)

**我方推断与未核实项。** 该摘要说明“未知效用可尝试估计”有直接研究路线；并不说明估计无偏、可唯一识别或能覆盖任意驾驶策略。全文、训练信号与数据、状态/观测边界、误差界、在线算力及安全约束均未读到，本文不据此采用其训练/控制方法或承接收敛安全结论。

## 5. 对已提出5D方案的独立数学审查

以下为我方设计建议及对root方案的审查，不是上述作者论文的复刻。

适用域限定为R5仍blocking、非UNKNOWN、有唯一可信物理参与者且既有几何角色理由充分。否则完全走原fixed-yield。已提交换道计划、5C准入/让行关系、clear期、minimum 5 m/s、动力学和whole-hold安全守卫都不变。

设`a`为ego等待纵向请求，`b`为本车模型中的peer请求：

```text
A_E = deduplicate({base, min(base, 0), original_fixed_yield})
A_P = {-0.5, 0, +0.5}
H = 5 s
J_E(a,b), J_P(a,b) = 登记的端点间距不足² + 自身端速偏离5² + 0.05×自身请求²
```

这构成至多3×3有限动作表。代价只对预测作排序，间距不足项不能作为碰撞证明。预测速度上下界截断需要对位置做对应分段积分，例如先减速到0，再保持停止，不能仅夹末速度而继续使用会穿过零速的整段二次位移。已有预测半车长、margin与standstill构成D时，应逐一标明单位/来源；新权重0.05、离散peer集合、H和目标5代理须显式登记为新预测模型参数，而非宣称所有参数完全未变。

**方法A：有限分支最坏情形对照。**

```text
a_A ∈ argmin_(a ∈ A_E) max_(b ∈ A_P) J_E(a,b)
```

这是相对三种假设预测的minimax，不是Stackelberg；它也不是面对邻车所有真实可达动作的鲁棒最优。全部安全仍来自原守卫。

**方法B：真实存在内外两层最优响应的条件主从模型。**

```text
BR_E(b) = argmin_(a ∈ A_E) J_E(a,b)           # 保留全部并列BR
V_P(b)  = max_(a ∈ BR_E(b)) J_P(a,b)         # 对leader悲观的follower并列响应
b_B ∈ argmin_(b ∈ A_P) V_P(b)                # leader外层最优
a_B ∈ argmax_(a ∈ BR_E(b_B)) J_P(a,b_B)       # 与悲观外层一致的模型响应
```

所有求解在ego内部完成。只要下层确实针对每个b分别优化ego成本，上层在这些BR上优化peer成本，而非简单给固定优先规则换名，这就是一个有限模型中的悲观Stackelberg求解。有限集合非空、代价有限时，可枚举得到模型解；没有迭代收敛难题。数值并列容差如非零，结果应称容差下的近似BR，并保留容差定义。最后仍有多解时，用预登记的动作数值/语义规则，不能用actor ID或邻车列表顺序。

“悲观”的对象须说清楚：上式是**对leader**而言的最坏follower最优响应，不等于对ego或道路安全最坏。若改为在`BR_E`内挑对peer最好的ego响应，则已变成乐观Stackelberg，必须更名。外层`b_B`并列时，也应明确统一tie规则；不能执行一个与用于`V_P`计算不一致的BR后仍报告同一悲观策略对。

**执行与安全。** 模型选中a后，通过原whole-hold guard才申请执行；拒绝则回退原fixed-yield并仍通过原守卫/原回退路径。被拒绝的`a_B`和实际回退动作应分别存储。回退动作一般不再是原模型表的BR，不能记为“Stackelberg均衡已执行”。纵使guard通过，准确说法也只是“执行了本车内部模型选出的ego请求”，真实peer没有承诺执行`b_B`。

### 需要明确但不要求追逐成功的设计点

- **横向优先与纵向顺序不同。** D对应的间距应写成明确表达式。如果用`max(0,D-(x_P-x_E))`，是偏好ego留在peer之后；如果用`max(0,D-abs(x_P-x_E))`，允许从任意一侧拉开。两者目的不同，不能靠上方优先暗中推出纵向leader关系。
- **5 s端点目标不约束中途。** 两车可能中途相交而端点分离，也可能在5 s后才受慢前导限制。保持原守卫可阻止越界动作，但端点排序的效率意义仍需实测。
- **代理目标5未必反映peer。** 即使这是ego的真实目标，也不证明peer目标相同；peer已在5左右时其最佳假想动作可能反复为0。这可能让双层解退化为固定预测，不是假阳性成功，但应保存并报告动作/BR实际多样性。
- **同一间距项不等于组效用。** 即使两方代价共享间距不足项，只要各自速度/用力成本不同并按上述两层分别优化，仍是双层模型；如果实现直接最小化两方成本之和，就变成联合目标优化，不可再称主从BR。
- **已知限制作为结果。** 唯一参与者条件会放弃多车互动；UNKNOWN与遮挡继续保守，几何角色仍不保证全局一致或公平。不要为提高触发率而读取隐含意图或放宽可见性。

## 6. 对5C失败的实际作用边界

项目事实来自 [5C验收](D:/yanjiu1/keyan1/docs/phase5c_lane_priority_acceptance.md) 与 [5C通行诊断](D:/yanjiu1/keyan1/docs/phase5c_liveness_diagnosis.md)，不是文献结论：上方5.6 s完成换道，但仍处于后车的可见竞争near集合；其后到17.1 s退出，原1 s clear期使下方18.1 s才清除episode，速度约0.03236 m/s。下方5.58 s首次保存的物理速度低于5；清除后30 s窗口最高约4.51093456 m/s，并受自身2 m/s慢前导与B1路径影响。真实短缺约0.489 m/s，不能归结为5 m/s数值端点。

**我方推断：** 新等待动作选择最多改变清除前的速度损失与相对纵向几何，也许减少无必要减速，但没有凭空创造minimum 5之下的换道计划。保持minimum与守卫时，若任一可认证等待动作都无法使本车保持/恢复到5，方法B即使模型求解完全正确，也可能继续不换道。慢前导限制、物理走廊占据、clear期、UNKNOWN以及参考选择仍可能独立主导结果。安全约束与不合作邻车允许阻断持续存在，因此没有无条件有限完成或编队证明。

下一轮比较应同时保留固定等待、方法A和方法B，原场景/数值/随机私态一致；记录模型触发次数、全部代价/BR、请求差异、guard拒绝及fallback、低于5首次时刻与累计时间、episode清除时速、清除后峰速、换道提交/完成和原形成检测。只需一个可独立验收单元；若A/B均未改善，应照实保存。论文阅读本身不开放阶段6。

## 7. 验收建议与声明边界

建议实现审查核实：一个下层BR会随peer动作改变的手工矩阵、一个多BR悲观tie矩阵、纯minimax与双层结果不同的矩阵、动作去重/顺序不变性、非法/UNKNOWN/多参与者回退、预测速度饱和积分、guard拒绝后保留模型与执行区分、禁用开关对5C逐拍等价。这里提出的是对非平凡行为变化有意义的验证点，本文没有运行或虚构这些测试结果。

允许表述：“本车依据局部观测，在有限假设动作与代理效用下枚举了一个主从模型；实际请求仍受原守卫约束。”

不允许表述：“邻车被识别为真实leader/真实合作类型”“对方必然让行”“双方达成Stackelberg或Nash均衡”“所有局部博弈总能收敛并恢复编队”“不改最低速度也已解决低速入口”。
