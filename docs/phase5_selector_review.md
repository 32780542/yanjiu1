## 规则核对

`confirmed_coverage` 按 `[formed_time_s,end_time_s)` 的分段最大组人数积分；确认之前的时间不回填，最终有效样本不额外延长一个控制周期，多个组不作人数求和或成员并集。分母为案例的固定人数 N 和完整持续时间。缺完整起止时间、存在采样缺口或执行不完整时 C 为 null；不补尾。开发得分只取六个预登记随机案例，六个 C 等权平均，事件和结构单元不进入分母。

资格检查覆盖全部十个普通 on 案例，要求完整执行、实际 driving 与原 comfort 条件通过，并保留固定数值对照的通过要求。资格成立后按六随机案例整体成功数、等权 C、绝对容差 1e-12 内固定 B1 的顺序选择。整体不形成或 nonrecovery 本身不作为证据损坏。没有合格 B 时保留 B1 作为明确不可推荐的诊断代表。C、成功次数及失败原因仍在输出中保留。

已尝试并被标准重放确认的物理失败前缀可进入汇总，其执行失败、失败原因、C=null 与失格状态被保留，不要求重跑到成功。缺 case、源文件不一致、无效记录/隔离、缺失重放覆盖或顶层与案例摘要不一致则拒绝正式选择。两类失败没有混为一谈。

跨副本比较同时检查完整 case 字典、initial、scripts、duration、requirements、道路、模型、物理/控制参数、去掉规则枚举后的共同 policy，以及各检测器参数。相同 OFF 用完整 trace 的字节或逐 JSON 记录语义相等校验；只有两侧均完整时标记允许合并完整窗口。选择器对 A 的全部十个案例再调用一次新 `-I -B -S` 进程生成，要求完整字典及源码摘要相等；B case 必须与 A 相等且共享相同生成器源文件。

## 绑定与适用范围

绑定入口执行显式副本的登记 Python、固定 `run.py phase5-replay` 与精确 source 路径，保存源码/输入/证据的前后摘要、命令、解释器摘要、stdout/stderr、标准回放的 source 身份、状态与输出文件摘要。消费绑定时重新验证这些字段，并在选择完成后再验证一次。预登记清单、v2 澄清和 heldout 初态清单绑定固定 SHA-256；读取 heldout 初态用于冻结未来输入，不是读取其结果。

绑定摘要是本地完整性证据，不是外部签名，也不能单独证明伪造整个执行环境后的文件来源。正式运行仍必须使用已指定的真实 A/B 源包与实际执行生成的绑定目录；本次合成管线的通过不能替代这些标准回放。这一边界与工具 README 的声明一致。

无参数变化、增益/安全容差搜索、重选方法或结果改善声明。本次开发选择仍未启动，不能提前宣布 B 的科学资格或胜者。复现探针时将保存的探针原字节复制到另一新目录，并在根工作区经 `scripts/run_logged.py` 运行，以生成全新复制包；既有失败与日志不得覆盖。
