# 阶段5F预登记：速度自适应换道时长候选

状态：**仅登记与父证据诊断；生产实现和正式车辆结果尚未开始。** 本单元仍属于阶段5，阶段6/7/8保持关闭。

## 单一研究问题

当R5与可见车道优先已经启用、真实本车速度低于旧5 m/s准入门槛时，有限候选时长5.0、7.5、10.0 s中是否存在同时通过运动学必要条件、当前R5局部竞争门和原 `verify_candidate` 全时域守卫的本车换道候选？无候选、未完成、碰撞、舒适或形成失败均原样保留。

不把一次提交、一次换道、稳定参考或局部单车通行解释为全队形成、恢复、公平、互斥、交通收益或一般安全。

## 冻结机制

- 顶层模式只有 `fixed` 与 `adaptive_duration`。fixed必须保持5E行为；adaptive只对 `r5_enabled=true` 且 `r5_lane_priority_enabled=true` 生效。R5-off和关闭车道优先的waiting基线保持fixed。
- 候选时长严格按 `[5.0, 7.5, 10.0]` s升序枚举。采用当前测得的正本车速度，不再把计划速度抬到5 m/s。
- 二段二次Bezier峰值参考横向加速度为 `4W/T^2`。硬转角运动学必要速度为 `sqrt(4WL/(T^2 tan(delta_max)))`。
- 冻结 `W=3.3 m`、`L=2.7 m`、`delta_max=40 deg` 后：
  - 5.0 s：峰值0.528 m/s²，必要速度1.3034431025565734 m/s；
  - 7.5 s：峰值0.23466666666666666 m/s²，必要速度0.8689620683710490 m/s；
  - 10.0 s：峰值0.132 m/s²，必要速度0.6517215512782867 m/s。
- 三个峰值都低于原2 m/s²舒适界，但该条件只允许进入验证，不证明跟踪、安全或完成。
- 0速继续由 `own_actuator_unobservable_at_stop` 拒绝；低于所有时长必要速度时物理候选数为0。
- 每个可建候选都先按候选自身持续时长评估R5竞争范围，再用原纵向请求调用未修改的 `verify_candidate`。只选择首个、即最短的真实safe候选；无safe候选不准备、不提交。
- 不修改邻车纵向硬加速度可达区间、横向假设、道路重建、扫掠深度、车身余量、舒适/硬界、制动、形成判据、R5优先/随机/博弈权重或活动计划的逐拍复核。
