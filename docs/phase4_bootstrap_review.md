- **连续状态与时钟：** 两个初始化SUMO区间均显式排除；本次0.1 s同步配置的物理零点对应SUMO 0.2 s。初始化完成后全部车辆按既有FleetBridge逐车核验位置、航向、速度、时刻、碰撞和传送报告。之后仍是模型积分、统一提交端点、一次SUMO步进；没有把初始化搬移算作真实驾驶轨迹。
- **安全含义：** `sumo_external_min_gap_m=0`只改变外部SUMO载体的原生间距设置；命令仍为 `--collision.action warn`、`--time-to-teleport -1`。对首次冻结运行源码逐文件SHA256比较确认，FleetBridge、ExternalBridge、运动学、车身变换、独立扫掠几何审计、NOA控制器/预测、安全相关阶段4配置和预定小案例均未改变。碰撞报告仍导致同步失败；没有以原生间距参数替代NOA跟驰距离或车身几何裕量。
- **失败保留：** 默认间距对照失败留下输入、命令、路由、原始SUMO日志、插入请求、实际插入ID、已执行初始化步数、异常与堆栈。成功与失败均使用独立目录。首次 `merge_no_gap` 的无物理轨迹失败与其他探针目录保持保留，修复不把旧失败改写为驾驶成功。
