## 冻结设计与备选

对照是已封存 R5 私有期限放行法。新法仅在 `noa/r5.py:advance_backoff` 的已有 deadline 分支增加 if/else：

1. 未到期限：原 BACKOFF、阻断、原让行制动。
2. 期限已到而当前 reason 为 ambiguous：保留本车 deadline、episode、随机状态和抽样数，phase 为既有 YIELD，blocking 为 true，reason 为 `expired_ambiguous_wait`。
3. 期限已到且有可见本车前方优势：原 ELIGIBLE；仍须原速度、准备、行为时钟和全部候选守卫。
4. 已进入、可见向内运动、可见他车前方优势、UNKNOWN、稳定清除和新目标逻辑完全沿用原规则。期限等待不能抵消可见让行条件。

不增加重抽、车型/ID优先权、邻车隐藏记忆/计划、全局槽位或中心协调。保守规则可能使对称双方持续等待乃至停车；零碰撞报告不代表通行、编队或一般安全证明。

曾考虑改变退避制动或修复速度上端，但会同时改变纵向状态/门槛，难以隔离本次放行规则作用，故本单元不做。也不扩大随机期限来针对已知1/2私有状态选值。
