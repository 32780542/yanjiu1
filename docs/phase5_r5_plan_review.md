## 审查中发现并已闭合的问题

1. **已进入者被自己的空隙边界排除。** 初稿先由目标车道占位求空隙，再要求潜在竞争者与自车处于同一空隙，最后才判断 `yield_entered`。部分跨线邻车可能本身就是前/后占位边界，或者与自车纵向投影相交，从而无法进入显式让行分支。最终 §2 改为近邻相关的已进入者/可见向内运动先判断；普通未进入者才使用占位闭区间并集的补集开区间。已给出 `(105,7.4)`、`(95,7.4)`、`(100,7.4)` 相对自车 `(100,1.65)` 的前界、后界和纵向重叠三个必须显式让行的测试，另测仅接触边界。这个修正使分支可达性可独立验证，而不是由原守卫拒绝掩盖规则未实现。
2. **优先关系覆盖退避后可能丢失期限。** 初稿未完整定义 BACKOFF/ELIGIBLE 暂时转为明确 YIELD 或关联未知后的锁存。最终 §3 将当前 phase 与 episode 的 deadline 分开：YIELD/UNKNOWN 可以保存未抽样、未来或已经到期的期限；回到 ambiguous 复用原期限，只在同 episode 首次 ambiguous 且 deadline 为 None 时抽样。仅明确新 episode/连续 clear 确认才清期限，随机状态和累计计数终身保留。§4 同时补齐“只有 YIELD 而没有 ambiguous”也提交自身状态但不抽样，以及时钟/消退在新候选循环和速度门槛之前更新。
3. **关联界与字段定义原先不够具体。** 最终 §3 给出惯性位置/速度、包角 heading 和尺寸的匹配式、唯一一对一集合匹配、前后界角色关联，UNKNOWN 已加入明确 phase schema。匹配不借用编队参考的低横速资格，丢帧不把缓存扩大为长期不可见轨迹；零或多匹配不能被解释为新身份或每帧新 episode。当前获准运动学模型中，切向加速度绝对界加法向 `v²|tanδ|/L` 上界可包住世界加速度分量；该界只说明物理兼容性，不能证明真实身份或安全。
4. **响应参数措辞已纠正。** 最终 §4 明确执行器滞后 `acceleration_lag_s=0.2s` 与规划响应 `noa_response_time_s=0.3s`，均保持原值，避免将二者误认为同一参数。原型工作目录与控制测试归属也已统一为独立 common 副本。

以上均在车辆运行和原型实现前闭合；没有通过后验表现选择这些修正，也没有改变旧 A/B 比较。

## 保留的失败与适用范围

- 可见向内运动优先是初版预先公开的保守物理线索，符合局部观测要求，不读取意图。它可能把本车道回中误当竞争；低于 `0.05m/s` 的刚启动横移和双方同 tick 开始仍有盲窗。原邻车额外横向加速度界保持 **0**，没有新增安全证明。
- 不同私有种子不保证不同截止时刻，不同截止时刻也可能量化到同一行为事件。相同私有状态的对称反例不得用 ID 修复。随机机制不保证互斥、公平、有限时间并入或对非配合车成功。
- 目标速度和原换道最低速度均为 5m/s。退避后从下方恢复可能只渐近接近门槛；ELIGIBLE 只代表计时已到期，不能解释为一定重新启动。既有门槛和目标均不调松。
- 匹配硬上界较宽，多个兼容匹配可能导致持续 UNKNOWN；这是需要记录的保守阻塞。唯一兼容匹配也不是拿到了邻车真实身份。
- 更减速不对后车或侧车安全单调有利；新增减速若未通过原 guard，只能报告 `yield_not_certified` 和真实 fallback 后果。已执行机动保留原轨迹与制动也不构成一般安全回撤。
- 新 R5 只在独立版本实现，不进入 B 候选选择，不修改旧 A/B、heldout 或 v1 结果。旧比较不能充当补齐版的实验验证。原阶段 5 科学失败以及阶段 6 不放行的边界不会因计划通过自动消失。
