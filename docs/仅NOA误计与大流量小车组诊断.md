# 仅NOA误计与大流量小车组诊断

核查日期：2026年10月28日。核查对象：修正NOA后的三车道主实验，4个需求率、3个种子、两种模式，共24例。原始轨迹和控制器保持原样。

本次核查确认：上一份报告把“局部几何匹配车组”写成了“编队规模”，这个表述不成立。仅NOA确实没有启用编队控制；它被计入的是偶然并排或交错的车辆。编队规则组在大流量下也没有形成预期的持续多层队伍，主要问题是追赶能力消失与补位前置条件过严。

## 一、仅NOA为什么会被算成编队

`experiments/platoon_metrics.py`的识别方法是：两辆车只要车道中心、相对位置和速度满足阈值，就连一条边；至少两辆车的连通分量就记入`mean_platoon_size`等字段。它没有要求三条车道全部占满，也没有要求存在上下两层。因此，下方与上方车道两辆车恰好并排，即使中间车道没有车，也会被算作一个二车组。

实际例子来自仅NOA、每道1250辆/h、seed1：43s时，下方和上方各有一辆车，纵向位置都为19.68m，速度都为28.8m/s。这两辆车被连边；这个二车组没有中间车，也没有前后层。

本次逐帧复查得到：

- 12例仅NOA的编队控制开关均关闭，补位换道次数均为0。
- 共17892个匹配车组观测，其中17851个为两辆车、41个为三辆车；所有观测都只有一层，符合30m目标间距的同车道边为0。
- 11105个观测仅由上、下两车组成，中间车道缺位。
- 以上数量是“车组×采样帧”，同一车组持续出现会重复计数，不是17892支独立队伍。

这说明原统计测到了相对位置相似性，却没有证明编队形成。仅NOA全部车辆均速行驶，相对位置自然可以长时间保持；原先约88%的关系保持比例，也不能解释为NOA执行了稳定编队控制。

本次保留原始数值，将这些表和图明确改称**局部几何匹配**。JSON/CSV中的`mean_platoon_size`等旧字段名保留，便于复算；其含义按这里更正。控制开关、局部相似关系、完整队形形成分别说明。

## 二、大交通流量下为什么仍然长不成大队

### 1. 入口间距约60m，目标间距却是30m

当前入口采用普通NOA的1.8s时距。主场景所需中心间距为：

`车长4 + 两侧余量0.3 + 静距3 + 1.8×28.8 = 59.14m`。

控制步长0.1s，实际最短放行间隔为2.1s；匀速行驶时同车道中心间距为`28.8×2.1=60.48m`。主实验12例仅NOA的实际最小间距与各例间距中位数均为60.48m；编队规则组各例中位数也为60.48m。

2000辆/h是请求率，共同源端的饱和供给约1714辆/h/车道。提高请求率主要增加源端未放行需求，不能直接把已经入场的60m间距压成30m。

### 2. 我上一轮的巡航封顶同时取消了追赶余量

`noa/simple_formation.py:formation_acceleration`先根据参考车速度和位置误差计算期望速度，再用`noa_target_speed_mps`截断。当前前车与后车都已达到28.8m/s，后车即使距目标还有30.48m，期望速度仍被截回28.8m/s，加速度请求就是0。

已直接调用真实规则函数复现两个例子：

| 可见车辆 | 位置误差 | 加速度请求 | 层窗与补位结果 |
| --- | --- | --- | --- |
| 同道前车在60.48m前方，属于独立车群 | 30.48m | 0m/s² | 选到前群纵向参考，但无法接近；本层窗为头层。 |
| 增加一辆跨道车辆，使本车与前车连通 | 30.48m | 0m/s² | 选到同道前车，60.48m层距使层窗不稳定，补位被拒绝。 |

统一道路限速和避免参考车速度逐层抬升是需要保留的条件；把正常巡航值同时当作所有追赶动作的上限，使已达巡航速度的后车失去了接近前队的能力。这是上一轮修改带来的形成能力问题。

### 3. 补位之前要求随机车流已经排列稳定

`layered_window`要求窗口里的车都接近同一30m层格，同车道相邻车辆也必须接近30m；`choose_layered_fill`只要发现层窗不一致、横向移动或速度不稳，就返回`layer_not_stable`。

持续随机到达的车辆尚未形成目标间距时，往往已经在这个入口被挡住。后车无法追近，补位又等待纵向排列完成，形成规则难以启动。

24例原始逐车台账中的实际换道为：

| 每道请求率（辆/h） | 仅NOA，3个种子总换道 | 编队规则组，3个种子总补位换道 |
| --- | --- | --- |
| 1250 | 0 | 3，分别为0/1/2 |
| 1500 | 0 | 0 |
| 1750 | 0 | 0 |
| 2000 | 0 | 0 |

因此，1750与2000的6例大流量编队实验没有发生一次补位换道。原图中的车组规模主要反映车道头车的局部速度调整和偶然几何匹配，不能代表补位规则已在大流量下发挥作用。

### 4. 600s车流并不等于每辆车有600s整队时间

主场景1200m、28.8m/s，每辆车在测量段仅停留约41.7s。600s是持续生成车辆的时长，后来车辆仍然只有一次道路通行时间。当前规则没有在这段时间内持续压缩间距和补齐层位。

## 三、按现有完整队形标准再检查一次

本次还使用既有`phase5_detection._component_measurement`检查每个50m纵向连通物理车群。该函数检查车道人数分布、同道30m间距、同层交错、速度差及车道归属。

仅NOA偶然出现2帧合格的三车单层；编队规则组出现171帧合格的三车单层。所有合格样本均只有一层，**没有一个合格的多层物理车群样本**。这里报告的是单帧几何检查；形成确认还应包含连续保持，不能把这些帧数直接写成形成次数。

这与原“最大匹配分量8辆”不矛盾：后者允许从周围未排好的车群里抽出一部分局部匹配关系，没有验证整个物理车群符合目标队形。

当前研究结论应写为：基础NOA通行已恢复正常；持续车流下的完整多层形成仍未实现。原2.21–2.47辆均值和最大8辆属于局部几何匹配统计，撤回其作为完整编队规模成果的表述。

## 四、本次修改与接续位置

本次完成轨迹复查、规则函数复现和报告口径纠正，更新了绘图标题和标签。控制器、发车规则、识别阈值、原始轨迹以及原统计数值均未改变。

下一轮形成规则需要解决两个相连的问题：让尚未排好的车辆具备可实现的纵向接近方式；让补位的稳定条件检查本次动作所需的局部关系，避免等待整个90m窗口先排成目标队形。新的形成结果应使用完整车群的车道占位、层距、相位和持续保持共同验收。
