# 持续车流中的编队规模与稳定度评价

本协议补充持续车流的直接编队评价，回答“有多少车辆实际组成编队、队有多大、相对队形是否精确、关系能否持续”。它不使用有限车群的 `N=4L`、每道4车、整队同时形成或末车入场后观察200s的判据。交通效率、平均速度、燃油和接触事实继续按各自协议报告。

实现为 [`experiments/platoon_metrics.py`](../variants/phase5g_pure_formation/experiments/platoon_metrics.py) 的 `evaluate_platoons`，输入只读 `positions.jsonl.gz`：

```python
from experiments.platoon_metrics import evaluate_platoons

result = evaluate_platoons(
    "某次运行/positions.jsonl.gz", lane_count=3, gap=30., offset=15.
)
```

每行格式是 `{"time_s": t, "states": {"车辆记录键": [x, y, v, a]}}`，单位为s、m、m/s、m/s²。只读取实际位置、纵向速度和采样时间；加速度仅校验数据完整性。车辆记录键只用于离线追踪同一车辆对，不读取控制器角色、槽位、期望跟随目标或通信状态，也不向控制器提供结果。

## 1. 先定义可观测的物理编队

实际在网车辆集合为 `0 <= x < road_length`，默认 `road_length=1200m`；尚未入路的入口队列不在其中。车道从下往上编号 `l=0,...,L-1`，中心为 `(l+0.5)*3.3m`。本拍与某车道中心横向偏差不超过0.3m的车辆才能建立编队边；横向偏差较大的在路车辆仍计入参与率分母。

从最高车道往下的相位偏移依次是0、15、0、15m：

\[
\delta_l = \begin{cases}0,&(L-1-l)\text{为偶数},\\d,&(L-1-l)\text{为奇数},\end{cases}
\qquad z_i=x_i+\delta_{l_i},\quad d=15\mathrm{m}.
\]

同车道目标中心距是独立参数 `D=gap`。D可以是24、30、36m，不要求D=2d。

每拍建立无向物理图，连边还要求端点速度差不超过0.5m/s：

1. 同车道：先将符合车道中心条件的车辆按纵向位置排序，仅检查其中相邻的前后车辆，要求 `abs(abs(x_i-x_j)-D) <= 2m`。
2. 不同车道：对本车和每一其他车道，寻找相位坐标最接近本车`z_i`的车辆，要求`abs(z_j-z_i) <= 2m`。它只连接同层，两个方向的搜索结果取并集。距离相同的候选按实际距离、记录键固定取舍。记录键不影响在线动作。

跨车道只连接同层，层与层之间必须由实际同车道D间距连接。这样，同车道60m间距不能通过跨道对角边绕过缺少的30m中间层，被串成一个大队。所有不同车道均可比较；同相位非相邻车道的同层对齐也属于被测结构。

每个至少含2辆车的连通分量定义为本拍物理编队，人数包含全部成员；孤立车不成队。连通分量天然不重叠，每辆车最多计入一个编队。允许同车道两车小队，也允许不满层和不满全部车道的局部编队；这里没有“全车道完整交错大队已经形成”的含义。连边速度条件是局部条件，长链可能累积更大速度差，队内速度RMS会保留这种事实。

**0.3m、2m、0.5m/s、至少2车、5s确认和1.01s最大采样间隔，均是本研究设定，不是文献给出的普适稳定性阈值。** 图定义也是本研究针对无通信局部自组织系统的离线观察约定。D、d、车道宽度和道路长度按保存的实验参数传入；不得针对结果修改阈值。比较不同规则时使用相同评价参数。

## 2. 采样、时间权重与开放边界

现有持续车流轨迹约每1s保存一帧。对于相邻有效采样 `t_k,t_(k+1)`，以左端已观测物理状态保持到右端，权重为实际 `Δt_k=t_(k+1)-t_k`。第一帧之前和最后一帧之后不补时间；因此末帧有可能影响“观察到的最大规模”，但不凭空增加车辆秒。1s数据不能复原两帧之间的瞬态和确切出界时刻，这些指标是该采样分辨率下的估计。

默认相邻帧间隔大于1.01s时记为采样缺口：整段不贡献车辆秒或质量指标，原有边在缺口前删失，下一帧重新开始关系计时。半秒等更细采样直接按真实时间加权；若明确使用2s采样，调用时须显式设置 `max_sample_gap_s`，不能让缺帧自动获得稳定保持时间。非有限数、结构不完整的状态、重复或倒序时间直接报错，不静默当作空场。

持续600s生成请求的实验，宜对该请求批次完整记录至入口余队和道路排空；所有已经实际入路车辆按记录贡献暴露时间。该函数只看到物理轨迹，不能从中恢复尚未入路的排队车辆或未保存的排空尾段。比较时必须列轨迹起止时间、有效观测时长和采样缺口数，必要时另外区分持续入流段与排空段。

物理边的连续性由同一记录键对追踪，以下结束原因区别处理：

- 前后两帧端点都仍在 `0 <= x < 1200`，而边消失：记一次内部断裂，包括几何、速度、车道中心条件或最近邻关系不再成立。
- 端点越界或不再出现在轨迹：删失，不记内部断裂。只凭positions文件无法区分正常退出和个别车辆记录丢失，二者都按不可继续观察处理，不声称全部缺失都是正常退出。
- 整段记录结束或出现采样缺口：现存边删失，不记断裂。
- 新车辆入场、新边建立：从本拍开始计时，不计断裂；稳定确认不继承其他车辆或其他边的年龄。

## 3. 六类主指标

令本拍在网人数为N_k，编队集合为G_k，编队g的成员数为n_gk，物理边集合为E_k。所有求和只覆盖相邻有效采样区间。

### 3.1 编队平均规模与观察最大规模

\[
\overline n=\frac{\sum_k\sum_{g\in G_k} n_{gk}\Delta t_k}
{\sum_k|G_k|\Delta t_k},\qquad
n_{\max}=\max_{k,g\in G_k}n_{gk}.
\]

对应 `mean_platoon_size` 和 `max_platoon_size`。平均值按编队秒加权，不把“某车经历的大队”重复当作多个大队；最大值是采样中观察到的事实，不要求已持续5s。没有编队时两者为`None`，并由参与率和原始累计量说明缺队事实。

### 3.2 编队参与率

\[
P=\frac{\sum_k\sum_g n_{gk}\Delta t_k}{\sum_kN_k\Delta t_k}.
\]

对应 `participation_rate`，范围0到1。分子是`platoon_vehicle_seconds`，分母是`vehicle_seconds`，因此孤立车和正在跨道、未符合图条件的车辆保留在分母。全部有效在路车辆均不成队时P=0；没有车辆暴露时间时P为`None`。

### 3.3 编队邻接几何RMS

同道边残差为 `q_ij=abs(abs(x_i-x_j)-D)`；跨道边残差为匹配的 `m∈{-1,0,1}` 对应的 `q_ij=abs(z_j-z_i-mD)`。

\[
E_x=\sqrt{\frac{\sum_k\sum_{e\in E_k}q_{e,k}^{2}\Delta t_k}
{\sum_k |E_k|\Delta t_k}}.
\]

对应 `geometry_rms_m`，单位m，按物理边秒加权。它表示**已经识别为编队的局部相对队形精度**，不是全体车辆的全局槽位误差。由于编队边本身受2m阈值筛选，必须和参与率并列，不能用少数精确小队的低误差替代大多数车辆未成队的事实。没有边暴露时为`None`。

### 3.4 队内速度RMS

\[
E_v=\sqrt{\frac{\sum_k\sum_g\sum_{i\in g}(v_{i,k}-\bar v_{g,k})^2\Delta t_k}
{\sum_k\sum_g n_{gk}\Delta t_k}}.
\]

对应 `speed_rms_mps`，单位m/s，是各队总体标准差按车辆秒合并后的RMS，使用实际道路纵向速度。它衡量一致性，不表示已经达到目标巡航速度；所有车同时停住也可能同速，应结合已有平均速度和行程指标解读。没有编队车辆暴露时为`None`。

### 3.5 连续关系稳定参与率

某边从s开始连续成立，只有在 `s+5s` 之后才支持其端点为“稳定参与车辆”。一辆车同时有多条成熟边时只计一次。在每个有效采样区间内，按最早成熟边的确认时刻与区间相交的时间精确累计，即使确认时刻落在两帧之间，也不简单取整成帧数。

\[
P_{\rm stable}=\frac{\int N_{\rm stable}(t)\,dt}{\sum_kN_k\Delta t_k}.
\]

对应 `stable_participation_rate`，分子为`stable_vehicle_seconds`，分母仍为全部在网车辆秒。确认前5s不回填，短于5s的关系不贡献稳定参与；无在网暴露时为`None`。例如6辆完美编队从0s记录到10s，普通参与率为1，稳定参与率为0.5，因为0至5s用于确认。这一确认延迟是指标定义的一部分，不是算法另一次成队失败。

### 3.6 内部断裂率

\[
B_{100}=100\frac{N_{\rm internal\ break}}{\sum_k\sum_g n_{gk}\Delta t_k}.
\]

对应 `internal_breaks_per_100_platoon_vehicle_s`，单位是次/(100编队车辆秒)，分子为`internal_breaks`。同一无向边在一拍中最多断一次，之后重新建立再断开可另计。该指标统计关系事件，不是事故数；出界、记录结束、缺口和新入场按前述规则排除。无编队车辆暴露时为`None`，有编队暴露且没有内部断裂时为0。

同时保留`platoon_seconds`、`edge_seconds`、`censored_edges`、`frame_count`、`observed_duration_s`、`sampling_gap_count`、`first_time_s`、`last_time_s`及实际参数，以便复核分母和观察范围。它们是审计量，不额外增加主评价维度。

## 4. 原始文献依据与适用边界

1. Su, D., and Ahn, S. (2017). *In-vehicle sensor-assisted platoon formation by utilizing vehicular communications*. International Journal of Distributed Sensor Networks, 13(7). [DOI与出版方原文](https://doi.org/10.1177/1550147717718756)。PDF第7页“Performance metrics / Platoon stability”以车辆状态变化次数评价组织稳定度；第8页“Average platoon size”及式(8)评价平均规模。其正文规模采用跟随车数量，本研究明确改为包含所有成员；本研究的内部边断裂是状态变化思想的物理关系改写，不是照搬其通信角色计数。
2. Cai, M., et al. (2019). *Multi-lane Formation Assignment and Control for Connected Vehicles*. IEEE IV, 1968–1973. [DOI](https://doi.org/10.1109/IVS.2019.8813792)；[本机PDF](<D:/zotero文献/storage/IN4MBL45/Cai 等 - 2019 - Multi-lane Formation Assignment and Control for Connected Vehicles.pdf>)。PDF第2页/印刷1969，§II-A、图1–3给出交错分层及不满尾层；第4页/1971，§III-C说明期望与实际距离、速度之差。这里借鉴几何目标和误差的物理含义，不采用集中目标分配。

[DOI](https://doi.org/10.1109/TITS.2024.3413831)；[本机PDF](<D:/zotero文献/storage/CCM57MKV/Sreenivasamurthy和Obraczka - 2024 - Adaptive Decentralized Emergent Behavior Based Autonomous Platooning.pdf>)。PDF第6页/18343式(6)含间距与速度误差；第13页/18350表IV分别报告加入、达到队速、达到期望间距的阶段时刻。其系统使用通信，本文只借鉴物理误差与过程评价，不把其信息条件等同于本系统。

[DOI](https://doi.org/10.1109/IV55156.2024.10588701)；[本机PDF](<D:/zotero文献/storage/Y97IG9J7/Cai 等 - 2024 - Multi-lane Formation Control in Mixed Traffic Environment.pdf>)。PDF第2页/2284，§II说明交错结构、前部空位优先；第3页/2285，§IV主要评价平均行程时间和油耗。这篇支持场景和几何背景，不能替代本协议的直接编队规模与稳定度指标。
